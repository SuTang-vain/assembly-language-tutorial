### 0.2 每日三段式

```
第一段 输入 1.0h   读本讲知识树 → 读对应真题的题意和标准答案（看懂，不背）
第二段 输出 2.5h   闭卷做真题 → 编程题遮答案白纸写 → 错的回逐考点详解那一条
```

D1–D2 输入可放宽到 1.5h（第2/3讲理解负担最重）；D3 之后输出压倒一切；
**D9–D10 输入为 0，只写和背。**

### 0.3 过关判定（唯一标准，不放水）

编程题默写过关 = 同时满足：
1. **遮住所有答案**，白纸写**完整程序**（不是填空、不是改错）；
2. 写完自己对答案，**错一处也算错**（含大小写、含漏 `H` 后缀、含指令顺序）；
3. 标红后立刻重写；
4. **连续 3 次零错**，记入 `盲区清单` 的达标区。

概念题过关 = 闭卷做对，且能说出「另外三个选项为什么错」。

## 六、盲区清单模板

**这是整个计划真正的产出物。** 每天只追加、不重写；D10 只看它 + 必背表。

```markdown
## 盲区清单（起始日：____）

### 未消项（红）
- [D5][8253] 方式2/3 混淆 —— 方式2=周期性负脉冲(M2M1M0=010, 74H)，
      方式3=连续方波(011, 36H)。错因：把"方波"记成了方式2
- [D8][8259] ICW2 写成 3BH —— 只写高5位。3BH=00111011，高5位=00111，
      所以 ICW2=00111000B=38H。错因：忘了低3位由IR级别自动填

### 已消项（绿，写清怎么消的）
- [D3][汇编] Q2 的 INC BYTE PTR [BX] 漏了 BYTE PTR —— 连续 3 次默写零错，D4 消灭
```

**规则**：
1. 一条 = 一个具体错误，**不许写"粗心""没复习"**；
2. 必须包含「正确做法」+「当时怎么错的」两部分；
3. 连续 3 次默写零错才能移入已消项；
4. D10 只允许存在已消项。

## 七、考场执行要点（考试要求 p49，原话照办）

1. 代码**书写工整、建议大写字母**；**考试时代码不用加注释**（不加分，还费时间）；
2. 答案写在答题纸**框内**——机读只扫框内，框外写了不算；
3. 答题纸**不可折叠、弄脏**（要扫描）；
4. 带**证件 + 黑色笔**；
5. 时长 2 小时，题型含单选/多选/判断/填空/简答/分析/简单编程/综合设计。

**答题顺序建议**：先做身份题和数字计算题（快且稳，建立信心）→ 再作答题 → 最后编程题。
编程题**不许空着**：写得出多少写多少，控制字写对就有分。
