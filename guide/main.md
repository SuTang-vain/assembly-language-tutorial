### 0.5 老师点名的"非常容易写错"清单（PDF p48，逐条自测）

1. **结尾缺失报错**：`MOV AL, 01001010`（漏 B）→ 必须写 `01001010B`；`INT 21`（漏 H）→ `INT 21H`。
2. **编译错误**：`MOV AL, FFH`——字母开头的十六进制数**前面要补 0**：`MOV AL, 0FFH`；`OUT F2, AL` 同理 `0F2H`。
3. **乘法错**：`16H × 4 = 64H` 是**错的**！16H=22D，22×4=88=**58H**（十进制惯性是这类题的坑：INT 16H 的向量在 58H 不是 64H）。
4. **地址写法**：物理地址不能只写 `1234H`；要写完整逻辑地址形式 `1234H:5678H`（或算出 5 位物理地址 179B8H）。
5. **端口序列**：基地址 58H 的端口是 58H、59H、**5AH、5BH**——十六进制里 59H+1=5AH，**不是 60H**（又是十进制惯性）。

## 一、第10讲 数模与模数转换芯片（DAC0832 / ADC0809）【老师排序第一优先】

> 老师标注：转换原理"了解"、指标"了解"、**输出电压公式与满量程误差"掌握"、单/双缓冲"掌握"、两片编程"掌握"**。作业未布置此讲 → 最容易复习盲区。

### 1.1 D/A：DAC0832〔掌握〕

- **8 位分辨率、电流输出**（IOUT1/IOUT2）→ 必须外接**反相运算放大器**把电流转电压（负→正）。
- 内部：**两级锁存** = 输入寄存器（第一级）→ DAC 寄存器（第二级）→ D/A 转换器；倒 T 型 R-2R 电阻网络。
- **三种工作方式**〔掌握〕：**直通**（两级都不锁存，调试用）；**单缓冲**（一级锁存，单路输出最常用）；**双缓冲**（两级都锁存，**用于多路 DAC 同步更新输出**——"为什么要有双缓冲"的标准答案）。
- **输出电压公式〔掌握·必背〕**：`VOUT = −(D / 256) × VREF`（D 为 0~255 的数字量，负号来自反相运放）。
  - 例：VREF=5V、D=80H(128) → VOUT = **−2.5V**；D=FFH(255) → ≈ **−4.98V**。
- **满量程误差〔掌握〕**：实际满量程输出与理想值之差（约 ±1 LSB 量级，能写出定义即可）。
- **编程〔掌握〕**：锯齿波 = 循环 `OUT DAC, AL; INC AL`（0→255 一轮）；三角波 = 增到峰值后改为递减；方波 = 交替送 00H/FFH + 延时。波形频率由送数节奏决定（软件延时 NOP 循环，或 8253 定时中断里送数）〔网〕。
- **双极性电压输出**〔了解·网〕：需再加一级运放做电流求和。

### 1.2 A/D：ADC0809〔掌握〕

- **8 位分辨率、8 个模拟通道**（IN0~IN7）、**逐次逼近（SAR）原理〔理解〕**、转换时间约 **100μs**（时钟 ~640kHz）、单 +5V 供电。
- **通道选择**：C、B、A 三位地址 + **ALE 锁存**（上升沿把通道号锁进芯片）。
- **控制信号时序〔理解〕**：START（**上升沿 SAR 复位、下降沿启动转换**）→ 转换中 **EOC=低** → 结束 **EOC=高** → **OE** 置有效后 D7~D0 才输出数据。时钟典型 640kHz；START 正脉冲宽度 ≥100ns 量级〔网·了解〕。
- **转换四步流程〔掌握·必背〕**：
  ① 送通道号（CBA + ALE 锁存）→ ② 发 START 正脉冲 → ③ 等 EOC 由低变高（查询或中断）→ ④ OE 有效读走 D7~D0。
- **数字量换算**：`D = (VIN / VREF) × 256`；反推 `VIN = D × VREF / 256`。例：VREF=5V、VIN=2.5V → D=80H；D=C0H(192) → VIN=3.75V。
- **编程〔掌握〕**：单通道采集子程序（选通道→启动→查 EOC→读数）；**循环采集 8 路**并存入指定内存区（配合 8255 或直接译码口）——骨架：通道号 00H→07H 循环、采集值存 [BX] 并 INC BX、CX 计 8 次〔网〕；"启动前要不断检测是否已开始转换"（老师原话强调时序细节）。

### 1.3 本讲易错

1. EOC 极性反：**转换中低、结束高**；
2. 只写 CBA 不发 ALE → 转换的还是上一个通道；
3. DAC 输出直接量电压（忘接运放/忘负号）；
4. 双缓冲的意义答成"更快"（是**多路同步**）；
5. 量化误差按 **±1/2 LSB**（8 位 5V 量程 ≈ 9.8mV）。

## 二、第9讲 可编程串行通信芯片 8251A

> 老师：串/并区别"了解"、同步原理"了解"、**帧格式与波特率计算"掌握"、C/D 及收发引脚"掌握"、异步/同步初始化"掌握"、双机通信编程"掌握"、Modem 远距"了解"**。

### 2.1 串行通信基本概念

- **传送方向**〔理解〕：单工 / 半双工 / **全双工（8251A 是全双工）**。
- **同步 vs 异步**〔了解〕：异步=按字符成帧、每字符重新同步、开销大；同步=数据块+同步字符、连续传送、时钟严格同相、效率高。
- **异步帧格式〔掌握·必背〕**：空闲(1) → **起始位(0，1位)** → **数据位(5~8位，低位先发)** → 校验位(0/1位) → **停止位(1/1.5/2位，逻辑1)**。
- **波特率 vs 比特率〔掌握·必考计算〕**：1 起始 + 7 数据 + 1 校验 + 1 停止 = 10 位/字符、每秒 120 字符时：
  **波特率 = 10×120 = 1200 波特；比特率 = 7×120 = 840 bit/s**（只数**数据位**才是比特率）。
- 8N1（8 数据无校验 1 停止）= 10 位/字符；字节速率 = 波特率 ÷ 10。
- 调制解调器（Modem）〔了解〕。

### 2.2 8251A 芯片

- 支持 **5~8 位数据**、奇/偶/无校验；引脚〔掌握〕：**C/D**（=0 数据口、=1 控制/状态口）、TXD/RxD、**TxRDY/RxRDY**（收发就绪）、TxE、TxC/RxC（收发时钟）、DSR/DTR/RTS/CTS（Modem 联络）、SYNDET（同步检测）。
- 工作原理〔理解〕：发送 = DATA → 并/串转换 →（异步加起止位/同步加同步字符）→ 移位 → TXD；接收反序。

### 2.3 三个字（本讲第一考点）

| 字 | 写/读哪口 | 作用 | 关键位 |
|---|---|---|---|
| **方式字** | 复位后第一个写控制口 | 定帧格式与波特率因子 | 异步 D1D0=因子（**01×1 / 10×16 / 11×64**）；D3D2 数据位（5~8）；D5D4 校验（00 无/01 奇/11 偶）；D7D6 停止位（01/10/11 位） |
| **命令字** | 控制口（方式字之后，可反复写） | 运行控制 | D0 TxEN、D2 RxE、**D4 ER 错误复位**、D5 RTS、**D6 IR 内部复位(40H)**、D7 EH 搜同步 |
| **状态字** | 读控制口 | 收发状态与错误 | **D0 TxRDY、D1 RxRDY**、D2 TxE、D3 PE、D4 OE、D5 FE、D6 SYNDET、D7 DSR |

- 经典值：异步 8 位/无校验/1 停止/×16 → 方式字 **4EH**；允许收发+清错 → 命令字 **15H**；**40H = 内部复位**。
- **引脚 TxRDY ≠ 状态字 TxRDY〔网·经典辨析〕**：引脚有效 = **发送缓冲器空 ∧ CTS̄ 有效 ∧ TxEN=1**；状态字 D0 只反映"缓冲器空"——查询编程用状态字，中断驱动用引脚。
- 初始化流程〔掌握·必背〕：
  - **异步 4 步**：① 向控制口连写 **3 个 00H**（确保复位——00 00 00 40 序列保证必定触发内部复位，防同步字符 00H 的歧义〔网〕）→ ② 写 **40H**（软件复位）→ ③ 方式字 → ④ 命令字（清错、允许收发）。注：每次写入需恢复时间 REVTIME。
  - **同步 5 步**：前 3 步同上（方式字设同步）→ ④ 写**同步字符（1~2 个）** → ⑤ 命令字。
  - 顺序铁律：**复位 → 方式字 → （同步字符）→ 命令字**；方式字/命令字/状态字**共用同一个口**，靠"先后顺序"区分。

### 2.4 双机通信编程〔掌握〕

- **发送端**：读状态字，**TEST AL,01H（TxRDY）**，就绪才 `OUT 数据口, AL`；用 SI/BX 指向内存数据区并递增。
- **接收端**：**先查错误再查就绪**：`TEST AL,38H`（PE/OE/FE 三错误，bit5~3）非 0 转 ERROR → `TEST AL,02H（RxRDY）`就绪才 `IN AL, 数据口`，存入内存并递增指针。

查询收发模板〔网〕：

```asm
SEND: MOV DX, 控制口
      IN  AL, DX
      TEST AL, 01H       ; TxRDY?
      JZ  SEND
      MOV DX, 数据口
      MOV AL, [SI]       ; 取待发字节
      OUT DX, AL
      INC SI
      LOOP SEND          ; 或按长度寄存器计数
RECV: MOV DX, 控制口
      IN  AL, DX
      TEST AL, 38H       ; 先查错误 PE/OE/FE
      JNZ ERROR
      TEST AL, 02H       ; RxRDY?
      JZ  RECV
      MOV DX, 数据口
      IN  AL, DX
      MOV [DI], AL
      INC DI
```
- 远距离 MODEM 通信〔了解〕。

### 2.5 本讲易错

1. 方式字必须**复位后第一个写**（顺序分）；
2. 波特率因子≠波特率（时钟=波特率×因子，时钟由 8253 提供，如 1200bps×16=19.2kHz〔网〕）；
3. 帧计算漏起止位（8N1=10 位）；
4. RS-232 是**负逻辑**（-3~-15V 为 1）〔了解〕；
5. 状态字 38H 掩码对应的是 PE/OE/FE 三个错误位。

## 三、第8讲 可编程并行接口芯片 8255A

> 老师：内部结构"了解"、**端口地址 A1A0"掌握"、三种方式"掌握（方式0）/了解（1、2）"、控制字"掌握"、编程例"掌握"（开关LED、4开关→七段码；4×4键盘"了解"）**。
> 作业映射：课堂练习8255（5题）＋第8讲作业（2 编程连线，已 100 分）——本讲是我作业全对的讲次，稳住即可。

### 3.1 结构与端口地址〔掌握〕

- 三个 8 位口 PA/PB/PC + 控制口（**没有 PD 口**——作业送分题）；A 组 = A 口 + C 口高 4 位，B 组 = B 口 + C 口低 4 位。
- **A1A0 端口选择**：00→A 口、01→B 口、10→C 口、11→**控制口**。
- **地址计算（高频陷阱）**：基地址 B 接 **8088 → 连续 B、B+1、B+2、B+3**；接 **8086 → 间隔 2：B、B+2、B+4、B+6**（数据线接低 8 位，芯片 A0 接 CPU 的 A1）。
  - 例（老师样题）：基地址 68H 接 8088 → 68H/69H/6AH/6BH；若接 8086 → 68H/6AH/6CH/6EH。
  - 课堂练习真题：基址 80H——8088 答 80/81/82/83H；8086 答 80/82/84/86H。

### 3.2 三种工作方式〔方式0掌握〕

| 方式 | 名称 | 端口 | 要点 |
|---|---|---|---|
| 方式 0 | 基本输入输出 | A、B、C（高/低 4 位各自独立设方向） | 无握手，最常用 |
| 方式 1 | 选通输入输出 | A、B | C 口各位自动变握手线（STB/IBF/OBF/ACK/INTR）；INTR 可接 8259 |
| 方式 2 | 双向总线 | **仅 A 口** | C 口 5 位作握手；**"PB 没有方式 2"** |

**方式 1/2 握手线精确分布〔网·选择/判断高频〕**：

| 配置 | PC7 | PC6 | PC5 | PC4 | PC3 | PC2 | PC1 | PC0 |
|---|---|---|---|---|---|---|---|---|
| A口方式1 **输入** | I/O | I/O | **IBF_A** | **STB̄_A** | **INTR_A** | — | — | — |
| A口方式1 **输出** | **OBF̄_A** | **ACK̄_A** | I/O | I/O | **INTR_A** | — | — | — |
| B口方式1 **输入** | — | — | — | — | — | **STB̄_B** | **IBF_B** | **INTR_B** |
| B口方式1 **输出** | — | — | — | — | — | **ACK̄_B** | **OBF̄_B** | **INTR_B** |
| A口方式**2** | **OBF̄_A** | **ACK̄_A** | **IBF_A** | **STB̄_A** | **INTR_A** | （PC2~0 供 B 口） | | |

- 规律：**A 组握手固定占 PC3~PC7（INTR 恒为 PC3），B 组固定占 PC2~PC0（INTR 恒为 PC0）**；输入用 STB̄/IBF，输出用 OBF̄/ACK̄。
- 锁存行为〔网〕：方式1 输入/输出**均可锁存**；方式0 输出锁存、输入不锁存（三态缓冲）。
- 中断允许位 INTE 由 BSR 控制字设置（如 INTE_A 输入 = PC4 置 1）〔了解〕。

### 3.3 控制字〔掌握·考卷附格式图，要会算〕

- 两个控制字写**同一控制口**，靠 **D7** 区分：**D7=1 方式选择字；D7=0 C 口置位/复位（BSR）**。
- 方式字各位（附图给格式）：D6D5=A 组方式；**D4=PA 方向（1 入 0 出）**；D3=PC 高 4 位方向；D2=B 组方式；D1=PB 方向；D0=PC 低 4 位方向。方向位**1=输入、0=输出**。
  - 参考值：全输入=**9BH**；全输出=**80H**；PA 出/PB 入=**82H**（方式0，PC 出）；PA 入/PB 出=**90H**。
- **BSR**〔掌握〕：D7=0，D3D2D1 选 PC 位（000=PC0…111=PC7），**D0=1 置 1 / 0 置 0**；**一次只能操作一位**。
  - 老师例（PC5 发脉冲，控制口 63H）：`MOV AL,0AH`（PC5=0）→ OUT；`MOV AL,0BH`（PC5=1）→ OUT；再 0AH。
  - 作业真题（第8讲）：PC6 正脉冲模板 = 先写 **00001100B(0CH)**（PC6=0）→ 第二空 **00001101B(0DH)**（PC6=1）→ 再写 0CH（PC6=0）；注意按位算：PC6 → D3D2D1=110，置 1=0DH、清 0=0CH。8255 基地址 80H 与 8086 相连时 C 口地址 **84H**（8086 间隔 2！）、控制口 **86H**。
- **状态字**〔了解〕：方式 1/2 下读 C 口得到状态（IBF/OBF/INTR）；方式 0 读 C 口得到的是数据。

### 3.4 编程套路〔掌握〕

三步：**算控制字 → 写控制口 → 数据口 IN/OUT**。例（开关→LED，PA 入/PB 出，8088 端口 60H 起）：

```asm
      MOV DX, 63H
      MOV AL, 90H        ; PA 入、PB 出（方式0）——按实际方向选 90H/82H 等
      OUT DX, AL
READ: MOV DX, 60H
      IN  AL, DX         ; 读开关（含机械抖动 → 调 DELAY_20MS 防抖）
      NOT AL             ; LED 极性相反时取反（老师样题"开关断开灯亮"）
      MOV DX, 61H
      OUT DX, AL
      JMP READ
```

- 4 开关 → 七段码：`AND AL,0FH` 取低 4 位 → **XLAT 查表**得段码 → `NOT`（共阴/共阳极性）→ 输出 → JMP 循环。
- 4×4 键盘（行列扫描）〔了解〕。

## 四、第7讲 可编程计数/定时芯片 8253

> 老师：概念/参数/内部结构"了解"、**计数原理与计数方式"理解"、六种工作方式（0/2/3 重点"掌握"）、编程"掌握"（产生波形、级联低频；读锁存计数值"了解"）**。
> 作业映射：课堂练习8253（5 题）＋第7讲作业（2 编程连线，已交）。

### 4.1 结构与端口〔了解+掌握地址〕

- **3 个独立 16 位减 1 计数器**（CNT0/1/2），各配 **CLK / GATE / OUT**；控制字寄存器只写；最高计数频率 **5MHz**。
- A1A0：00→计数器0、01→计数器1、10→计数器2、11→**控制口**（与 8255 同套路，地址计算同 8086/8088 差异）。

### 4.2 计数原理〔理解〕

- **倒计数**：减到 0 时 OUT 输出结束信号；每个计数器有**初值寄存器→计数执行单元→输出锁存器**。
- 计数制〔掌握〕：二进制或 BCD。**最大初值：二进制 65536（写 0 即最大）、BCD 10000（2 字节，写 0）**；BCD 1 字节最大 **99**（课堂练习真题：不是 100！）；BCD 2 字节最大 **9999**。
- 初始化三步〔掌握〕：① 写控制字 → ② 写计数初值（**双字节时先低后高**）→ ③ 启动（写完初值即自动开始）。

### 4.3 六种工作方式〔方式0/2/3 掌握〕

| 方式 | 名称 | 启动 | 输出特征 | 自动重装 |
|---|---|---|---|---|
| 0 | 计数结束中断 | 软件 | 计数中 OUT=低，**到 0 变高**（上升沿可请求中断） | 否 |
| 1 | 可编程单稳态 | **硬件（GATE↑）** | 单个负脉冲，宽度=初值个时钟 | 可重触发 |
| 2 | 速率(分频)发生器 | 软件 | **周期性负脉冲**（每轮低一个时钟） | **是** |
| 3 | 方波发生器 | 软件 | **连续方波** | **是** |
| 4 | 软件触发选通 | 软件 | 到 0 输出**一个时钟宽负脉冲** | 否 |
| 5 | 硬件触发选通 | **硬件（GATE↑）** | 同 4 但由 GATE 触发 | 否 |

- 速记：**软件启动 0/2/3/4，硬件启动 1/5；周期性（自动重装）只有 2 和 3**。
- **方式3 奇数初值 N〔网〕**：高电平 (N+1)/2、低电平 (N−1)/2 个 CLK（近似方波；偶数才是严格 1:1）——判断题常用。
- **脉冲宽度对比〔网·名校真题〕**：方式1 负脉冲宽度 = **N 个 CLK**（单稳态）；方式4/5 负脉冲 = **1 个 CLK**；方式2 每 N 个 CLK 输出 1 个 CLK 宽负脉冲（f_OUT = f_CLK/N）。
- **GATE 逐方式作用〔网〕**：方式0/2/3/4 = **电平**允许/禁止（拉低暂停、拉高恢复；方式2 的 GATE ↑ 还会重装初值）；方式1/5 = **上升沿触发**（每次触发重装一轮）。
- 课堂练习真题：连续方波=**方式3**；周期性负脉冲=**方式2**。

### 4.4 控制字〔考卷附图〕

D7D6 选计数器；D5D4 读写方式（01 只低、10 只高、**11 先低后高**）；D3~D1 方式号；D0 制式（0 二进制/1 BCD）。
常用：CNT0 方式3 二进制先低后高=**36H**；CNT1 方式2 二进制先低后高=**74H**。RL=01/10 时初值**只写一个字节**（低或高），写错字节数会错位〔网〕。

### 4.5 初值计算〔必考〕

```
分频：N = f_in ÷ f_out        定时：N = t × f_in
```

- 例：2MHz 时钟 → 0.05Hz（周期 20s）LED：N_total = 2 000 000 × 20 = 4×10⁷ > 65536 → **级联两级**（如一级 20000×二级 1000 等，老师例取 N1·N2 之积）。
- 例：1MHz→1kHz 方波：N=1000=03E8H，方式 3，先写 E8H 再写 03H。
- 例：2MHz→1s：N=2 000 000 → 两级（2000 × 1000）：07D0H 与 03E8H。
- **单位换算先对齐指数**（kHz×ms = 10⁶/10³ 配平），这是 8253 计算题的第一失分点。

### 4.6 编程模板〔掌握〕

```asm
      MOV DX, 控制口
      MOV AL, 76H        ; CNT1、先低后高、方式3、二进制
      OUT DX, AL
      MOV DX, CNT1口
      MOV AL, 0E8H
      OUT DX, AL         ; 低字节
      MOV AL, 03H
      OUT DX, AL         ; 高字节
```

读当前计数值〔了解〕：写**锁存命令**（D7D6 选通道、D5D4=00 锁存当前计数值），再从计数器口读；**8254 增加读回命令**（可同时锁存计数值+状态）；最高频率口径：8253-5 = 5MHz（老师课件），8254 = 10MHz〔网〕。

### 4.7 本讲易错

1. 先低后高写反/只写一字节；2. 方式 4（软件）与方式 5（硬件）输出相同、触发不同；3. 初值 0 = 最大计数；4. BCD 下初值按十进制写（1000 写 1000H 不是 03E8H）；5. GATE 在方式 1/5 是触发、在 0/2/3/4 是允许/禁止；6. 级联总输出 = 两级分频之积。

## 五、第6讲 可编程中断控制器 8259A ＋ 8086 中断系统

> 老师：中断概念"了解"、**8086 中断处理压栈顺序"掌握"、中断向量/向量表"掌握"、35H 读/25H 设置向量"掌握"、8259 内部结构"了解"、优先级数量"掌握"、ICW/OCW"掌握"（注意：**试卷不附 8259 寄存器资料**）、单片应用编程"掌握"、两片级联初始化"理解"**。
> 作业映射：第6讲作业（6 题，未交但有官方答案已抄录）＋课堂练习8259（5 题，80 分——**我在 ICW2 上丢过 20 分**）。

### 5.1 中断基础

- **硬件中断 / CPU 轮询 / DMA** 区别〔了解〕。
- **8086 中断响应自动压栈顺序〔掌握·必背〕：FLAGS → CS → IP**（栈顶是 IP）；随后**清 IF、TF**。
  - 对比：**CALL 子程序只压 CS→IP（段间）或 IP（段内）**，不压 FLAGS——所以**中断返回必须 IRET（弹 IP、CS、FLAGS 三字），子程序返回用 RET**。
- 中断标志〔掌握〕：**IF 置 1 = STI（开中断）、清 0 = CLI（关中断）**；INTR 受 IF 控制，**NMI 不受 IF 控制**（非屏蔽，类型码 2）。
- 优先级：内部中断（除法错0/单步1/断点3/溢出4/INT n）> **NMI(2) > INTR**。
- **INTR 响应需要两个 INTA 总线周期〔网·可屏蔽中断专属〕**：第 1 个 INTA——8259 **冻结优先级判定、ISR 置 1（清对应 IRR 位）**，准备类型码；第 2 个 INTA——后沿把**类型码送上数据总线**，CPU 读取（此周期 M/IŌ、RD̄/WR̄ 均无效，可作识别特征）。NMI/内部中断无此周期——判断题"可屏蔽中断要执行两个中断响应总线周期"=**对**。

### 5.2 中断向量表〔掌握·必考计算〕

- 位置 **00000H~003FFH**（内存最低 **1KB**），共 **256 × 4 字节**。
- 每项 4 字节（小端）：**低 2 字节 = IP，高 2 字节 = CS**。
- **定位公式：表项首地址 = 中断类型码 n × 4**（十六进制乘法！16H×4=58H，不是 64H——老师易错清单原题）。
  - INT 16H → **00058H~0005BH**；n=4 → 00010H~00013H；n=44H → 44H×4=110H → 00110H~00113H。
- 反查题：00040H 起存 240BH（=IP）、00042H 起存 D169H（=CS）→ 40H/4=**10H**，入口 CS:IP = **D169:240BH**（作业第6讲 Q4 原题，答案 B）。
- 存放题：n=4、入口 0485:0016H → 10H:16H、11H:00H、12H:85H、13H:04H（低字节在低地址）（第6讲 Q1）。
- **读取向量〔掌握〕**：`MOV AL,n; MOV AH,35H; INT 21H` → 返回 **ES:BX** = 入口地址。
- **设置向量〔掌握〕**：`DS:DX ← 服务程序地址、AL ← 类型号、AH=25H、INT 21H`；模板：

```asm
      MOV AX, 0
      MOV DS, AX           ; 向量表在 0000 段（直接法时）
      MOV SI, n*4          ; 如 44H*4 = 110H
      MOV AX, 3600H        ; IP
      MOV [SI], AX
      MOV AX, 2000H        ; CS
      MOV [SI+2], AX
      ; —— 或者 DOS 法：
      PUSH DS
      MOV AX, SEG INTRAD
      MOV DS, AX
      MOV DX, OFFSET INTRAD
      MOV AL, n
      MOV AH, 25H
      INT 21H
      POP DS
```

（作业第6讲 Q5 连线原题：SI←44H*4、[SI]←IP、[SI+2]←CS、AH←25H——四个空 F/D/E/H 对应 25H、[SI+2]、44H*4、DX。）

### 5.3 8259A 芯片〔结构"了解"、以下必背〕

- **一片 8 级中断源**（IR0~IR7，**默认 IR0 优先级最高、IR7 最低**）；**级联**：CAS0~2 级联线、SP̄/EN̄ 主从设定。
- **优先级数量〔掌握·真题考过〕**：2 片=**15 级**；3 片=**22 级**；最多 **9 片（一主八从）= 64 级**。
- 内部三寄存器〔了解〕：IRR（谁在请求）、ISR（谁正在被服务）、IMR（**1=屏蔽**）。
- **端口（接 8088 经典 20H/21H）〔掌握〕**：**偶地址（A0=0）**：ICW1、OCW2、OCW3；**奇地址（A0=1）**：ICW2、ICW3、ICW4、**OCW1（屏蔽字）**。

### 5.4 初始化命令字 ICW〔掌握·必背，附图不给〕

| 命令字 | 端口 | 写什么 |
|---|---|---|
| ICW1 | **偶地址** | 启动初始化（D4=1 标志）；触发方式（边沿/电平）、单片/级联、是否要 ICW4 |
| ICW2 | 奇地址 | **中断类型码高 5 位**（低 3 位自动填 IR 序号）——**3BH 类型号 → ICW2 = 38H**（00111<<3=00111000B；我课堂练习答 07H 丢 20 分的题！） |
| ICW3 | 奇地址 | **仅级联时写**：主片=哪位 IR 接了从片（如从片接 IR2 → 00000100B）；从片=自身标识（接主片 IR2 → 00000010B）（第6讲 Q6 原题：主 ICW3=00000100B、从 ICW3=00000010B） |
| ICW4 | 奇地址 | **µPM=1（8086 模式）**；全嵌套/特殊全嵌套（D4；**特殊全嵌套=主片级联时用，允许同一从片内更高优先级请求再进入**〔网〕）；缓冲方式；AEOI 自动结束 |

- **级联初始化次序〔理解〕**：主片 ICW1~ICW4 → 从片 ICW1~ICW4（各自的偶/奇地址口，从片口 A0H/A1H）。
- **类型码归属〔网〕**：**从片的类型码由从片自己的 ICW2 决定**（主片 ICW2 只定主片 8 级）；主片 ICW3 位图与从片 ID 必须对应（IR2 ↔ ID=2）。
- 作业第6讲 Q6 套路（主 20H/21H、从 A0H/A1H、类型号主 08H~0FH、从 70H~77H）：主 ICW2=00001000B、主 ICW3=00000100B、从 ICW2=01110000B、从 ICW3=00000010B。

### 5.5 操作命令字 OCW〔掌握·必背〕

| 命令字 | 端口 | 用途 |
|---|---|---|
| **OCW1** | **奇地址 21H** | **中断屏蔽字，1=屏蔽**（用 AND/OR 指令构造成） |
| **OCW2** | **偶地址 20H** | **EOI 中断结束：`MOV AL,20H; OUT 20H,AL`**。两种语义〔网〕：**普通 EOI 清 ISR 中优先级最高的"1"**（只适合全嵌套）；**特殊 EOI 指定位**（D6 SL=1、D2~D0 指定位，用于嵌套结构可能被破坏时）。OCW2 还负责优先级循环（D7 R、D6 SL、D5 EOI 位组合）〔了解〕 |
| OCW3 | 偶地址 | 读 IRR/ISR、查询方式（读 IRR 用 0AH） |

- **OCW1 屏蔽字真题（第6讲 Q3）**：只允许时钟 IR0、键盘 IR1、硬盘 IR5 → 屏蔽其余：**11011100B → OUT 21H**（IR0/1/5 位写 0 允许，其余写 1 屏蔽）；ICW2 设 08H → `MOV AL,00001000B; OUT 21H,AL`。
- **EOI 时机（第6讲 Q2 答案 C）**：普通 EOI 与特殊 EOI 都在**中断服务程序结束前**发出；OCW2=20H 使 ISR 中优先级最高的"1"清零。

### 5.6 中断应用编程套路〔掌握·老师点名的综合题〕

**主程序**：设置中断向量（25H 或直接法）→ 设置循环次数 → **STI 开中断** → 允许某 IR（OCW1 屏蔽字）→ 等待/干正事 → 返回 DOS（4CH）。
**服务程序**：显示提示（09H）→ 处理 → **`MOV AL,20H; OUT 20H,AL`（EOI）** → **IRET**。

```asm
MYINT PROC FAR
      PUSH AX
      PUSH DS
      ……                  ; 处理
      MOV AL, 20H
      OUT 20H, AL         ; EOI——不发则同级/低级中断永远进不来
      POP DS
      POP AX
      IRET                ; 不能写成 RET！
MYINT ENDP
```

### 5.7 本讲易错（含个人错题）

1. **ICW2 只写高 5 位**：3BH → 38H（07H 是错的——已丢过 20 分）；
2. 16H×4=58H（不是 64H）；向量项低字 IP 高字 CS；
3. IMR **1=屏蔽**（直觉反）；OCW1 奇地址、OCW2 偶地址；
4. 服务程序结尾 **IRET** + **EOI**，缺一不可；进入中断 CPU 自动清 IF，服务程序里若允许嵌套才再 STI；
5. 中断压栈 FLAGS→CS→IP 与 CALL 压栈区别（简答常客）；
6. 2 片 15 级 / 3 片 22 级 / 9 片 64 级（作业原题：15、64）。

### 7.1 结构与定义〔掌握〕

- 段定义 `XXX SEGMENT … ENDS`；**SEG/OFFSET** 取段址/偏移；变量 **DB/DW**（DW 11H,22H,3344H → 11 00 22 00 44 33 小端）；

- 常量 **EQU**（不可重定义）与 `=`（可重定义）——区别就一条；宏 `MACRO…ENDM`；
- 子程序 `PROC … RET … ENDP`（8086 压栈 CS→IP）；**中断子程序 PROC FAR … EOI … IRET ENDP**（压栈 FLAGS→CS→IP）。

### 7.2 DOS INT 21H 功能表〔必背！试卷不附〕

| 功能号 | 功能 | 入口 | 出口 |
|---|---|---|---|
| **01H** | 键盘输入一字符并回显 | — | **AL=字符** |
| **02H** | 显示一个字符 | **DL=字符** | — |
| **09H** | 显示字符串 | **DS:DX=串首址（'$' 结尾）** | — |
| **0AH** | 缓冲输入一行 | DS:DX=缓冲区首址 | 缓冲区格式（[最大数][实际数][字符…]） |
| **25H** | 设置中断向量 | **DS:DX=入口、AL=类型号** | — |
| **35H** | 读取中断向量 | AL=类型号 | **ES:BX=入口** |
| **4CH** | 程序终止返回 DOS | AL=返回码 | — |

**0AH 缓冲区三段精确口径〔网〕**：第 1 字节 = **允许输入的最大字符数（含回车，且不能为 0）**；第 2 字节 = **实际输入字符数（不含回车，DOS 自动回填）**；第 3 字节起存键入字符，**末尾自动存回车 0DH**。缓冲区必须定义在当前数据段：`BUF DB 20, ?, 20 DUP(?)`。

〔了解·网〕08H = 无回显键入一字符；0BH = 检查键盘状态（AL=0FFH 有键）。

### 8.2 常用指令清单（老师 p36 划定范围）〔掌握〕

- **MOV**：四禁令——①两操作数不能同时内存；②立即数不能直接进段寄存器；③CS 不能作目的；④类型必须匹配（MOV AL,BX 非法）。
- **XCHG** 交换（不能立即数/段寄存器）；**XLAT**：AL ← DS:[BX+AL]（查表，"查第 5 个字符"样题：`LEA BX,TABLE; MOV AL,4; XLAT`）。
- **IN/OUT**：累加器只能 AL/AX；端口 ≤FFH 立即、>FFH 用 DX（`IN AL,DX`）。
- **LEA**：取**偏移地址**（`LEA BX,TABLE` ≙ `MOV BX,OFFSET TABLE`）；与 MOV 取内容对比。
- **PUSH/POP**：**8086 只压字**（PUSH AL 非法）；PUSH 先 SP−2 再存数，POP 先取数再 SP+2。
- **加减乘除**：ADD/ADC/SUB/SBB/CMP/INC/DEC/NEG；**INC/DEC 不影响 CF**；CMP 只置标志不回写；**NEG 影响 CF（x≠0 时 CF=1）及 ZF/SF/OF/PF/AF**〔网〕；**CBW/CWD 不影响标志**——有符号除前 CWD、无符号除前 XOR DX,DX，混用是程序阅读题陷阱〔网〕。
  **乘除隐含寄存器〔必背〕**：MUL r8→**AX=AL×r8**；MUL r16→**DX:AX=AX×r16**；DIV r8→AX÷r8 商 AL 余 AH；DIV r16→DX:AX÷r16 商 AX 余 DX；**除法前清 DX（XOR DX,DX）或 CWD**；商装不下→**0 号中断（除法溢出）**，不是置标志。
- **与或非异或**：AND/OR/XOR/NOT/TEST——**CF=OF=0**，SF/ZF/PF 按结果；**NOT 不影响任何标志**；TEST=不回写的 AND（测位）；招式：`AND AL,0FH` 保留低 4 位、`OR AL,80H` 置最高位、`XOR AL,0FFH` 取反、`XOR AX,AX` 清零（2 字节+清标志）。
  - **作业判断真题**："`OR AL,40H` 常用于检测 AL 第 6 位是否为 1"→ **错**（OR 是置位/合并用，检测要用 TEST/AND）。
- **比较与测试**：CMP（算术比较）、TEST（位测试）——都只置标志。
- **移位**：**SAL≡SHL（完全相同，作业判断原题答案"对"）**；SHR 补 0、SAR 补符号位（有符号除 2）；**次数>1 必须用 CL**；CF=最后移出的位；循环移位 ROL/ROR（不经过 CF）、**RCL/RCR（带 CF）**。作业原题：`MOV AL,0A8H; MOV CL,3` 后 SAL 得 D0H、SAR 得 F5H（符号位保护）。
- **转移**：**无条件 JMP**（填空样题答案）；有符号比大小 **JG/JGE/JL/JLE**，无符号 **JA/JAE/JB/JBE**（混用是高频错）；条件转移全是**短转移（±128 字节）**，**LOOP 系列同样是短转移**〔网〕；远距离条件跳转用"Jcc + JMP"两段式。
- **LOOP**（CX−1≠0 转，不影响标志）；**NOP**。
- 指令长度：最短 **1 字节**（NOP/HLT），最长 6 字节（作业填空原题）。

### 8.3 标志位速查（作业反复考）〔掌握〕

| 指令 | CF | OF | 其他 |
|---|---|---|---|
| ADD/ADC/SUB/SBB/CMP/NEG | √ | √ | ZF/SF/PF/AF 全影响 |
| INC/DEC | **不动** | √ | ZF/SF/PF/AF 影响 |
| MUL/IMUL | √ | √ | 其余不定 |
| AND/OR/XOR/TEST | **=0** | **=0** | ZF/SF/PF 按结果 |
| NOT | 不影响 | 不影响 | 全不影响 |
| SHL/SHR/SAL/SAR | =移出位 | 仅次数=1 时有意义 | 移位不改变低位标志语义 |
| ROL/ROR/RCL/RCR | =移出位（RCL/RCR 过 CF） | 仅次数=1 | **SF/ZF/PF 不影响** |
| MOV/PUSH/POP/XCHG/LEA | **全部不影响** | | |
| LOOP/JMP | 不影响 | | |

〔网〕**LAHF/PUSHF 不影响标志；SAHF/POPF 影响标志**（两两成对的判断题）。〔了解〕`XCHG AX,AX` 的机器码就是 1 字节 NOP（90H）。

- 带符号加法标志计算（第2讲作业 Q5 原题，老师 p40 同型例）：1011 0100B（B4H=−76）+ 1100 0111B（C7H=−57）= 1 0111 1011B → 8 位结果 7BH：**CF=1（进位）、AF=0（4+7=0BH 无半进位）、ZF=0、PF=1（结果 7BH 含 6 个 1，偶）、SF=0、OF=1（负+负=正，溢出）**。计算套路：逐位加 → 按定义判 6 个标志，OF 用"双正得负/双负得正"判；PF 只数**结果低 8 位**中 1 的奇偶。老师 p40 例（+105+50=155）：01101001+00110010=10011011 → CF=0、AF=0、ZF=0、PF=0（7 个 1，奇）、SF=1、**OF=1（正+正=负）**。

## 九、第2讲 微处理器的系统结构（8086/8088）

> 老师：结构图"了解"、**寄存器/FLAGS/物理地址/堆栈/存储体/最小系统"掌握"**。
> 作业映射：第2讲 16 题（题量最大，全部作业题都值得重做一遍）。

### 9.1 基本参数〔背数字〕

| 项 | 8086 | 8088 |
|---|---|---|
| 数据线 | **16 根** | **8 根**（主要区别） |
| 地址线 | 20 根 | 20 根 |
| 指令队列 | **6 字节** | **4 字节** |
| 内存寻址 | 1MB（M/IŌ=1） | 同 |
| I/O 寻址 | 64KB（M/IŌ=0） | 同 |
| 引脚 | 40 脚，AD0~15 地址/数据复用 | 同（外部数据 8 位） |

- **EU/BIU〔掌握〕**：执行单元（ALU+通用寄存器+FLAGS）与总线接口单元（段寄存器+IP+**6 字节指令队列**+地址加法器）**并行工作**（BIU 预取指令）。
- **物理地址 = 段地址×16 + 偏移**（十六进制段址左移一位再相加）。样题：CS:IP=1234H:5678H → **179B8H**；CS:IP=3456H:0210H → 34560+0210=**34770H**（作业 Q11）。逻辑地址书写必须 `段:偏移` 完整形式（老师易错清单）。
- 复位后：**CS=FFFFH、IP=0000H**（其余寄存器清 0），从 FFFF0H 开始执行（作业判断原题"对"）。

### 9.2 寄存器组〔掌握·填空高频〕

- 通用 8 个：**AX**（累加器：乘除/IO 专用）、**BX**（基址、可作地址）、**CX**（计数：LOOP/移位 CL）、**DX**（数据：乘积高位、间接端口）；**SP**（栈顶指针，配 SS）、**BP**（基址指针，默认配 SS）、**SI**（源变址，配 DS）、**DI**（目的变址，**串操作配 ES**）。高低 8 位可拆 AH/AL 等。
- 段寄存器 4 个填空（作业原题，务必**大写**）：**CS 代码段 / DS 数据段 / SS 堆栈段 / ES 附加段**。
- 控制 2 个：IP（指令指针）、FLAGS。
- **FLAGS〔掌握〕**：状态位 **CF(0) PF(2) AF(4) ZF(6) SF(7) OF(11)**，控制位 **TF(8) IF(9) DF(10)**；口诀"CF PF AF ZF SF TF IF DF OF"。**OF=有符号溢出、CF=无符号进位**，两者独立。
  - 标志位计算作业模板（Q5）：两个 8 位带符号数相加后写 6 个标志——逐位算，注意 PF 数**低 8 位中 1 的个数**的奇偶、AF 是 D3→D4 半进位。

### 9.3 堆栈〔掌握〕

- 栈顶 **SS:SP**；**PUSH：SP−2**；**POP：SP+2**（作业原题：SS:SP=2000:0300H，两条 PUSH 后 SP=02FCH，再 POP 后 02FEH）。
- 堆栈大小：SS:SP=2000:1300H → 栈区 2000:0000H~2000:12FFH，**容量=SP（1300H 字节）**（老师 p41 原话）。
- **8086 压栈顺序**：CALL → CS,IP；中断 → FLAGS,CS,IP（见第6讲）。

### 9.4 引脚与时序〔掌握+了解〕

- **地址/数据复用**：AD15~AD0（T1 传地址、后续传数据）；A16/S3~A19/S6 高 4 位地址/状态复用；**BHE/S7**（低有效选奇体）；**MN/MX̄**（第 32 脚：接 +5V 最小模式，接地最大模式由 **8288** 总线控制器出控制信号——"8086 把状态码 S0S1S2 送给 8288"是选择高频点）。
- **读写判断（作业 Q7 原题）**：WR̄=1、RD̄=0、M/IŌ=1 → **正在读内存**（RD̄ 低=读、M/IŌ 高=存储器）。
- 时序〔了解/概念〕：时钟周期（主频倒数）<总线周期（**至少 4 个 T：T1 地址、T2~T4 数据**）<指令周期；慢设备插 **Tw**；8086 标准主频 4.77MHz（T≈200ns）。〔网〕5MHz 下一个总线周期 = **800ns**；**READY 在 T3 采样**，低则 T3 后插 Tw 直到变高；T1 输出地址 + **ALE 锁存**（下降沿锁入 373）；最小模式数据收发由 **DT/R̄（1 写 0 读）+ DEN̄（使能）**控制 74LS245〔了解〕。
- **最小系统两块配套芯片〔掌握〕**：地址锁存 **74LS373（或 8282）至少 3 片**（锁存 A0~A19+BHE，共 21 位 → 3×8）、数据缓冲 **74LS245（或 8286）至少 2 片**（16 位数据 → 2×8）——作业 Q12 原题"3，2"。

### 9.5 存储体（奇偶体）〔掌握〕

1MB 分两个 512KB 体：**偶体（数据线 D7~D0，选通 = A0=0）**、**奇体（数据线 D15~D8，选通 = BHE=0）**；其余地址线 A19~A1 两体共用。

| BHĒ | A0 | 操作 |
|---|---|---|
| 1 | 0 | 偶地址读/写**一个字节**（偶体） |
| 0 | 1 | 奇地址读/写**一个字节**（奇体） |
| 0 | 0 | 偶地址读/写**一个字**（一个总线周期） |
| 1 | 1 | 无效 |

- **小端序〔必背〕**：低字节在低地址——字 1234H 存于 10000H → 10000H=34H、10001H=12H（第1讲作业 Q5）。
- **字访问次数（作业 Q16 连线原题）**：从偶地址（如 0000H）读字=**1 次**总线周期；从奇地址（如 0001H）读字=**2 次**（先奇体后偶体）；字节恒 1 次。
- 存储体选择连线（作业 Q15）：给 BHĒ/A0 电平 → 判断选中哪个体/是否无效。

### 9.6 本讲易错

1. 指令队列 6（8086）/4（8088）；数据线 16/8；
2. 物理地址先左移段址（12340H+5678H），不是 1234H+5678H；
3. PUSH/POP 只能字、方向位"先减后存/先取后加"；
4. BHĒ 低有效；奇地址字 2 个总线周期；
5. "复位后从 FFFF:0000H 开始执行"——对。

| OCW3 | 偶 20H | 读 IRR/ISR（0AH=读 IRR）、查询方式 |

配套流程：初始化 ICW1→ICW2→(ICW3)→ICW4；服务程序结束**前**发 EOI；返回用 IRET；主程序 STI。

### 11.3 必背数字表

| 6/4 | 指令队列 8086=6 字节、8088=4 字节 |
| 1MB / 64KB | 内存独立寻址 / I/O 独立寻址 |
| 3片/2片 | 74LS373（锁存 21 位地址）3 片、74LS245（缓冲 16 位数据）2 片 |
| 15/22/64 | 8259 级联 2/3/9 片的优先级数（一主八从 64 级） |
| 65536 / 10000 | 8253 二进制/BCD 最大计数（写 0）；BCD 单字节 99、双字节 9999 |
| 0/2/3 方式 | 8253 软件启动 0/2/3/4、硬件 1/5；周期性只有 2/3 |

### 11.4 控制字参考值速查（格式看附图，值要会算）

- 8255：全输入 9BH / 全输出 80H / PA出PB入 82H / **PA入PB出 90H**；BSR：PCi 置 1 = 0000 0**iii**1、清 0 = 0000 0**iii**0（iii=位号）
- 8253：CNT0 方式3 先低后高二进制 **36H**；CNT1 方式2 **74H**；CNT2 方式3 **B6H**
- 8251：异步 8N1×16 方式字 **4EH**；命令"允许收发+清错" **15H**；内部复位 **40H**；状态字测 TxRDY=01H、RxRDY=02H、错误掩码 38H
- 8259：单片经典 ICW1=13H、ICW2=08H、ICW4=01H；EOI=20H；屏蔽字按位"0 允 1 屏"

### 11.5 易错 20 条（老师 p48 ＋ 三源合并，考前最后一遍）

1. 数字结尾 B/H 不可省（01001010B、21H）；字母开头补 0（0FFH、0F2H）
2. 16H×4=58H（≠64H）；INT 16H 向量在 00058H~0005BH
3. 十六进制加法：59H+1=5AH（≠60H）
4. 物理地址写完整（1234H:5678H 或 179B8H），不能只写 1234H
5. ADD AL,256 非法（超 8 位立即数）；PUSH AL 非法（只能压字）
6. IN AL,100H 非法（100H=256>FFH 须 DX）；OUT 300H,AL 同；**但 OUT 0F2H,AX 合法**（0F2H=242≤FFH）
7. MOV DS,段名 非法（经 AX）；CS 不能作目的；两内存操作数非法
8. INC/DEC 不影响 CF；NOT 完全不影响标志；MOV 类不影响标志
9. SAL≡SHL；SAR≠SHR（符号位）；次数>1 用 CL
10. "OR 检测位"错——检测用 TEST/AND
11. 中断压栈 FLAGS→CS→IP；服务程序必须 EOI+IRET（缺 EOI 下次中断进不来）
12. ICW2 高 5 位（3BH→38H）；IMR 1=屏蔽；OCW1 奇口、OCW2 偶口
13. 向量项低字 IP、高字 CS（小端）
14. 8255 端口：8086 间隔 2（80/82/84/86H）、8088 连续（80/81/82/83H）
15. 8255 方向位 1=输入；BSR 一次一位、写控制口；方式 2 仅 A 口
16. 8253 先低后高写初值；初值 0=最大计数；周期性只有方式 2/3
17. 8251 初始化：3×00H→40H→方式字→（同步字符）→命令字；状态 38H=三错误
18. ADC0809：EOC 转换中低/结束高；通道要 ALE 锁存；OE 才能读数
19. DAC0832 电流输出要接运放；双缓冲=多路同步
20. 8253 级联输出频率=两级分频之积；超 65536 必级联
