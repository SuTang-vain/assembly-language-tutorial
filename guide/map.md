# 一、真题自己说的话

## 1.1 这不是一门「接口课」

题量最大的是第 2、3 讲——CPU 结构和指令系统，合计 31 题、占 38%。五颗接口芯片
（第 6～10 讲）合计 39 题、占 48%。

如果只看芯片题量，容易误判成「接口课」；但第 2、3 讲那 31 题全部是关于**机器本身**
的：寄存器怎么分、标志位怎么算、物理地址怎么算、什么指令合法。芯片题里也有相当
一部分考的是「这个芯片是什么身份」这类记忆题。

**判断：这门课是用五颗可编程芯片当载体，逼你第一次真正理解「程序如何在机器上
精确地发生」。汇编是手段，芯片是教具。**

## 1.2 题型结构暴露了考试的真实形态

连线题 18 题 + 填空题 12 题 = 30 题，占 37%。这两种题型在作业里都长成「给参考代码
填空」的样子，但题干自己写明了考试要求：

- 第6讲 Q3：「作业中只需要选出正确的答案即可，**考试中要求写出过程及代码**」
- 第6讲 Q4：「作业中只需要选出正确的答案即可，**考试时要求写出来过程及结果**」
- 第8讲 Q1/Q2：「**只写代码即可**，不用画电路图」

**判断：作业放水，考试不放。** 上表「需要写汇编代码的题」列出的每一题，考试都是
白纸默写。这是复习的真正主战场，实际占分远高于题量占比。

## 1.3 题量最少的讲次恰恰是枢纽

第 5 讲只有 2 题，是十讲里最少的。但它讲的是 74LS138 译码和 I/O 编址——**外设在
CPU 眼里就是几个地址**。后面五颗芯片每一道编程题的第一步「算端口地址」，全部依赖
这一讲。第8讲那两道「8086 接地址 +2、8088 接连续」的选择题，就是第 5 讲的直接延伸。

**判断：第 5 讲不能因为题少就跳过，它是第 6～10 讲的地基。**

# 二、从 81 题反推的完整知识树

按真题实际考到的内容列，不按课本目录。

## 第1讲 基础（真题 5 题）——地基

- **十六进制写法规则**：字母开头必须补 0（`0F1H` 合法，`FFH` 要写 `0FFH`）；
  无 `H` 后缀就是十进制（`16` ≠ `16H`）
- **三大总线**：数据总线 DB / 地址总线 AB / 控制总线 CB
- **ASCII 码**：`'A'=41H`、`'1'=31H`、`'a'=61H`（大小写差 20H，数字与字母差 11H）
- **小端模式**：`12345678H` 从 10000H 存起，10000H 处是 `78H`（低有效字节在低地址）
- 微处理器发展史（4004→8008→8086→32位→64位）——纯记忆，优先级最低

## 第2讲 8086 结构（真题 16 题）——第一大块

- **EU / BIU 两部分并行工作**：EU 算、BIU 取，这是流水线的雏形
- **4 个段寄存器** CS / DS / SS / **ES**（附加段，真题专门考这个空）
- **8 个通用寄存器** AX / BX / CX / DX / BP / **SP** / SI / **DI**
- **三个数字**：数据线 16 位、地址线 20 位、寻址 1MB
- **8086 vs 8088**：唯一区别是外部数据线（16 位 / 8 位）
- **标志位六大件** CF / ZF / SF / PF / AF / OF——真题要求能手算
- **PUSH/POP 与 SP**：PUSH 使 SP−2，POP 使 SP+2
- **物理地址 = 段值 × 16 + 偏移**（`3456:0210H` → `34770H`）
- **地址/数据复用**：AD15~AD0 低 16 位兼作数据线，A19~A16 兼作状态线
- **时序三层**：时钟周期 → 总线周期（≥4 个 T）→ 指令周期（**不等长**）
- **最小模式**：MN/MX̄ 接 +5V，控制信号全由 CPU 直接产生
- **奇偶存储体**：BHĒ 与 A0 的组合决定选哪个体、读字节还是字
- **字/字节访问的存储器周期数**（对齐问题）
- 74LS373 地址锁存器 3 片 + 74LS245 数据缓冲器 2 片
- 复位后 CS=FFFFH、IP=0000H

## 第3讲 8086 指令（真题 15 题）——第二大块

- **JMP 的五种形态**：近跳、寄存器间接、`[BX]` 二级间接、`FAR PTR` 远跳、
  `DWORD PTR [BX]` 双字间接
- **算术指令的副作用**：`MUL BL` 改 AH:AL、`IMUL CX` 改 DX:AX、
  `DIV CL` 商在 AL 余在 AH、`IDIV CX` 商在 AX 余在 DX
- **指令长度**：最短 1 字节、最长 6 字节、指令队列 6 字节
- **LOOP / LOOPE 的执行轨迹追踪**（真题给具体初值要求算终值）
- **移位家族** SHL / SHR / SAR / RCL 与 CF 的关系；
  **SAR 与 SHR 对负数的结果不同**
- **非法指令清单**（真题连考 3 题，见下表「坑」第 1～7 条）
- **CF 的置位来源**：只有算术/逻辑/移位能改；MOV/PUSH/POP/XCHG 完全不影响标志
- **XOR AX,AX 优于 MOV AX,0**：短 1 字节，且顺带清标志
- **检测位要用 TEST，不是 OR**（`OR AL,40H` 会破坏 AL）
- **SAL ≡ SHL**（结果永远相同）
- **寻址方式五类**：立即 / 寄存器 / 寄存器间接 / 直接 / 相对基址加变址
- **XLAT 查表**：`BX + AL` 寻址，AL 既是索引又是结果

## 第4讲 汇编（真题 4 题，全部编程）

四个程序，每一个考一个不同的语言机制：

| 真题 | 程序任务 | 考查机制 |
|---|---|---|
| Q1 | 显示 00–FFH 全部 ASCII | 循环计数 + `DOS 02H` 显示单字符 |
| Q2 | 统计正数/负数/零的个数 | 循环 + `CMP` + `JG/JE/JL` 三分支 + `INC BYTE PTR [BX]` |
| Q3 | 成绩分档显示 F/G/P | 多次 `CMP` + `JB/JAE` + `JMP` 组织分支 |
| Q4 | 键盘输入查七段码 + 提示串 | `DOS 09H` 打印 `$` 结尾串 + `DOS 01H` 输入 + `XLAT` |

## 第5讲 IO/总线（真题 2 题）——题最少但是枢纽

- **74LS138 译码器**：CBA 输入 011 → Y3̄ 输出低电平
- **门控条件**：A19 A18 A14 必须为指定组合，译码器才使能
- **片选条件**：/Y3̄=0 要求 A17 A16 A15 = 011
- **27128 是存储器，不是 I/O 设备**（存储器映射与 I/O 映射的区分）

## 第6讲 8259 中断（真题 11 题）——难度顶峰

- **中断向量表定位**：类型号 n 的入口在 `n×4` 起的 4 字节，**低字存 IP、高字存 CS**
- **反查**：40H 起存 240BH、42H 起存 D169H → n=10H，CS=D169H IP=240BH
- **OCW2 EOI**：`20H` 普通 EOI（清最高优先级位）、`01100011B` 特殊 EOI（后三位
  指定位）；**都必须在中断服务程序结束前发**
- **ICW2**：只写高 5 位，低 3 位由 IR 级别自动填。设 08~0FH 写 `00001000B`；
  若响应时发出 3BH，则 ICW2 应为 `38H`
- **OCW1 屏蔽字**：0=允许。只允许 IR0/IR1/IR5 → `11011100B`
- **8259 向 8086 发的是 INTR**（不是 NMI，也不是 INTA）
- **级联容量**：2 片管 15 个可屏蔽中断源，9 片管 64 个
- **直接法设向量**：`MOV SI, n*4` → `MOV [SI],AX` → `MOV [SI+2],AX`
- **DOS 法设向量**：`MOV AH,25H` → `MOV AL,n` → `INT 21H`
- **主从初始化**：主片 ICW2=08H、ICW3=`00000100B`(IR2)、ICW4；
  从片 ICW2=70H、ICW3=`00000010B`、ICW4

## 第7讲 8253 定时（真题 7 题）

- **BCD 计数上限**：1 字节最大 **99**，2 字节最大 **9999**（不是 100 / 10000）
- **方式 3 = 连续方波，方式 2 = 周期性负脉冲**（真题连考 2 题区分这两个）
- **控制字格式**：`SC1SC0 RL1RL0 M2M1M0 BCD`
- **级联分频**：OUT1 → CLK2，总初值 = 两级相乘
- **初值计算**：N = f_clk ÷ f_out

## 第8讲 8255 并行（真题 7 题）

- **端口地址陷阱（高频）**：接 **8086** 时间隔 2（80/82/84/86H），
  接 **8088** 时连续（80/81/82/83H）
- **C 口 BSR**：一次只能置/复位**一位**（真题专门考「一次设置所有引脚」是错的）
- **端口只有 PA/PB/PC，没有 PD**
- **编程**：PC6 输出正脉冲、A口读开关驱动 B口 LED

## 第9讲 8251 串行（真题 9 题）

- **波特率计算**：波特率 = 每字符位数 × 字符率。1+8+0+1=10 位 × 200 字符/秒
  = 2000 Bd，×16 = **32 kHz**
- **异步帧**：起始位 0、数据 5~8 位**低位先发**、校验可选、停止位 1~2。
  真题考「数据位只能是 8 位」是**错**的
- **引脚辨析**：`C/D̄` 才是控制/数据选择，**A0 不是**
- **TXC 可以是波特率的 1 / 16 / 32 / 64 倍**
- **三个字共用一个口，靠先后顺序区分**：
  方式字（如 `00111000B` = 同步+双同步+偶校验+7位）、
  命令字（如 `10010101B` = 搜索同步+复位错误+使能收发）、状态字
- **异步初始化 4 步**：3×`00H` → `40H` 内部复位 → 方式字 → 命令字
- **同步初始化 5 步**：前 3 步同 + 同步字符 1~2 个 + 命令字
- **双机通信**：8253 产生波特率时钟（N = 2MHz ÷ 76.8kHz = 26）+ 8251 收发查询

## 第10讲 DAC/ADC（真题 5 题）

- **DAC0832**：8 位 / 256 级、建立时间约 1μs、**电流输出**（必须外接反相运放
  才能出电压）、两级锁存
- **三种工作模式**：直通 / 单缓冲（最常用）/ 双缓冲（多路同步更新）
- **ADC0809**：8 位、8 通道轮流、**逐次逼近型**、约 100μs、单 +5V
- **引脚**：ALE 地址锁存、VREF± 参考电压、CLK 外部时钟、OE 输出允许

# 三、零基础六步路径

真题的知识依赖是严格分层的，顺序不能乱。

## 第 0 步　十六进制与二进制运算（半天）

不是「复习」，是**重新学**。后面每一步的计算都建立在二进制直觉上。练到不用想为止。

## 第 1 步　第2讲 结构（真题 16 题）

核心不是背参数，是建立三个模型：

1. CPU = EU + BIU 两条流水线；
2. 内存地址 = 段值 × 16 + 偏移；
3. 一条指令的生命周期 = 若干总线周期，每周期 4 个 T。

自测：第2讲 16 题全做，重点 Q5（标志位手算）、Q8（SP 追踪）、Q11（物理地址）、
Q15/Q16（奇偶存储体与对齐）。

## 第 2 步　第3讲 指令（真题 15 题）

重点不是「认指令」，是**指令的约束条件**。真题连考 3 题非法指令，说明
「知道什么不能写」比「知道什么能写」更重要。把下表的坑逐条搞懂为什么非法。

自测：第3讲 15 题全做，重点 Q6/Q7/Q8（三道非法指令）、Q10（CF 来源）、
Q14（寻址方式分类）、Q15（XLAT）。

## 第 3 步　第4讲 汇编程序（真题 4 题，全编程）

**分水岭。** 前两步是「看懂」，这一步开始「写出」。四个程序对应四个机制：
循环、分支、查表、DOS 调用。**每个都要能在白纸上默写。**

自测：遮住参考代码，重写四个程序。

## 第 4 步　第5讲 译码（真题 2 题）

题最少但不能跳。搞懂「外设在 CPU 眼里就是几个地址」，后面五颗芯片全建立在这上面。

自测：第5讲 2 题；再自己算一遍「8255 基地址 80H 接 8086 / 8088 分别是哪些口」。

## 第 5 步　第6～10讲 五颗芯片（真题 39 题，含 13 道编程题）

每颗芯片都是同一个套路，只是参数不同：

```
① 算端口地址（8086 要 +2）
② 写控制字（告诉芯片用什么方式）
③ 写初值 / 数据
④ 读状态字、查询就绪
⑤ 读写数据
⑥ （8259 特有）中断服务程序结束前发 EOI
```

建议按此顺序（先易后难，且后讲的会用到先讲的）：

**8255 → 8253 → 8251 → 8259 → DAC/ADC**

自测：每讲真题全做；编程题遮住参考代码重写。

# 四、真题反复埋的坑

每条都标了真题出处，可回原题核对。

| # | 陷阱 | 真题出处 |
|---|---|---|
| 1 | `PUSH AL` 非法——8086 栈操作只认 16 位字 | 第3讲 Q6A |
| 2 | `SBB AL,259`、`ADC BL,-255` 非法——8 位寄存器立即数超范围 | 第3讲 Q6D、Q7D |
| 3 | `IN AL,100H` 非法、`OUT 300H,AL` 非法——端口立即数 > FFH 必须经 DX | 第3讲 Q6B、Q8D |
| 4 | `OUT 0F2H,AX` 却合法——同一规则的反面：端口号 ≤ FFH 才能用立即数 | 第3讲 Q7A |
| 5 | `MOV [DI],[SI]` 非法——两个操作数不能同时为内存 | 第3讲 Q6C |
| 6 | `MOV AL,[BX][BP]` 非法——两个基址寄存器不能搭配 | 第3讲 Q7C |
| 7 | `MOV 12H,AL` 非法——立即数不能作目的操作数 | 第3讲 Q8A |
| 8 | 十六进制字母开头必须补 0：`0F1H` 合法，`FFH` 要写 `0FFH` | 第1讲 Q3 |
| 9 | `OR AL,40H` 不是检测位——会破坏 AL，检测要用 TEST | 第3讲 Q11 |
| 10 | MOV/PUSH/POP/XCHG 完全不影响标志；CMP 只影响标志、不改操作数 | 第3讲 Q10A |
| 11 | BCD 计数 1 字节最大 99、2 字节最大 9999（不是 100 / 10000） | 第7讲练习 Q2/Q3 |
| 12 | 8255 接 8086 端口地址 +2、接 8088 连续——差一字节全盘皆错 | 第8讲练习 Q1/Q3 |
| 13 | 中断向量表低字存 IP、高字存 CS——顺序反了地址就错 | 第6讲 Q1/Q4 |
| 14 | ICW2 只写高 5 位：响应时发出 3BH，则 ICW2 = 38H | 第6讲练习 Q5 |

> 第 14 条是本课程高频错题记录中唯一丢分的点（课堂练习 8259 Q5，丢 20 分），
> 说明这条坑的隐蔽性——详见 `../作业/review-汇编作业总览.md` 中该题明细。

# 五、五类必须默写的骨架

上表「需要写汇编代码的题」抽象出的全部内容。考试不给你参考代码，所以这五段必须
写到条件反射。每段标注了它对应哪些真题。

## 骨架 A：DOS 功能调用（第4讲 全部 4 题）

```asm
MOV AH, 01H / INT 21H   ; 键入一个字符 → AL
MOV AH, 02H / INT 21H   ; 显示 DL 中的字符
MOV AH, 09H / INT 21H   ; 显示 DS:DX 指向的 '$' 结尾字符串
MOV AH, 4CH / INT 21H   ; 返回 DOS
MOV AH, 25H / INT 21H   ; 设置中断向量：AL=类型号，DS:DX=入口
```

## 骨架 B：循环查表 / 统计（第4讲 Q1/Q2/Q4）

```asm
        MOV CX, 计数
        MOV BX, OFFSET 表
LOOP1:
        CMP BYTE PTR [BX], 0     ; 或 SUB AL,30H + XLAT
        JG  / JE / JL  分支
        INC BYTE PTR [结果单元]
        INC BX
        LOOP LOOP1
```

## 骨架 C：可编程芯片初始化四步（第5～10讲 通用）

```asm
        MOV DX, 控制口地址
        MOV AL, 控制字          ; 通道 + 读写法则 + 工作方式 + 数制
        OUT DX, AL
        MOV DX, 数据口地址
        MOV AL, 初值低字节
        OUT DX, AL
        MOV AL, 初值高字节      ; RL=11 时才写
        OUT DX, AL
```

对应真题：第8讲 Q1（PC6 正脉冲）、Q2（开关驱动 LED）；
第7讲 Q1（级联定时）、Q2（1kHz 方波 + 500Hz 负脉冲）；
第9讲 Q1（同步命令字）、Q2（同步初始化排序）、Q3（双机通信）。

## 骨架 D：查询式收发（第8讲 Q2、第9讲 Q3）

```asm
; 发送
NEXT_T: IN  AL, DX
        TEST AL, 01H            ; TxRDY
        JZ  NEXT_T
        MOV DX, 数据口
        MOV AL, [源]
        OUT DX, AL
; 接收：先查错，再查就绪
NEXT_R: IN  AL, DX
        TEST AL, 38H            ; 错误位
        JNZ ERROR
        TEST AL, 02H            ; RxRDY
        JZ  NEXT_R
        MOV DX, 数据口
        IN  AL, DX
        MOV [目的], AL
```

## 骨架 E：中断（第6讲 Q5/Q6）

```asm
; 设向量（直接法）
        MOV AX, 0000H
        MOV DS, AX
        MOV SI, 类型号*4
        MOV AX, OFFSET ISR
        MOV [SI], AX            ; 低字 = IP
        MOV AX, SEG ISR
        MOV [SI+2], AX          ; 高字 = CS
; 8259 初始化：ICW1 → ICW2 → ICW3(级联时) → ICW4
; 服务程序末尾必须发 EOI
        MOV AL, 20H
        OUT 20H, AL             ; 普通 EOI
```
