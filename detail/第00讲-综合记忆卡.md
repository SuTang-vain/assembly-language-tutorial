## 163. 必背表 A：DOS INT 21H 七项（试卷不附！）

**层级** 必背·试卷不附 ｜ **来源** `师+章+题` ｜ **正文** §11.1 ｜ **详见** [第04讲条目 108~114](第04讲-汇编程序与DOS调用.md)

### ① 机理详解

**主文档 §11.1 原表**（逐格保留）：

| AH | 功能 | 入口 | 出口 |
|---|---|---|---|
| **01H** | 键入一字符并回显 | — | **AL** |
| **02H** | 显示一字符 | **DL** | — |
| **09H** | 显示 '$' 串 | **DS:DX** | — |
| **0AH** | 缓冲输入一行 | **DS:DX** | 缓冲区 |
| **25H** | 设置中断向量 | **DS:DX**、AL=类型号 | — |
| **35H** | 读取中断向量 | AL=类型号 | **ES:BX** |
| **4CH** | 返回 DOS | AL=返回码 | — |

**为什么必背**：老师 p47 明确「试卷**不附** DOS INT 21H 功能调用表」，
即考试时要凭空写出功能号 + 入口 + 出口。这七项是**全课程唯一「必须整表默写」的内容**。

**三条记忆主线**：

```
① 方向记忆：读用 A（出口 AL/ES:BX），写用 D（入口 DL/DS:DX）
   01H → AL（读）          02H → DL（写）
   35H → ES:BX（读）       25H ← DS:DX（写）

② 中断向量一对：25H 写 / 35H 读，功能号差 10H
   写：DS:DX = 入口、AL = 类型号
   读：AL = 类型号 → ES:BX = 入口

③ 串的三件套：09H 显示（'$' 结尾）、0AH 输入（缓冲区三段）、
   单字符用 01H（读）/ 02H（写）
```

### ② 例题

只用本表，写一段「提示请输入 → 读一个字符 → 显示它 → 返回 DOS」。

```asm
DATA    SEGMENT
MESS    DB 'PLEASE INPUT: $'
DATA    ENDS
CODE    SEGMENT
        ASSUME CS:CODE, DS:DATA
START:  MOV AX, DATA
        MOV DS, AX

        LEA DX, MESS         ; 09H：入口 DS:DX
        MOV AH, 09H
        INT 21H

        MOV AH, 01H          ; 01H：出口 AL
        INT 21H              ; AL = 键入字符

        MOV DL, AL           ; 02H：入口 DL
        MOV AH, 02H
        INT 21H

        MOV AH, 4CH          ; 4CH：返回 DOS
        INT 21H
CODE    ENDS
        END START
```

**四行功能号全部出自上表**，无一项需要表外知识。

### ③ 易错提示

- **01H 出口是 AL、02H 入口是 DL**——读写方向最易混（第04讲条目 108/109）。
- **25H 用 DS:DX、35H 用 ES:BX**——寄存器组合易混（第06讲条目 80/81）。
- **AH 每次用前都要重设**：`INT 21H` 会破坏 AH。
- **0AH 缓冲区三段口径**：最大数（含回车、不为 0）/ 实际数（不含回车）/ 字符 + 0DH。
- 漏 **4CH** 程序不停——每道程序题都要检查结尾。

### ④ 横向辨析

| 功能 | 入口 | 出口 | 对应讲次详解 |
|---|---|---|---|
| 01H | — | **AL** | 第04讲 条目 108 |
| 02H | **DL** | — | 第04讲 条目 109 |
| 09H | **DS:DX** | — | 第04讲 条目 110 |
| 0AH | **DS:DX** | 缓冲区 | 第04讲 条目 111 |
| 25H | **DS:DX + AL** | — | 第06讲 条目 81 |
| 35H | **AL** | **ES:BX** | 第06讲 条目 80 |
| 4CH | AL=返回码 | — | 第04讲 条目 114 |

## 164. 必背表 B：8259 命令字（试卷不附！）

**层级** 必背·试卷不附 ｜ **来源** `师+章+题` ｜ **正文** §11.2 ｜ **详见** [第06讲条目 85~95](第06讲-8259A与中断系统.md)

### ① 机理详解

**主文档 §11.2 原表**（逐格保留）：

| 字 | 端口（20H/21H 体系） | 关键内容 |
|---|---|---|
| **ICW1** | **偶 20H** | 初始化启动（**D4=1**）；边沿/电平、单片/级联、要不要 ICW4 |
| **ICW2** | 奇 21H | **类型码高 5 位**（3BH→38H） |
| **ICW3** | 奇 21H | **仅级联**：主片=级联位图（IR2→00000100B）；从片=标识（IR2→00000010B） |
| **ICW4** | 奇 21H | **µPM=1**(8086)、全嵌套/特殊嵌套、AEOI |
| **OCW1** | **奇 21H** | 屏蔽字（**1=屏蔽**） |
| **OCW2** | **偶 20H** | **EOI=20H** |
| **OCW3** | 偶 20H | 读 IRR/ISR（**0AH=读 IRR**）、查询方式 |

**主文档 §11.2 配套流程原文**：

> 初始化 `ICW1→ICW2→(ICW3)→ICW4`；服务程序结束**前**发 EOI；返回用 IRET；主程序 STI。

**为什么必背**：老师 p47 明确「试卷**不附** 8259 寄存器资料」。
8259 的 7 个命令字 + 端口 + 极性，是除 DOS 表外第二块「整表默写」内容。

**奇偶口记忆法**：

```
偶地址 20H：ICW1、OCW2、OCW3        （3 个）
奇地址 21H：ICW2、ICW3、ICW4、OCW1  （4 个）
```

**三条极性铁律**（最易错）：

```
① ICW2 是「类型码高 5 位」→ 低 3 位必须为 0（是 8 的倍数）
② OCW1 是「1 = 屏蔽」（与 8255A 的 INTE 1=允许**相反**）
③ EOI = 20H 写偶口（不是 21H）
```

### ② 例题

只用本表，完成「8259 单片初始化（类型号 08H~0FH，8086 模式）+ 允许 IR0/IR1 + EOI」。

```asm
        MOV AL, 13H          ; ICW1：偶口，D4=1、边沿、单片、要 ICW4
        OUT 20H, AL
        MOV AL, 08H          ; ICW2：奇口，高 5 位 00001 → 08H~0FH
        OUT 21H, AL
        MOV AL, 01H          ; ICW4：奇口，µPM=1（8086）
        OUT 21H, AL
        MOV AL, 0FCH         ; OCW1：奇口，只允许 IR0/IR1（这两位写 0）
        OUT 21H, AL
        ; …服务程序结束前…
        MOV AL, 20H          ; OCW2：偶口，普通 EOI
        OUT 20H, AL
```

**七个命令字的口与值全部出自上表**。ICW3 未出现——因为 ICW1 的 SNGL=1 声明单片。

### ③ 易错提示

- **ICW2 高 5 位要左移 3 位**：3BH → 38H（我在课堂练习答 07H 丢 20 分，第06讲条目 87）。
- **OCW1 写奇口、OCW2 写偶口**：写反了命令不生效且无报错。
- **单片不写 ICW3**：写了会让后续 ICW4 被当成 ICW3，全错位（实验十三踩过）。
- **EOI 在服务程序结束前发**，不是结束后（第06讲条目 95）。
- **查询方式也要发 EOI**：查询命令会把 ISR 对应位置 1。

### ④ 横向辨析

| | 8259A 命令字 | 8255A 控制字 | 8251A 三字 |
|---|---|---|---|
| 口选择 | **A0**（奇/偶） | **A1A0**（11 = 控制口） | **C/D** |
| 同口多寄存器 | 靠**顺序**（ICW 序列） | 靠 **D7** 区分 | 靠**顺序 + 读写方向** |
| 是否受 CPU 位数影响 | **否** | **是**（8086 间隔 2） | 是 |
| 关键极性坑 | **IMR 1=屏蔽** | **方向位 1=输入** | 同步用 95H、异步用 15H |

## 165. 必背数字表

**层级** 必背 ｜ **来源** `师+章+题+网` ｜ **正文** §11.3

### ① 机理详解

**主文档 §11.3 原表**（逐格保留，共 18 项）：

| 数字 | 内容 |
|---|---|
| **×4** | 中断向量表项 = 类型码×4；表区 00000H~003FFH（1KB、256 项） |
| **FLAGS→CS→IP** | 中断压栈顺序（IRET 弹三字）；CALL 只压 CS,IP（RET 弹之） |
| **SP±2** | PUSH −2 / POP +2；堆栈容量 = SS:SP 的 SP 值 |
| **×16** | 物理地址 = 段址×16 + 偏移（左移一位） |
| **20/16、20/8** | 8086 地址线/数据线；8088 地址线/数据线 |
| **6/4** | 指令队列 8086 = 6 字节、8088 = 4 字节 |
| **1MB / 64KB** | 内存独立寻址 / I/O 独立寻址 |
| **3片/2片** | 74LS373（锁存 21 位地址）3 片、74LS245（缓冲 16 位数据）2 片 |
| **15/22/64** | 8259 级联 2/3/9 片的优先级数（一主八从 64 级） |
| **65536 / 10000** | 8253 二进制/BCD 最大计数（写 0）；BCD 单字节 99、双字节 9999 |
| **0/2/3 方式** | 8253 软件启动 0/2/3/4、硬件 1/5；周期性只有 2/3 |
| **5MHz** | 8253 最高计数频率；8086 主频 4.77MHz（T≈200ns） |
| **100μs** | ADC0809 转换时间；时钟 ~640kHz |
| **±1/2 LSB** | 量化误差；1 LSB = VREF/2ⁿ |
| **20ms** | 按键防抖 DELAY_20MS（实验口径） |
| **41H/61H/31H/30H** | 'A'/'a'/'1'/'0' 的 ASCII；大小写差 20H；'$'=24H；CR=0DH、LF=0AH |
| **2 字节** | XOR AX,AX（vs MOV AX,0 的 3 字节） |
| **±128** | 条件转移短转移范围 |

> 主文档原文此行写作「100μs? 20ms」，问号是草稿痕迹；按内容应为 **20ms（按键防抖）**，
> 与上一行 ADC0809 的 100μs 是两回事，勿混。

**按「乘法因子」分三组记忆**：

```
① ×4   中断向量表（类型码 → 首地址）
② ×16  物理地址（段址 → 段基址）
③ ×2   PUSH/POP 的 SP 变化（±2 字节）
```

**按「芯片」分五组记忆**：

```
8086/8088：20/16、20/8、6/4、1MB/64KB、3片/2片、4.77MHz
8259：     ×4、FLAGS→CS→IP、15/22/64、±128（条件转移）
8253：     65536/10000、99/9999、0/2/3 方式、5MHz
ADC0809：  100μs、±1/2 LSB
汇编/DOS： 41H/61H/31H/30H、2 字节（XOR）
```

### ② 例题

连用本表三个数字，算「INT 16H 的向量在内存哪四个字节」：

```
① ×4（向量表）   ：16H × 4 = 58H     ← 十六进制乘法，不是 64H
② 表区 00000H 起 ：首地址 = 00058H
③ 每项 4 字节    ：占 00058H ~ 0005BH

答：00058H、00059H、0005AH、0005BH
（内容按小端：低字 IP 在 58H/59H，高字 CS 在 5AH/5BH）
```

### ③ 易错提示

- **16H×4 = 58H 不是 64H**（老师 p48 易错清单第 2 条，本课程第一大计算坑）。
- **59H+1 = 5AH 不是 60H**（十六进制加法惯性，第 3 条）。
- **堆栈容量 = SP 值**，不是 SP×2、不是 64KB。
- **373 是 3 片不是 2 片**（21 位 ÷ 8 向上取整）。
- **8088 数据线 8 根**（老师样题问 8088，别顺口答 16）。
- **±1/2 LSB 是 ADC 的量化误差**，DAC 的满量程误差是 ~±1 LSB，别混。

| 数字 | 属谁 | 详解链接 |
|---|---|---|
| ×4、FLAGS→CS→IP、15/22/64 | 8259 / 中断 | 第06讲 条目 71/77/83 |
| ×16、20/16、6/4、1MB/64KB、3片/2片 | 8086/8088 | 第02讲 条目 139/141/153 |

## 166. 控制字参考值速查（格式看附图，值要会算）

**层级** 必背 ｜ **来源** `师+章+题+网` ｜ **正文** §11.4

### ① 机理详解

**主文档 §11.4 原文**（四条 bullet 逐条保留）：

> - **8255**：全输入 **9BH** / 全输出 **80H** / PA出PB入 **82H** / **PA入PB出 90H**；
>   BSR：PCi 置 1 = `0000 0iii1`、清 0 = `0000 0iii0`（iii = 位号）
> - **8253**：CNT0 方式3 先低后高二进制 **36H**；CNT1 方式2 **74H**；CNT2 方式3 **B6H**
> - **8251**：异步 8N1×16 方式字 **4EH**；命令「允许收发+清错」**15H**；
>   内部复位 **40H**；状态字测 TxRDY=**01H**、RxRDY=**02H**、错误掩码 **38H**
> - **8259**：单片经典 ICW1=**13H**、ICW2=**08H**、ICW4=**01H**；EOI=**20H**；
>   屏蔽字按位「0 允 1 屏」

| 芯片 | 控制字/命令字 | 值 | 备注 |

| | 方式字·**PA 入 PB 出** | **90H** | **最常用** |
| | BSR·PCi 置 1 | `0000 0iii1` | iii = 位号 |
| | BSR·PCi 清 0 | `0000 0iii0` | 一次只能一位 |
| **8253** | CNT0 方式3 先低后高（二进制） | **36H** | BCD 版 **37H** |

| | CNT2 方式3 先低后高（二进制） | **B6H** | BCD 版 **B7H** |

| | ICW2·PC 机主片 | **08H** | 3BH → **38H** |
| | ICW4·8086 模式 | **01H** | µPM=1 |
| | OCW2·普通 EOI | **20H** | 写偶口 |

**BCD 与二进制只差 D0**：36H↔37H、74H↔75H、B6H↔B7H。
作业第7讲两题都用 **BCD**（37H/75H），别把主文档的二进制答案直接套

### ② 例题

只用本表，写出「8255 基址 80H 接 8086，PC6 发一个正脉冲」的控制口与两个 BSR 值。

```
① 基址 80H 接 8086 → 端口间隔 2 → 控制口 = 86H
   （来自第08讲条目 37，不属本表；本表只给 BSR 值）

② PC6 → 位号 iii = 110
   置 1（高）= 0000 1101B = 0DH
   清 0（低）= 0000 1100B = 0CH

③ 正脉冲序列：0CH → 0DH → 0CH
   （作业第8讲 Q1 标准答案：第一空 86H、第二空 0DH）
```

### ③ 易错提示

- **「格式看附图，值要会算」**：老师 p47 说 8255/8253/8251 的**格式图会附**，
  但**具体值要自己算**——所以表要熟，推导更要会。
- **BCD 与二进制只差 D0**：作业第7讲两题是 BCD（37H/75H）。
- **8251 同步用 95H 不是 15H**：差 D7（EH）。
- **8259 的 ICW2=38H 与 8251 的方式字 38H 数值巧合**，含义完全不同（第09讲条目 27）。
- **8255 的 90H 与 91H 只差 D0**（PC 低 4 位方向），作业 Q2 的干扰项。

## 167. 易错 20 条（老师 p48 ＋ 三源合并，考前最后一遍）

**层级** 必背 ｜ **来源** `师+章+题+网` ｜ **正文** §11.5

### ① 机理详解

**主文档 §11.5 的 20 条原文**（逐条保留）：

```
 1. 数字结尾 B/H 不可省（01001010B、21H）；字母开头补 0（0FFH、0F2H）
 2. 16H×4=58H（≠64H）；INT 16H 向量在 00058H~0005BH
 3. 十六进制加法：59H+1=5AH（≠60H）
 4. 物理地址写完整（1234H:5678H 或 179B8H），不能只写 1234H
 5. ADD AL,256 非法（超 8 位立即数）；PUSH AL 非法（只能压字）
 6. IN AL,100H 非法（100H=256>FFH 须 DX）；OUT 300H,AL 同；
    但 OUT 0F2H,AX 合法（0F2H=242≤FFH）
 7. MOV DS,段名 非法（经 AX）；CS 不能作目的；两内存操作数非法
 8. INC/DEC 不影响 CF；NOT 完全不影响标志；MOV 类不影响标志
 9. SAL≡SHL；SAR≠SHR（符号位）；次数>1 用 CL
10. "OR 检测位"错——检测用 TEST/AND
11. 中断压栈 FLAGS→CS→IP；服务程序必须 EOI+IRET（缺 EOI 下次中断进不来）
12. ICW2 高 5 位（3BH→38H）；IMR 1=屏蔽；OCW1 奇口、OCW2 偶口
13. 向量项低字 IP、高字 CS（小端）
14. 8255 端口：8086 间隔 2（80/82/84/86H）、8088 连续（80/81/82/83H）
15. 8255 方向位 1=输入；BSR 一次一位、写控制口；方式 2 仅 A 口
16. 8253 先低后高写初值；初值 0=最大计数；周期性只有方式 2/3
17. 8251 初始化：3×00H→40H→方式字→（同步字符）→命令字；状态 38H=三错误
18. ADC0809：EOC 转换中低/结束高；通道要 ALE 锁存；OE 才能读数
19. DAC0832 电流输出要接运放；双缓冲=多路同步
20. 8253 级联输出频率=两级分频之积；超 65536 必级联
```

**按「失分概率」分三档**（考前时间不够就按这个顺序看）：

```
第一梯队（老师原话点名 + 我丢过分）：
  2（16H×4）  3（59H+1）  5（立即数/压字）  12（ICW2 高5位）
  → 第 12 条我在课堂练习 8259 答 07H，丢 20 分

第二梯队（作业反复考）：
  6（端口范围）  7（MOV 禁令）  8（标志）  10（OR 检测位）
  14（8255 地址）  16（8253 初值）  17（8251 初始化）

第三梯队（记住就得分）：
  1（B/H 后缀）  4（地址写法）  9（移位）  11（EOI+IRET）
  13（小端）  15（BSR）  18（EOC）  19（DAC 运放）  20（级联）
```

### ② 例题

> 8088 系统，8253 基址 40H，CLK1 接 5MHz，要求 LED 亮 4 秒灭 4 秒。

```
用到的易错条：
· 第 3 条（十六进制加法）→ 40H 连续：CNT1=41H、CNT2=42H、控制口=43H
· 第 16 条（初值 0 = 最大计数）→ N1 = 10000 写 0000H
· 第 20 条（级联 = 两级之积）→ N1×N2 = 10000×4000 = 4×10⁷
```

### ③ 易错提示

### ③ 易错提示

### ② 例题

自测第 6 项「8253：控制字会算（36H/74H/B6H）」：

```
CNT0 方式 3 先低后高二进制：
  D7D6 = 00（CNT0）
  D5D4 = 11（先低后高）
  D3~D1 = 011（方式 3）
  D0 = 0（二进制）
  → 00 11 011 0 = 0011 0110B = 36H ✔

CNT1 方式 2：D7D6 = 01、D3~D1 = 010
  → 01 11 010 0 = 0111 0100B = 74H ✔

CNT2 方式 3：D7D6 = 10、D3~D1 = 011
  → 10 11 011 0 = 1011 0110B = B6H ✔
```

三个全部推出 → 第 6 项可打勾。
