# 第07讲 可编程计数/定时芯片 8253 · 逐考点详解

## 本讲是什么 & 关键考点

**先从一个问题说起**：怎么让计算机「等一会儿」，或者「数个数」？

最笨的办法是**软件定时**——让 CPU 跑一段空循环：

```asm
MOV DX, 0FFFFH        ; 延时常数
AGAIN: MOV CX, DX
WAIT1: NOP
       LOOP WAIT1     ; 空转
       DEC DX
       JNZ AGAIN
```

这能延时，但有三个硬伤：**占用 CPU**（延时时啥也干不了）、**不精确**（换个频率的
CPU 时间就不准）、**不通用**（换个机器要重算常数）。

**8253 就是为解决这个问题而生的硬件**：把「数数」这件事外包给一颗专门的芯片，
CPU 设好初值就撒手，数完了芯片自己发信号。**定时的本质是计数**——CLK 接固定频率的
时钟脉冲，数够 N 个就是过了 N 个周期；CLK 接外部随机事件，数够 N 次就是发生了 N 次。

**它内部是怎么做的？** 每个计数通道里是三个接力的小寄存器，数据这样流动：

```
 CPU 写入 ──► 初值寄存器 ──► 减1计数器 ──► 输出锁存器 ──► CPU 读出
              （可读写，      （不可访问，    （只读，锁存
               计数中不变，    真正减1的地方）  那一刻的值）
               用于自动重装）
                     ▲              │ 减1
                     │              ▼
              CLK 脉冲 ── GATE 门控（开关）──► OUT 输出波形
```

- **初值寄存器**记住你装的数，计数过程中**不变**——所以方式 2/3 减到 0 能**自动重装**，
  重新开始；
- **减1计数器**是真正干活的地方，但它 **CPU 读不到**；
- 所以又配了一个**输出锁存器**——你想看当前值，先发锁存命令让它「咔」地把那一刻的值
  锁存下来，CPU 再读。

**为什么要有三个独立通道？** 因为可以同时干三件事：一个产生方波、一个对外计数、
一个做延时，互不干扰。

**关键考点**： 「六种工作方式」和「编程」为「掌握」级——也就是说，
试卷很可能让你**写初始化代码**：选方式、算初值、按「控制字→低字节→高字节」的顺序写。
本讲的全部考点，都是围绕「会用」展开的。

## 53. 结构：3 个独立 16 位减 1 计数器，各配 CLK/GATE/OUT；控制字寄存器只写；最高 5MHz

**层级** 了解+掌握地址 ｜ **来源** `章+网` ｜ **正文** §4.1

> 💡 **一句话**：每个计数通道里是三个接力的寄存器——初值寄存器（CPU 装数，不变）、
> 减1计数器（真正干活，CPU 读不到）、输出锁存器（供 CPU 读那一刻的值）。
> 三者缺一不可，后面讲的所有「为什么」都从这里长出来。

### ① 机理详解

先看数据怎么在通道里流动，再看三个寄存器为什么都必须存在：

```
 CPU 写入 ──► 初值寄存器 ──► 减1计数器 ──► 输出锁存器 ──► CPU 读出
              （可读写）      （不可访问）    （只读）
                                    │
               CLK 脉冲 ── GATE 门控 ──► OUT 输出波形
```

- **初值寄存器**：存放 CPU 写入的初值，计数过程中**内容不变**。这就是为什么方式 2/3
  减到 0 后能**自动重装**——初值还在原地，装回去就能再来一轮。
- **减1计数器**：真正执行减 1 的地方，但 **CPU 无法直接访问**。它只在内部跳动。
- **输出锁存器**：因为减1计数器读不到，所以要靠它——CPU 想看当前值，先发锁存命令，
  锁存器「锁存」那一刻的值，CPU 再读。

8253 内部是**三个完全独立的 16 位减 1 计数通道**，各配三根外部引脚：

```
              ┌──────────────────────────────┐
   CLK0 ─────►│  CNT0：初值寄存器             │
   GATE0 ────►│        ↓                      │───► OUT0
              │     计数执行单元（16 位减 1）   │
              │        ↓                      │
              │     输出锁存器                 │
              └──────────────────────────────┘
   CLK1 ─────►   CNT1 …                        ───► OUT1
   GATE1 ────►                                   ───►
              ┌──────────────────────────────┐
   CLK2 ─────►│  CNT2 …                       │───► OUT2
   GATE2 ────►└──────────────────────────────┘
              
   A1A0 = 11 ─► 控制字寄存器（只写，无对应数据口）
```

各部分的职责：

| 引脚/部件 | 作用 |
|---|---|
| **CLK** | 计数/定时脉冲输入，每个下降沿使计数值减 1 |
| **GATE** | 门控输入，控制是否允许计数 |
| **OUT** | 输出信号，波形由工作方式决定 |
| **初值寄存器** | 保存写入的初值，用于方式 2/3 的自动重装 |
| **计数执行单元** | 真正执行减 1 的地方，**它的当前值才是可读的** |
| **输出锁存器** | 锁住某一时刻的计数值供 CPU 读（读之前要先发锁存命令） |
| **控制字寄存器** | **只写不读**，没有对应的 A1A0 数据口 |

关键参数：**最高计数频率 5MHz**（8253-5，课件口径）；
8254 为 10MHz。三个计数器**完全独立**，可分别设不同方式、不同初值、同时运行。

### ② 例题

8253 的「控制字寄存器」和「计数器口」有什么区别？CPU 能读控制字寄存器吗？

```
控制字寄存器（A1A0 = 11）：只写，用于设定工作方式、计数制、读写顺序、
                          选哪个计数器。写一次即生效，无需读回。
计数器口（A1A0 = 00/01/10）：可读可写。写 = 送初值；读 = 取当前计数值
                            （但必须先发锁存命令，见条目 69）。

→ CPU 不能读控制字寄存器（没有读操作定义），也不需要读——
  控制字由程序员自己决定，不存在「读回确认」的机制。
```

### ③ 易错提示

- **三个计数器是独立的**：可以 CNT0 方式 3、CNT1 方式 0、CNT2 方式 2 同时跑。
  别以为 8253 只能整片一种方式。
- **控制字寄存器只写**：看到「读控制口」的代码一定是错的。
- **最高频率 5MHz 是 8253-5 的口径**，若题目说 8254 则用 10MHz（条目 69）。
- 结构为了解级，但**端口地址是掌握级**（见条目 54）。

### ④ 横向辨析

| | 8253 | 8255A |
|---|---|---|
| A1A0=00/01/10 | **计数器 0/1/2** | **PA/PB/PC 口** |
| A1A0=11 | 控制字寄存器 | 控制口 |
| 三个「口」的性质 | **同质**（都是计数器） | **异质**（三种不同口） |
| 数据口可否读 | 可（先锁存） | 可（方式 0 输入不锁存） |

**8253 与 8255A 的 A1A0 编码完全相同**，但前三个口的含义不同。
这是最容易串的地方——记的时候按芯片分别记。

## 54. A1A0：00 CNT0 / 01 CNT1 / 10 CNT2 / 11 控制口

**层级** 掌握 ｜ **来源** `章+网` ｜ **作业题** 第7讲Q1 ｜ **正文** §4.1

### ① 机理详解

| A1 | A0 | 选中 | 读/写 |
|---|---|---|---|
| 0 | 0 | **计数器 0** | 写初值 / 读当前值 |
| 0 | 1 | **计数器 1** | 同上 |
| 1 | 0 | **计数器 2** | 同上 |
| 1 | 1 | **控制字寄存器** | **只写** |

端口地址同样受 CPU 数据线位数影响（与 8255A 同规律）：

| CPU | CNT0 | CNT1 | CNT2 | 控制口 |
|---|---|---|---|---|
| **8088**（基址 B） | B | B+1 | B+2 | B+3 |
| **8086**（基址 B） | B | B+2 | B+4 | B+6 |

### ② 例题

**作业第7讲 Q1**：8253 基地址 40H，与 **8088** 连接，求控制口与两个计数器口。

```
8088 → 连续：
  CNT0 = 40H, CNT1 = 41H, CNT2 = 42H, 控制口 = 43H

第一空（计数通道 1）= 41H   ← 选项 B
第三空（计数通道 2）= 42H   ← 选项 E

（标准答案的参考代码注释也印证：MOV DX, 43H 控制口地址）
```

**作业第7讲 Q2**：8253 基地址 300H，连接 **8086**：

```
8086 → 间隔 2：
  CNT0 = 300H, CNT1 = 302H, CNT2 = 304H, 控制口 = 306H

（标准答案参考代码：MOV DX, 306H 控制口地址；MOV DX, 300H 计数通道 0；
  MOV DX, 302H 计数通道 1）✓
```

### ③ 易错提示

- **先判 CPU 再定地址**：Q1 是 8088（连续，41H/42H/43H），
  Q2 是 8086（间隔 2，300H/302H/306H）。两题基址不同、CPU 不同，别互相套答案。
- **A1A0=10 是 CNT2 不是 CNT1**：二进制 10 = 2。
- **控制口只写**：不要试图 `IN AL, 306H`。
- 十六进制进位别错：40H+1=41H ✓，但 0FH+1=10H、59H+1=5AH。

### ④ 横向辨析

| 芯片 | 地址是否受 CPU 数据线位数影响 |
|---|---|
| **8253** | **是**（8088 连续 / 8086 间隔 2） |
| **8255A** | **是**（同上） |
| 8259A | 否（只用 A0 分奇偶口） |
| ADC0809 | 否（通道由 C/B/A 选，与 CPU 无关） |

**8253 与 8255A 是「同规律兄弟」**，8259A 是「只认奇偶」的例外。

## 55. 计数原理：倒计数；初值寄存器→计数执行单元→输出锁存器

**层级** 理解 ｜ **来源** `章+网` ｜ **正文** §4.2

### ① 机理详解

8253 是**倒计数（减法计数）**：写入初值 N 后，每来一个 CLK 脉冲计数值减 1，
减到 0 时 OUT 输出「结束信号」（具体波形由方式决定）。

三个寄存器各司其职：

```
① 初值寄存器  ← CPU 写入 N。方式 2/3 每轮结束会自动把 N 重新装进执行单元（自动重装）
                ↓
② 计数执行单元 ← 真正减 1 的地方。它的当前值 = 还能承受多少个 CLK
                ↓
③ 输出锁存器  ← 锁住某一瞬间执行单元的值，供 CPU 读。读之前必须先发「锁存命令」
```

**为什么需要锁存器**：计数执行单元的值在**持续变化**，CPU 读它的时候可能正跨在一次
减 1 中间，读到错值。锁存命令先把当前值「快照」进锁存器，CPU 再从锁存器读，
就稳定了（见条目 69）。

**方式 0 的 N+1 细节**（实验九的关键现象）：

```
写入初值 N 后，第 1 个 CLK 脉冲并不立即减 1，而是把 N 从初值寄存器装入执行单元；
从第 2 个脉冲才开始减 1。
→ 从写完初值到 OUT 变高，共需 N + 1 个 CLK。

实验九（N = 15）：写完初值到 OUT0 变高需 15 + 1 = 16 个单脉冲。
屏幕显示的当前值序列是 15 → 14 → … → 0（共 16 个状态）。
```

### ② 例题

实验九（JSQ.ASM）要求初值 N ≤ 0FH，取 N = 15。问按下多少次单脉冲后 OUT0 变高？

```
第 1 个脉冲：把 15 装入计数执行单元（不减 1）
第 2 个脉冲：15 → 14
第 3 个脉冲：14 → 13
…
第 16 个脉冲：1 → 0  → OUT0 变高并保持

共需 N + 1 = 15 + 1 = 16 次。
```

### ③ 易错提示

- **方式是「减 1」不是「加 1」**：初值 N 表示「还能承受 N 个脉冲」，不是「数到 N」。
- **方式 0 归零需 N+1 个脉冲**是本讲最重要的实验细节，
  主文档 §5.7 之外的实验二 README 专门记录了这一点。
- **读当前值必须先锁存**：直接 `IN` 在高频计数时不可靠。
- 方式 2/3 的自动重装靠**初值寄存器**保留 N——这是它们能周期输出的原因。

### ④ 横向辨析

| | 8253 计数执行单元 | 8251A 发送缓冲器 | ADC0809 SAR |
|---|---|---|---|
| 单位 | 计数（减 1） | 字节 | 位（逐次逼近） |
| 触发 | CLK 边沿 | CPU 写 | 时钟周期 |
| 当前值可读 | **可**（先锁存） | 不可直接读 | 转换完才可读 |

## 56. 计数制与最大初值：二进制 65536（写 0）/ BCD 10000；BCD 单字节 99、双字节 9999

**层级** 掌握 ｜ **来源** `章+题` ｜ **作业题** 练习8253Q2/Q3 ｜ **正文** §4.2

### ① 机理详解

计数制由控制字 **D0** 决定：**D0=0 二进制、D0=1 BCD**。

最大初值：

| 计数制 | 字节数 | 最大初值 | 怎么写 |
|---|---|---|---|
| **二进制** | 1 字节 | 255 | FFH |
| **二进制** | **2 字节** | **65536** | **写 0000H**（0 即最大） |
| **BCD** | 1 字节 | **99** | 99H |
| **BCD** | **2 字节** | **10000** | **写 0000H**（0 即最大） |

**为什么「写 0 = 最大」**：16 位全 0 就是 65536（二进制）或 10000（BCD）。
芯片内部把「初值 0」特判为「装入最大值」。这是一个省事的设计——
想用满量程就写 0，不用去算 65536 的表示（65536 在 16 位里本来就表示不了）。

**BCD 码的书写规则**：BCD 用 4 位表示一个十进制数字，所以

- 十进制 99 → BCD **99H**（1001 1001）
- 十进制 100 → BCD **0100H**（0000 0001 0000 0000，低字节 00H 高字节 01H）
- 十进制 2000 → BCD **2000H**（低字节 00H，高字节 20H）
- 十进制 4000 → BCD **4000H**（低字节 00H，高字节 40H）
- 十进制 10000 → BCD **0000H**（写 0）

**BCD 与二进制的数值差是高频陷阱**：十进制 26 在二进制是 1AH，在 BCD 是 26H。
写错制式，初值差一大截。

### ② 例题

**真题 1（课堂练习 8253 Q2）**：BCD 编码方式，计数初值（1 字节）最大可以是？

```
BCD 1 字节 = 2 个十进制数字 → 最大 99
正确答案：A（99）

干扰项 B = 100：100 在 BCD 1 字节里放不下（需要 3 个十进制数字 = 12 位）
```

**真题 2（课堂练习 8253 Q3）**：BCD 编码，计数初值（2 字节）最大可以是？

```
BCD 2 字节 = 4 个十进制数字 → 最大 9999
正确答案：C（9999）

干扰项 D = 10000：10000 需要 5 个十进制数字 = 20 位，放不下。
             但「初值写 0」时芯片按 10000 处理——这是特殊规定，不是「能表示 10000」。
```

**作业第7讲 Q1 的 BCD 初值**：需要 N1·N2 = 4×10⁷，取 N1 = 10000、N2 = 4000：

```
N1 = 10000（BCD，2 字节写 0）→ 低字节 00H，高字节 00H
   → 第二空 = 00H（选项 F）✓
N2 = 4000（BCD）→ 4000H → 低字节 00H，高字节 40H
   → 第四空 = 40H（选项 H）✓
```

### ③ 易错提示

- 本讲易错第 4 条（主文档 §4.7）：**「BCD 下初值按十进制写（1000 写 1000H 不是 03E8H）」**。
- **BCD 1 字节最大 99、2 字节最大 9999**——课堂练习连考两题，
  答案是 99 和 9999，**不是 100 和 10000**。
- **「写 0 = 最大」与「最大能表示多少」是两回事**：BCD 2 字节最大初值是 10000，
  但这是靠「写 0」实现的，不是靠编码表示。
- 作业第7讲两题都用了 **BCD**（控制字 D0=1），所以控制字是 37H/75H 而**不是**主文档
  的 36H/74H（那是二进制）。见条目 63 的专述。

### ④ 横向辨析

| | 二进制 | BCD |
|---|---|---|
| 4 位表示 | 0~15 | 一个十进制数字 0~9 |
| 1 字节最大 | 255（FFH） | **99**（99H） |
| 2 字节最大 | 65536（写 0） | **10000**（写 0） |
| 十进制 26 | 1AH | **26H** |
| 控制字 D0 | 0 | 1 |
| 优点 | 范围大 | 读数直观（屏幕直接显示十进制） |

**实验九用二进制**（10H，N=15 只写一字节）；**作业第7讲两题用 BCD**
（37H/75H，因为要求显示十进制计数值）。选哪种取决于「要不要直观显示」。

## 57. 初始化三步：写控制字 → 写初值（双字节先低后高）→ 写完即自动启动

**层级** 掌握 ｜ **来源** `章+题` ｜ **作业题** 第7讲Q1/Q2 ｜ **正文** §4.2

### ① 机理详解

8253 每个计数器的初始化固定三步：

```
① 写控制字     → 控制口（A1A0=11）：选计数器、定方式、定读写顺序、定制式
② 写计数初值   → 计数器口（A1A0=00/01/10）：
                 双字节时**先低后高**（先 OUT 低字节，再 OUT 高字节）
③ 启动         → **写完初值即自动开始**，不需要额外的启动命令
```

**第 ③ 步的「自动启动」是 8253 相对 8251A 的大便利**：8251A 要写命令字才允许收发，
8253 写完初值立刻跑。所以 8253 的初始化只有「两次 OUT」，
而 8251A 要「4~5 次 OUT」。

**双字节必须「先低后高」**：这是 8253 的硬规定。写反了会怎样？

```
设 N = 1000 = 03E8H
正确：先 OUT E8H（低），再 OUT 03H（高）→ 初值 = 03E8H = 1000 ✓
错误：先 OUT 03H，再 OUT E8H → 芯片把第一个字节当低字节、第二个当高字节
      → 初值 = E803H = 59395 ✗（完全不对）
```

**只写一个字节**（RL=01 只写低 / RL=10 只写高）：适合 N ≤ FFH 的场合，
如实验九 N=15，控制字 10H（D5D4=01 只写低 8 位），只需一次 `OUT`。

### ② 例题

实验十（DSQ.ASM）第一级：CNT0 方式 3，N = 1000，写出完整初始化。

```asm
        mov  dx, 283h        ; 控制口（CS 接 Y0，280H~287H）
        mov  al, 36h         ; 0011 0110B：CNT0、先低后高、方式3、二进制
        out  dx, al          ; ① 写控制字

        mov  dx, 280h        ; 计数器 0 数据口
        mov  ax, 1000        ; N = 1MHz / 1kHz = 1000 = 03E8H
        out  dx, al          ; ② 先写低字节 E8H
        mov  al, ah
        out  dx, al          ;    再写高字节 03H（顺序不能反）
                             ; ③ 写完即自动启动，OUT0 输出 1kHz 方波
```

**用 `MOV AX, 1000` + `OUT DX, AL` + `MOV AL, AH` + `OUT DX, AL` 是标准写法**：
一次取好 16 位值，先送 AL（低 8 位），再把 AH 移到 AL 送高 8 位。

### ③ 易错提示

- 本讲易错第 1 条（主文档 §4.7）：**「先低后高写反/只写一字节」**。
  看到控制字 D5D4=11 就必须写两次，漏一次初值就只有一半，频率差 256 倍。
- **只写一字节的场合**：RL=01（只低）或 RL=10（只高），且 N 确实能用一个字节表示。
  实验九 N=15 用 10H（RL=01）只写一次，这是对的——因为 15 < 256。
- **写完初值即启动**：不要再写别的「启动命令」（没有这个东西）。
- 控制字与初值**必须写对口**：控制字写控制口，初值写计数器口。
  两题作业都靠这个区分（Q1 第一空 41H 是计数器口，控制口是 43H）。

### ④ 横向辨析

| 芯片 | 初始化步数 | 是否需要额外「启动/使能」命令 |
|---|---|---|
| **8253** | **2 次 OUT**（控制字 + 初值） | **不需要**（写完即启动） |
| 8255A | **1 次 OUT**（控制字） | 不需要 |
| 8251A | 4~5 次 OUT | **需要**（命令字允许收发） |
| 8259A | 2~4 次 OUT | 需要（STI + OCW1 屏蔽字） |

**8253 与 8255A 是最简单的两个**（一个控制字搞定），
8251A 最麻烦（顺序敏感 + 要 REVTIME）。

## 58. 六种工作方式特征表（启动方式 / 输出特征 / 自动重装）

**层级** 掌握(0/2/3) ｜ **来源** `章+网+题` ｜ **作业题** 练习8253Q4/Q5 ｜ **正文** §4.3

### ① 机理详解

| 方式 | 名称 | 启动 | 输出特征 | 自动重装 |
|---|---|---|---|---|
| **0** | 计数结束中断 | **软件** | 计数中 OUT=低，**到 0 变高并保持** | 否 |
| **1** | 可编程单稳态 | **硬件（GATE↑）** | 单个负脉冲，宽度 = N 个 CLK | 可重触发 |
| **2** | 速率(分频)发生器 | **软件** | **周期性负脉冲**（每轮低 1 个 CLK） | **是** |
| **3** | 方波发生器 | **软件** | **连续方波** | **是** |
| **4** | 软件触发选通 | **软件** | 到 0 输出**1 个 CLK 宽负脉冲** | 否 |
| **5** | 硬件触发选通 | **硬件（GATE↑）** | 同 4，但由 GATE 触发 | 否 |

三种重点方式的波形：

```
方式 0（计数结束中断）：
  OUT: ─────┐                ┌──────────
            └────────────────┘
       写入初值        计到 0
       （变低）        （变高并保持）

方式 2（分频器，周期性负脉冲）：
  OUT: ───┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─
          └─┘ └─┘ └─┘ └─┘ └─┘
        ← N 个 CLK 一轮，每轮低 1 个 CLK →
        f_OUT = f_CLK / N

方式 3（方波发生器）：
  OUT: ──┐   ┌──┐   ┌──┐   ┌─
         └───┘   └───┘   └───┘
        ← N 个 CLK 一轮，高 N/2、低 N/2 →
        f_OUT = f_CLK / N，占空比约 50%
```

**方式 2 与方式 3 的输出频率公式相同**（都是 f_CLK/N），
区别只在**占空比**：方式 3 是 50% 方波，方式 2 是「每轮低一个时钟」的窄脉冲。
用逻辑笔测频率两者读数相同，但示波器看波形完全不同。

### ② 例题

**真题 1（课堂练习 8253 Q4）**：8253 有 6 种工作方式，其中能产生**连续方波**输出的
工作方式是？

```
正确答案：方式 3（选项 C）

依据：方式 3 = 方波发生器，自动重装，输出连续方波。
      方式 2 是「周期性负脉冲」，不是方波。
```

**真题 2（课堂练习 8253 Q5）**：能产生**周期性负脉冲**的工作方式是？

```
正确答案：方式 2（选项 C）

→ Q4 与 Q5 就是考「方式 2 vs 方式 3」这一对区别，答案正好互补。
   记牢：方波=3，周期负脉冲=2。
```

### ③ 易错提示

- **方式 2 与方式 3 的频率公式相同**（f_CLK/N），别以为方式 2 的频率是方式 3 的一半。
- **方式 1 是「硬件启动」，方式 4 是「软件启动」**，两者输出相同（1 个 CLK 宽负脉冲）、
  触发不同（本讲易错第 2 条）。
- **方式 0 到 0 后 OUT 变高并保持**，不是变成周期信号（因为没有自动重装）。
- 方式 0/2/3 为掌握级，但**方式 2/3 的区分是送分题**，必须拿下。

### ④ 横向辨析

| | 方式 0 | 方式 2 | 方式 3 |
|---|---|---|---|
| 自动重装 | 否 | **是** | **是** |
| 周期性 | 否 | 是 | 是 |
| 输出 | 到 0 变高保持 | 周期负脉冲 | 方波 |
| 典型用途 | 计数 N 个事件后通知 | 分频/波特率 | 方波/时钟 |
| 控制字（CNT0 二进制先低后高） | 10H/20H | 24H/34H | **36H** |
| 实验 | 实验九（JSQ.ASM） | — | 实验十（DSQ.ASM） |

## 59. 速记：软件启动 0/2/3/4、硬件启动 1/5；周期性（自动重装）只有 2 和 3

**层级** 掌握 ｜ **来源** `章+网+题` ｜ **作业题** 练习8253Q4/Q5 ｜ **正文** §4.3

### ① 机理详解

六种方式可以用两个维度一刀切：

```
                自动重装（周期性）
                ┌──────────┬──────────┐
   软件启动      │  方式 0  │ 方式 2   │
   （写初值）    │  方式 4  │ 方式 3   │
                ├──────────┼──────────┤
   硬件启动      │    —     │    —     │
   （GATE↑）     │  方式 5  │  方式 1  │
                └──────────┴──────────┘
```

两句速记：

1. **软件启动 0/2/3/4，硬件启动 1/5**
2. **周期性（自动重装）只有 2 和 3**

推导方式 1 的特殊性：方式 1 是「可编程单稳态」，像可重触发的单稳态触发器——
每次 GATE 上升沿重新开始一轮，输出一个宽度为 N 的负脉冲。
它确实会「重来」，但那是**外部重触发**，不是芯片自动重装初值。

### ② 例题

不查表回答：方式 5 的输出波形和方式 4 完全相同吗？触发方式有何不同？
哪些方式能产生连续周期信号？

```
① 输出波形：完全相同——都是「计到 0 时输出 1 个 CLK 宽的负脉冲」。
② 触发方式：方式 4 由**软件**触发（写初值即启动）；
             方式 5 由**硬件**触发（GATE 上升沿）。
③ 连续周期信号：只有**方式 2 和方式 3**（自动重装）。
   方式 0/4/5 都是一次性（方式 1 可重触发但不是自动周期）。
```

### ③ 易错提示

- 本讲易错第 2 条（主文档 §4.7）：**「方式 4（软件）与方式 5（硬件）输出相同、
  触发不同」**——选择题爱考。
- **别把方式 1 算进「周期性」**：方式 1 靠外部重触发，不是自动重装。
- 「软件启动」的确切含义是「**写入初值即启动计数**」，不是「用指令启动」。
- 记住「**周期只有 2 和 3**」这一句，就能答掉一半的方式题。

|---|---|---|---|---|---|---|
| 软件启动 | ✔ | ✘ | ✔ | ✔ | ✔ | ✘ |
| 硬件启动 | ✘ | ✔ | ✘ | ✘ | ✘ | ✔ |
| 自动重装 | ✘ | ✘ | **✔** | **✔** | ✘ | ✘ |

## 60. 方式 3 奇数初值：高电平 (N+1)/2、低电平 (N−1)/2 个 CLK

**层级** 理解 ｜ **来源** `网` ｜ **正文** §4.3

### ① 机理详解

方式 3 输出方波，理想情况高、低各占 N/2 个 CLK。但 **N 为奇数**时无法整除：

| N | 高电平 CLK 数 | 低电平 CLK 数 | 占空比 |
|---|---|---|---|
| 偶数 N | N/2 | N/2 | 严格 50% |
| **奇数 N** | **(N+1)/2** | **(N−1)/2** | 略大于 50% |

例如 N = 5：高 3 个 CLK、低 2 个 CLK → 高电平多一个时钟周期。
输出频率仍是 f_CLK/N（周期还是 N 个 CLK），只是不对称。

**为什么高电平多一个**：芯片内部实现是「减到 0 时翻转输出，并重装初值」。
奇数时重装的值与剩余计数的奇偶配合，导致高电平侧多一个 CLK。
这个细节只需记住结论，不必推导内部电路。

### ② 例题

8253 CNT0 方式 3，CLK = 1MHz，初值 N = 999（奇数）。求 OUT0 的频率、高低电平时间。

```
周期 T = N / f_CLK = 999 / 1MHz = 999 μs
频率 f = f_CLK / N = 1MHz / 999 ≈ 1001 Hz

高电平时间 = (N+1)/2 ÷ f_CLK = 500 / 1MHz = 500 μs
低电平时间 = (N−1)/2 ÷ f_CLK = 499 / 1MHz = 499 μs
总周期 = 999 μs ✓  高电平比低电平多 1 μs（1 个 CLK）
```

### ③ 易错提示

- **这是单一来源条目**（只有 `网` 源）。无明确要求，按「理解」准备，
  判断题可能考「方式 3 一定是 50% 占空比」→ **错**（奇数初值时不是）。
- **奇数初值不改变频率**，只改变占空比——别答成「频率减半」。
- 若题目要求严格 50% 占空比，必须选**偶数初值**。
- 与方式 2 的区别：方式 2 每轮低 1 个 CLK，占空比是 (N−1)/N，本来就不对称。

### ④ 横向辨析

| | 方式 3 偶数初值 | 方式 3 奇数初值 | 方式 2 |
|---|---|---|---|
| 占空比 | **严格 50%** | (N+1)/2 : (N−1)/2 | (N−1) : 1 |
| 频率 | f_CLK/N | f_CLK/N | f_CLK/N |
| 波形 | 方波 | 近似方波 | 窄负脉冲 |

## 61. 脉冲宽度对比：方式 1 = N 个 CLK；方式 4/5 = 1 个 CLK；方式 2 每 N 个 CLK 输出 1 CLK 宽负脉冲

**层级** 理解 ｜ **来源** `网` ｜ **正文** §4.3

### ① 机理详解

四种「一次性脉冲」的宽度对比，这是名校真题的高频点：

| 方式 | 触发 | 负脉冲宽度 | 说明 |
|---|---|---|---|
| **1** | GATE↑ | **N 个 CLK** | 单稳态，宽度由初值决定 |
| **4** | 软件 | **1 个 CLK** | 软件触发选通 |
| **5** | GATE↑ | **1 个 CLK** | 硬件触发选通 |
| **2** | 软件（周期） | 每 N 个 CLK 输出 **1 个 CLK** 宽 | 周期性 |

图示：

```
方式 1（宽度 = N 个 CLK）：
        ┌──────────────┐
   ─────┘              └──────
        ← N 个 CLK →

方式 4 / 5（宽度 = 1 个 CLK）：
        ┌─┐
   ─────┘ └──────────────
        ← 1 CLK →

方式 2（每 N 个 CLK 一个窄脉冲）：
        ┌─┐   ┌─┐   ┌─┐
   ─────┘ └───┘ └───┘ └────
        ← N → ← N →
```

**记忆法**：方式 1 是「**单稳态**」，脉冲宽度可编程（= N）；
方式 4/5 是「**选通**」，只输出一个时钟的窄脉冲（表示「数到了」）；
方式 2 是「**分频器**」，每 N 个来一个窄脉冲。

### ② 例题

CLK = 1MHz，分别用方式 1（N=100）、方式 4（N=100）、方式 2（N=100）。
求三种情况下 OUT 的负脉冲宽度和周期（方式 2）。

```
方式 1：宽度 = 100 个 CLK = 100 μs
        （一次性，无周期；GATE 再次上升沿可重触发）

方式 4：宽度 = 1 个 CLK = 1 μs
        （一次性；重新写初值才能再来一次）

方式 2：每轮 N = 100 个 CLK = 100 μs 来一个 1 μs 宽负脉冲
        周期 = 100 μs，频率 = 1MHz/100 = 10 kHz
        占空比 = 1/100 = 1%
```

### ③ 易错提示

- **这是单一来源条目**（只有 `网` 源）。无明确要求，按「理解」准备。
- **方式 1 的宽度是 N 个 CLK，不是 1 个**——这是它与方式 4/5 的核心区别。
- **方式 2 的周期是 N 个 CLK，脉冲只有 1 个 CLK 宽**——别把「宽度」和「周期」混。
- 若题目问「哪种方式的脉冲宽度可由初值控制」→ 只有**方式 1**。

### ④ 横向辨析

| 问法 | 答案 |
|---|---|
| 脉冲宽度 = N 个 CLK | **方式 1** |
| 脉冲宽度 = 1 个 CLK | **方式 4 / 方式 5** |
| 每 N 个 CLK 一个窄脉冲 | **方式 2** |
| 50% 占空比 | **方式 3**（偶数初值） |
| 到 0 变高并保持 | **方式 0** |

## 62. GATE 逐方式作用：0/2/3/4 为电平允许/禁止；1/5 为上升沿触发

**层级** 理解 ｜ **来源** `网` ｜ **正文** §4.3

### ① 机理详解

GATE 引脚的作用**随方式而变**，这是最易混的一处：

| 方式 | GATE 的作用 | 拉低 GATE | 拉高 GATE |
|---|---|---|---|
| **0** | **电平**允许/禁止 | 暂停计数 | 恢复计数 |
| **1** | **上升沿触发** | 无影响 | 重新开始一轮 |
| **2** | **电平**允许/禁止 | 暂停计数 | 恢复；**上升沿还会重装初值** |
| **3** | **电平**允许/禁止 | 暂停计数 | 恢复 |
| **4** | **电平**允许/禁止 | 暂停计数 | 恢复 |
| **5** | **上升沿触发** | 无影响 | 重新开始一轮 |

规律：

- **方式 1/5（硬件启动）**：GATE 是**边沿**触发，电平高低无所谓，上升沿才动作。
- **方式 0/2/3/4（软件启动）**：GATE 是**电平**门控，高电平允许计数、低电平禁止。
  方式 2 特殊：GATE 的上升沿还会**重装初值**（相当于重新启动）。

**实验接线印证**：实验九/十都把 **GATE0 ← +5V**，就是为了让它「常允许计数」，
免得暂停。如果 GATE 接地，计数器根本不动。

### ② 例题

实验九中 GATE0 接 +5V。若把 GATE0 接地，现象如何？若改用单脉冲接 GATE0 呢？

```
GATE0 接地（常低）：
  方式 0 下 GATE 是电平门控 → 计数被禁止 → 计数值不变，OUT0 保持低。
  屏幕显示值停在初值 15 不动。

GATE0 接单脉冲：
  方式 0 下 GATE 是电平门控（不是边沿）→ 脉冲高电平期间允许计数，
  低电平期间暂停。按下一次只会计几个，行为不可预期。
  → 单脉冲应该接 CLK0（每个下降沿计 1），GATE0 应接 +5V。
```

### ③ 易错提示

- 本讲易错第 5 条（主文档 §4.7）：**「GATE 在方式 1/5 是触发、在 0/2/3/4 是允许/禁止」**。
- **方式 2 的 GATE 上升沿会重装初值**——这是方式 2 独有的细节，
  可用于「随时重启分频器」。
- **实验里 GATE 接 +5V 不是可选的**：接了就动，不接不动。
- 别把 GATE 当「启动按钮」用在方式 0/2/3/4 上——那样只在电平为高时计数，
  不是「按一下启动一次」。

### ④ 横向辨析

| | GATE 为电平门控 | GATE 为边沿触发 |
|---|---|---|
| 方式 | **0、2、3、4** | **1、5** |
| 接地后果 | 禁止计数（暂停） | 无影响 |
| 接 +5V | 正常计数 | 正常（等待上升沿启动） |
| 接单脉冲 | 脉冲期间计数（不推荐） | 每按一次启动一轮 |

## 63. 控制字：D7D6 计数器、D5D4 读写方式、D3~D1 方式号、D0 制式；36H/74H/B6H

**层级** 掌握·考卷附图 ｜ **来源** `纲+章+题` ｜ **作业题** 第7讲Q1 ｜ **正文** §4.4

### ① 机理详解

控制字位布局（**考卷会附格式图，但值要会算**）：

```
 D7 D6 │ D5 D4 │ D3 D2 D1 │ D0
 计数器 │ 读写  │  方式号   │ 制式
```

| 位 | 取值 | 含义 |
|---|---|---|
| **D7D6** | 00 / 01 / 10 / 11 | 选 CNT0 / CNT1 / CNT2 / **非法（11 不用）** |
| **D5D4** | 00 | 锁存当前计数值（见条目 69） |
| | **01** | 只写/读**低 8 位** |
| | **10** | 只写/读**高 8 位** |
| | **11** | **先低后高**（16 位） |
| **D3D2D1** | 000~101 | 方式 0~5 |
| **D0** | 0 / 1 | 二进制 / **BCD** |

**四个经典控制字逐位验算**（均为二进制、先低后高）：

| 值 | 二进制 | D7D6 | D5D4 | D3D2D1 | D0 | 含义 |
|---|---|---|---|---|---|---|
| **36H** | 0011 0110 | 00 = CNT0 | 11 = 先低后高 | 011 = 方式 3 | 0 = 二进制 | CNT0 方式 3 方波 |
| **74H** | 0111 0100 | 01 = CNT1 | 11 = 先低后高 | 010 = 方式 2 | 0 = 二进制 | CNT1 方式 2 分频 |
| **B6H** | 1011 0110 | 10 = CNT2 | 11 = 先低后高 | 011 = 方式 3 | 0 = 二进制 | CNT2 方式 3 方波 |
| **10H** | 0001 0000 | 00 = CNT0 | 01 = 只写低 8 位 | 000 = 方式 0 | 0 = 二进制 | CNT0 方式 0，单字节初值 |

**推导 36H（CNT0 方式 3 二进制先低后高）**：

```
D7D6 = 00   CNT0
D5D4 = 11   先低后高
D3D2D1 = 011  方式 3
D0 = 0     二进制
→ 00 11 011 0 = 00110110B = 36H ✓
```

**推导 74H（CNT1 方式 2）**：

```
D7D6 = 01   CNT1
D5D4 = 11   先低后高
D3D2D1 = 010  方式 2
D0 = 0     二进制
→ 01 11 010 0 = 01110100B = 74H ✓
```

**推导 76H（CNT1 方式 3，实验十第二级）**：只把 74H 的方式位 010 改成 011：

```
→ 01 11 011 0 = 01110110B = 76H ✓
```

> **指导书的一处注释错误**：指导书 DSQ.ASM 把 76H 注释成「工作方式 2」，
> 但 76H 的 D3~D1 = 011 是**方式 3**；方式 2 应为 74H。实验二 README 已记录此修正。
> 本报告代码用 76H + 方式 3 的注释。

### ② 例题

**作业第7讲 Q1** 的两个控制字（均为 **BCD**，所以 D0 = 1）：

```
控制字 1：01110101B = 75H
  D7D6 = 01   → CNT1
  D5D4 = 11   → 先低后高
  D3D2D1 = 010 → 方式 2（分频，作第一级）
  D0 = 1      → BCD
  → 注释「设置为输入, 方式2, 负脉冲」✓

控制字 2：10110111B = B7H
  D7D6 = 10   → CNT2
  D5D4 = 11   → 先低后高
  D3D2D1 = 011 → 方式 3（方波，作第二级）
  D0 = 1      → BCD
  → 注释「设置为输出, 方式3, 方波」✓
```

**作业第7讲 Q2** 的两个控制字（同样 BCD）：

```
第一空：00110111B = 37H   → CNT0、先低后高、方式 3、BCD（1kHz 方波）
第四空：01110101B = 75H   → CNT1、先低后高、方式 2、BCD（500Hz 负脉冲）
```

> **37H 与 36H 只差 D0**：36H 是二进制，37H 是 BCD。
> 主文档 §4.4 列的 36H/74H 是**二进制**口径；作业两题都用 BCD，
> 所以是 37H/75H。**看 D0 是 0 还是 1**，这是最隐蔽的失分点。

### ③ 易错提示

- **D7D6 = 11 是非法组合**（不存在「控制字寄存器自己」这个计数器）。
- **D5D4 = 00 不是「不写初值」**，而是「锁存命令」（条目 69），
  后面要跟一次读操作。
- **BCD 与二进制只差 D0**：36H↔37H、74H↔75H、76H↔77H。
  作业两题都是 BCD，别把主文档的二进制答案直接套。
- **方式号在 D3D2D1 三位**，别漏算一位：方式 3 = 011，写成 11 就错位。
- 实验九 N=15 用 **10H**（RL=01 只写低 8 位）——因为 N ≤ 0FH 一个字节够。

### ④ 横向辨析

| 需求 | 控制字（二进制） | 控制字（BCD） |
|---|---|---|
| CNT0 方式 0，只写低字节 | **10H** | 11H |
| CNT0 方式 3，先低后高 | **36H** | 37H |
| CNT1 方式 2，先低后高 | **74H** | 75H |
| CNT1 方式 3，先低后高 | **76H** | 77H |
| CNT2 方式 3，先低后高 | **B6H** | B7H |
| CNT0 锁存命令 | 00H | — |

## 64. RL=01/10 时初值只写一个字节（低或高）

**层级** 理解 ｜ **来源** `网` ｜ **正文** §4.4

### ① 机理详解

D5D4（常记作 RL，Read/Load）决定初值写几个字节：

| D5D4 | 名称 | 写几字节 | 适用 |
|---|---|---|---|
| **00** | 锁存命令 | 0（后跟读操作） | 读当前计数值 |
| **01** | 只低 8 位 | **1**（只写低字节） | N ≤ 255 |
| **10** | 只高 8 位 | **1**（只写高字节） | N 是 256 的整数倍 |
| **11** | 先低后高 | **2** | N > 255 |

**RL=10（只写高字节）的妙用**：芯片内部会自动把高字节左移 8 位当完整 16 位值。
所以想设 N = 256×k，写一个字节 k 就行。例如 N = 51200 = 0xC800，
用 RL=10 只写 **C8H** 即可（C8H × 256 = 51200）。

**写错字节数的后果**：

```
控制字说先低后高（11），程序只写了一个字节：
  → 芯片还在等第二个字节，初值不完整，计数行为完全错乱
控制字说只写低字节（01），程序写了两个字节：
  → 第二个字节会被当成下一条控制字解释 → 整片失控
```

### ② 例题

要把 CNT0 的初值设为 51200，写出最省字节的控制字与初值序列。

```
51200 = 0xC800 = 0xC8 × 256
用 RL = 10（只写高 8 位）：只写一个字节 C8H

        MOV DX, 控制口
        MOV AL, 00010100B    ; CNT0、D5D4=10 只写高字节、方式1、二进制
        OUT DX, AL
        MOV DX, CNT0口
        MOV AL, 0C8H         ; 高字节 = C8H → 实际初值 C800H = 51200
        OUT DX, AL
```

### ③ 易错提示

- **这是单一来源条目**（只有 `网` 源）。无明确要求，按「理解」准备。
- **RL=00 不是「不写初值」**，是锁存命令——后文必须跟读操作（条目 69）。
- **RL=01/10 只写一个字节**，若实际初值需要 16 位就会错。
  实验九 N=15 用 10H（RL=01）是对的，因为 15 < 256。
- 判断能否单字节：**N ≤ 255 用 RL=01；N 是 256 的倍数用 RL=10；否则必须 RL=11**。

### ④ 横向辨析

| D5D4 | 写字节数 | 实验九 JSQ.ASM | 实验十 DSQ.ASM |
|---|---|---|---|
| 01 | 1（低） | **10H**（N=15） | — |
| 10 | 1（高） | — | — |
| **11** | 2（先低后高） | — | **36H / 76H**（N=1000） |
| 00 | 锁存命令 | 读当前值时用 | — |

## 65. 初值计算：分频 N=f_in÷f_out；定时 N=t×f_in

**层级** 必考 ｜ **来源** `章+题` ｜ **作业题** 第7讲Q1/Q2 ｜ **正文** §4.5

### ① 机理详解

两个公式，覆盖所有 8253 计算题：

$$\text{分频：} N = \frac{f_{in}}{f_{out}} \qquad
\text{定时：} N = t \times f_{in}$$

- **分频**：已知输入时钟频率和想要的输出频率，求初值。
- **定时**：已知输入时钟频率和想要的定时时长，求初值。
  因为 N 个时钟的时间就是 N/f_in = t，所以 N = t × f_in。

两个公式本质相同（f_out = 1/t），只是已知条件不同。

### ② 例题

**作业第7讲 Q2**：2MHz 时钟，CNT0 输出 1kHz 方波；CNT1 输出 500Hz 负脉冲。

```
① CNT0（方式 3，方波）：
   N = f_in / f_out = 2 MHz / 1 kHz = 2 000 000 / 1 000 = 2000
   BCD 写法：2000 → 2000H → 低字节 00H，高字节 20H
   → 第二空 = 00H（选项 A），第三空 = 20H（选项 D）✓

② CNT1（方式 2，负脉冲）：
   N = f_in / f_out = 2 MHz / 500 Hz = 2 000 000 / 500 = 4000
   BCD 写法：4000 → 4000H → 低字节 00H，高字节 40H
   → 第五空 = 00H（选项 A），第六空 = 40H（选项 C）✓
```

**作业第7讲 Q1**（级联，见条目 66）：LED 亮 4 秒灭 4 秒。

```
① 周期 T = 4 + 4 = 8 s → f_out = 1/8 = 0.125 Hz
② 总初值 N_total = f_in / f_out = 5 000 000 / 0.125 = 40 000 000
③ 超过 65536 → 必须级联，拆成 N1 × N2 = 4 × 10⁷
   取 N1 = 10000、N2 = 4000（平台答案）
④ 验证：5 MHz ÷ 10000 = 500 Hz；500 Hz ÷ 4000 = 0.125 Hz ✓
```

**实验十（DSQ.ASM）**：1MHz 时钟，级联出 1Hz。

```
第一级：N = 1 MHz / 1 kHz = 1000 → OUT0 = 1kHz 方波
第二级：N = 1 kHz / 1 Hz = 1000   → OUT1 = 1Hz 方波
总分频系数 = 1000 × 1000 = 10⁶
```

### ③ 易错提示

- **Hz 与 kHz 与 MHz 先统一单位**（见条目 67）。
- **「亮 4 秒灭 4 秒」的周期是 8 秒不是 4 秒**——Q1 第一处失分点。
- **BCD 与二进制的初值表示不同**：2000 在 BCD 是 2000H，在二进制是 07D0H。
  Q2 用 BCD 所以是 00H/20H。
- **N > 65536 时必须级联**，单计数器做不到（Q1 的 N=4×10⁷）。
- 实验十的 1000 = 03E8H（二进制），先写 E8H 再写 03H——**顺序不能反**。

### ④ 横向辨析

| 已知 | 求 | 公式 |
|---|---|---|
| f_in、f_out | N（分频） | N = f_in / f_out |
| f_in、t | N（定时） | N = t × f_in |
| t、级联级数 | 每级 N | 先算 N_total，再拆成若干因子 |

## 66. 超 65536 必级联；级联总输出 = 两级分频之积

**层级** 掌握 ｜ **来源** `章+题` ｜ **作业题** 第7讲Q1 ｜ **正文** §4.5

### ① 机理详解

单个 16 位计数器最大初值 65536（二进制）或 10000（BCD）。
需要更大分频比时，把**前一级的 OUT 接后一级的 CLK**：

```
CLK1 ──► [CNT1, N1] ──OUT1──► [CNT2, N2] ──OUT2──► LED
         （方式 2/3）              （方式 2/3）

f_OUT1 = f_CLK1 / N1
f_OUT2 = f_OUT1 / N2 = f_CLK1 / (N1 × N2)
```

**总公式**：

$$f_{OUT2} = \frac{f_{CLK1}}{N_1 \times N_2}$$

即**总输出频率 = 两级分频系数之积除输入频率**。
反向：N_total = N1 × N2 = f_in / f_out。

**实验十（DSQ.ASM）的标准接法**：

```
CLK0 ← 1MHz
OUT0 → CLK1      （级联）
第一级 CNT0：方式 3，N = 1000 → OUT0 = 1kHz
第二级 CNT1：方式 3，N = 1000 → OUT1 = 1Hz
总分频系数 = 1000 × 1000 = 10⁶
```

**作业第7讲 Q1 的标准接法**：

```
CLK1 ← 5MHz
OUT1 → CLK2      （级联）
OUT2 → LED
第一级 CNT1：方式 2，N1 = 10000 → OUT1 = 500Hz
第二级 CNT2：方式 3，N2 = 4000  → OUT2 = 0.125Hz（周期 8s）
总分频系数 = 10000 × 4000 = 4 × 10⁷
```

**为什么第一级用方式 2、第二级用方式 3**：方式 2/3 都能自动重装、都能周期输出。
第一级只要「每 10000 个脉冲来一次」即可（方式 2 的窄脉冲足够当第二级的 CLK）；
第二级要驱动 LED 亮灭交替，必须**方波**（方式 3）——窄负脉冲会让 LED 只闪一下。

### ② 例题

作业第7讲 Q1 完整重做：5MHz 时钟，LED 亮 4 秒灭 4 秒并重复，8253 基址 40H 接 8088。

```asm
; ---- 第一级：CNT1，方式 2，N1 = 10000（BCD 写 0000H）----
        MOV DX, 43H          ; 控制口
        MOV AL, 01110101B    ; CNT1、先低后高、方式 2、BCD
        OUT DX, AL
        MOV DX, 41H          ; 第一空 = 41H（CNT1 口）
        MOV AL, 00H          ; N1 低字节 = 00H
        OUT DX, AL
        MOV AL, 00H          ; 第二空 = 00H（N1 高字节；10000 BCD 写 0000）
        OUT DX, AL

; ---- 第二级：CNT2，方式 3，N2 = 4000（BCD 写 4000H）----
        MOV DX, 43H          ; 控制口
        MOV AL, 10110111B    ; CNT2、先低后高、方式 3、BCD
        OUT DX, AL
        MOV DX, 42H          ; 第三空 = 42H（CNT2 口）
        MOV AL, 00H          ; N2 低字节 = 00H
        OUT DX, AL
        MOV AL, 40H          ; 第四空 = 40H（N2 高字节）
        OUT DX, AL
```

四空答案：**第一空 = 41H(B)、第二空 = 00H(F)、第三空 = 42H(E)、第四空 = 40H(H)**
（平台标注「BECA（41H 00H 42H 40H）」）

> 另一种可行拆分是 N1 = 4000、N2 = 10000（平台标注「BACE」），
> 此时 OUT1 = 1250Hz、OUT2 = 0.125Hz，结果相同。

### ③ 易错提示

- 本讲易错第 6 条（主文档 §4.7）：**「级联总输出 = 两级分频之积」**。
  别答成「两级之和」或「两级之差」。
- **N > 65536 才需要级联**；N = 40000 用单级 BCD 就能做到（40000 > 9999 不行，
  BCD 2 字节最大 10000，所以 **BCD 下 N > 10000 就要级联**）。
- **前级用方式 2 或 3 都行，后级要方波必须方式 3**。
- **周期是 8 秒不是 4 秒**（亮 4 + 灭 4）。
- **N1 = 10000 在 BCD 里写 0000H**（写 0 = 最大），这是条目 56 规则的应用。

### ④ 横向辨析

| | 单级 | 级联 |
|---|---|---|
| 最大分频比 | 65536（二进制）/ 10000（BCD） | 65536²（二进制） |
| 接法 | CLK 直接接时钟 | **前级 OUT → 后级 CLK** |
| 总公式 | f_out = f_in / N | f_out = f_in / (N1×N2) |
| 典型 | 实验十第一级 | 实验十整体、作业 Q1 |

## 67. 单位换算先对齐指数（kHz×ms 配平）——计算题第一失分点

**层级** 掌握 ｜ **来源** `章+网` ｜ **作业题** 第7讲Q1 ｜ **正文** §4.5

### ① 机理详解

8253 计算题的第一失分点不是不会乘除，而是**单位没配对**：

```
错误示范：f = 2 MHz，t = 20 ms
  N = t × f = 20 × 2 = 40        ✗✗✗ （差了 10⁶）

正确：先把两边都换成「秒」和「Hz」
  f = 2 MHz = 2 × 10⁶ Hz
  t = 20 ms = 20 × 10⁻³ s
  N = t × f = 20×10⁻³ × 2×10⁶ = 40 × 10³ = 40000  ✓
```

**配平口诀**：`kHz × ms = 10³ × 10⁻³ = 1`，所以

$$\text{kHz} \times \text{ms} = 1 \quad\Rightarrow\quad
N = f[\text{kHz}] \times t[\text{ms}]$$

这是最省心的组合。同理：

| 组合 | 关系 |
|---|---|
| **kHz × ms** | **= 1**（直接用数值相乘） |
| MHz × μs | = 1 |
| Hz × s | = 1 |

### ② 例题

CLK = 2MHz，要求定时 20 秒。求初值，并判断是否需级联。

```
方法一（配平到 kHz × ms）：
  f = 2 MHz = 2000 kHz
  t = 20 s = 20000 ms
  N = 2000 × 20000 = 4 × 10⁷

方法二（直接算）：
  N = t × f = 20 × 2×10⁶ = 4 × 10⁷

4 × 10⁷ > 65536 → 必须级联。
拆分：N1 = 2000、N2 = 20000？不行，20000 > 10000（BCD 上限）
      取 N1 = 2000、N2 = 20000 → 20000 超 BCD 上限
      改取 N1 = 4000、N2 = 10000 → 4 × 10⁷ ✓
  或二进制：N1 = 4000、N2 = 10000（10000 > 9999？BCD 不行；二进制 10000 OK）
```

> 注意：BCD 2 字节最大 10000（靠写 0 实现），所以 N2 = 10000 在 BCD 下**可以**
> （写 0000H）；N = 20000 在 BCD 下**不行**（超过 4 位十进制）。

### ③ 易错提示

- **先统一单位再算**：这是主文档明说的「第一失分点」。
- **最省心是 kHz × ms**，凑成这个组合再乘。
- **算完先判断是否超上限**：二进制 > 65536、BCD > 10000 就要级联。
- **「亮 4 秒灭 4 秒」周期取 8 秒**——这不是单位问题但是同类的「题意误读」。

### ④ 横向辨析

| 场景 | 单位组合 | 直接乘？ |
|---|---|---|
| 8253 定时题 | kHz × ms | **是** |
| 8253 定时题 | MHz × μs | **是** |
| 波特率计算（8251A） | 波特 × 秒 → 位 | 需注意「只数数据位」 |
| ADC0809 换算 | V / V（无量纲） | 直接算 |

**8253 与 8251A 的计算题都要「先配平单位」**，只是一个乘时间一个乘位数。

## 68. 编程模板：控制字 → 初值低字节 → 初值高字节

**层级** 掌握 ｜ **来源** `章+题` ｜ **作业题** 第7讲Q1/Q2 ｜ **正文** §4.6

### ① 机理详解

单计数器初始化的标准模板：

```asm
        MOV DX, 控制口        ; A1A0 = 11
        MOV AL, 控制字        ; 选计数器 + 方式 + 读写顺序 + 制式
        OUT DX, AL

        MOV DX, 计数器口      ; A1A0 = 00/01/10
        MOV AL, 低字节        ; 先低
        OUT DX, AL
        MOV AL, 高字节        ; 后高
        OUT DX, AL
        ; 写完即自动启动，无需额外命令
```

**实验十（DSQ.ASM）的优雅写法**——用 `MOV AX, N` 一次取好 16 位：

```asm
        mov  dx, io8254_1     ; 计数器 1 数据口
        mov  ax, 1000         ; N = 1kHz / 1Hz = 1000 = 03E8H
        out  dx, al           ; 先写低字节 E8H
        mov  al, ah
        out  dx, al           ; 再写高字节 03H（顺序不能反）
```

比「两次 `MOV AL, imm`」更不易错，且便于改初值。

**级联的模板**（作业 Q1 / 实验十）：两个计数器各自「控制字 + 初值」，
接线上前级 OUT 接后级 CLK。

```asm
; 第一级
        MOV DX, 控制口
        MOV AL, 控制字1
        OUT DX, AL
        MOV DX, CNT1口
        MOV AL, N1低
        OUT DX, AL
        MOV AL, N1高
        OUT DX, AL
; 第二级
        MOV DX, 控制口
        MOV AL, 控制字2
        OUT DX, AL
        MOV DX, CNT2口
        MOV AL, N2低
        OUT DX, AL
        MOV AL, N2高
        OUT DX, AL
```

### ② 例题

把实验十两级级联写成标准模板（1MHz → 1kHz → 1Hz）。

```asm
io8254_0 equ 280h            ; 计数器 0
io8254_1 equ 281h            ; 计数器 1
io8254c  equ 283h            ; 控制寄存器

code segment
assume cs:code
start:
        mov  dx, io8254c     ; ── 第一级 ──
        mov  al, 36h         ; CNT0、先低后高、方式 3、二进制
        out  dx, al
        mov  dx, io8254_0
        mov  ax, 1000        ; N = 1MHz / 1kHz = 1000
        out  dx, al          ; 低字节 E8H
        mov  al, ah
        out  dx, al          ; 高字节 03H

        mov  dx, io8254c     ; ── 第二级 ──
        mov  al, 76h         ; CNT1、先低后高、方式 3、二进制
        out  dx, al
        mov  dx, io8254_1
        mov  ax, 1000        ; N = 1kHz / 1Hz = 1000
        out  dx, al          ; 低字节 E8H
        mov  al, ah
        out  dx, al          ; 高字节 03H

        mov  ah, 4ch
        int  21h             ; 返回 DOS
code ends
end start
```

> 接线（硬件，不在代码里）：CLK0 ← 1MHz；OUT0 → CLK1；GATE0/GATE1 ← +5V；
> OUT1 → 逻辑笔。

### ③ 易错提示

- **控制字写控制口、初值写计数器口**：两题作业都靠这个设空
  （Q1 第一空 41H 是计数器口，控制口是 43H）。
- **双字节必须两次 OUT**，漏一次初值只有一半，频率差 256 倍。
- **用 `MOV AX, N` + `MOV AL, AH` 的写法**比两次立即数不易错。
- **写完初值即启动**：不要再写「启动命令」。
- 实验九 N=15 用 RL=01（10H）**只写一个字节**——别照抄双字节模板。

### ④ 横向辨析

| 芯片 | 模板长度 | 关键 |
|---|---|---|
| **8253** | 控制字 + 1~2 次初值 | **先低后高** |
| 8255A | 控制字 + IN/OUT 循环 | 方向位 1=输入 |
| 8251A | 3×00H + 40H + 方式字 + 命令字 | **顺序 + REVTIME** |
| 8259A | ICW1~ICW4 + OCW1 + EOI | ICW2 高 5 位 |

## 69. 读当前计数值（锁存命令）；8254 增加读回命令；8254 最高 10MHz

**层级** 了解 ｜ **来源** `纲+网` ｜ **正文** §4.6

### ① 机理详解

读当前计数值不能直接 `IN`，因为计数执行单元的值在持续变化。
必须先发**锁存命令**「拍照」：

```
① 写锁存命令到控制口：
   D7D6 = 选计数器
   D5D4 = 00   ← 锁存命令的标志
   D3D2D1、D0 = 任意（通常写 0）
   → CNT0 的锁存命令 = 0000 0000B = 00H

② 从计数器口读（1~2 次，字节数同初始化时的 RL 设置）
```

锁存的是「发命令那一刻」的值，之后计数器继续跑，锁存器里的值不变，
CPU 可以安心读。读完之后锁存器自动失效，下次读要重新发锁存命令。

**实验九（JSQ.ASM）的读法**：N=15 只写低字节（RL=01），所以读也只需一次：

```asm
next:
        mov  dx, io8254_0    ; 计数器 0 数据口
        in   al, dx          ; 读当前计数值（15 → 14 → … → 0）
        call disp            ; 显示
```

> 实验九的参考程序**未发锁存命令**，因为 N ≤ 0FH、计数频率很低（单脉冲），
> 直接读不会读到跨减 1 的中间值。高频计数时必须先锁存。

**8254 的增加**：8254 多一条**读回命令**（Read-Back Command），
可同时锁存**计数值 + 状态字**，并且可以一次对多个计数器发令。
8253 没有这条命令。

**最高频率口径**：8253-5 = **5MHz**（课件口径）；8254 = **10MHz**。

### ② 例题

8253 CNT1 正在计数，想读它的当前值。写出控制字的锁存命令与读序列。

```
锁存命令：D7D6 = 01（CNT1），D5D4 = 00（锁存）
        → 0100 0000B = 40H

        MOV DX, 控制口
        MOV AL, 40H         ; 锁存 CNT1 当前值
        OUT DX, AL
        MOV DX, 41H         ; CNT1 口
        IN  AL, DX          ; 读低字节（RL=01 时）
        IN  AL, DX          ; 读高字节（RL=11 时需两次）
```

### ③ 易错提示

- **D5D4 = 00 是锁存命令，不是「不写初值」**（条目 64 已强调）。
- **每次读前都要重新发锁存命令**：锁存器读后失效。
- **读的字节数由初始化时的 RL 决定**：RL=01 读 1 次，RL=11 读 2 次。
- **8253 没有读回命令**，别把 8254 的特性写到 8253 程序里。
- 最高频率：题目说 **8253 用 5MHz**，说 **8254 用 10MHz**。

### ④ 横向辨析

| | 8253 | 8254 |
|---|---|---|
| 锁存命令 | 有（D5D4=00） | 有 |
| **读回命令** | **无** | **有**（计数值+状态一起锁） |
| 最高频率 | 5MHz（8253-5） | 10MHz |
| 引脚 | 24 脚 | 28 脚（多 RD̄/ WR̄/ CS̄ 等） |

**本课程实验用 8253（5MHz 口径）**，实验二 README 记录的 8254 差异仅供区分。

## 本讲小结

学到这里，8253 在你脑子里应该长成**三条并行的数据流**——
每条流上三个寄存器接力：CPU 把数装进初值寄存器（不变，供自动重装），
减1计数器干活（CPU 读不到），输出锁存器锁住那一刻供 CPU 读；外加一个只写不读的控制口。
围绕它的考点其实只有四件事：**选口（A1A0）、写初始化（控制字→低→高）、
算初值（分频/定时）、辨方式（六种）**。把这四件事练熟，本讲就拿下了。
