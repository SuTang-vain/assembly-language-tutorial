# 第04讲 汇编语言程序设计与 DOS 功能调用 · 逐考点详解

## 本讲是什么 & 为什么考

**先从一个问题说起**：你写的 `.asm` 文件只是文本，CPU 又不认字——它怎么变成能跑的程序？

CPU 只认识二进制机器码，所以一份汇编源码要经过四段接力才能跑起来：

1. **编辑**：用文本编辑器写出 `.asm` 源文件——`SEGMENT/ENDS`、`MOV`、`INT 21H` 此刻都只是字符；
2. **汇编（MASM）**：汇编器把助记符翻译成机器码，把段、变量、标号落成具体地址，产出目标文件 `.obj`；
3. **连接（LINK）**：连接器把 `.obj` 组织成可执行文件 `.exe`，处理各段之间的引用关系；
4. **运行**：DOS 把 `.exe` 装入内存、建好段环境，从 `END START` 指定的入口开始执行。

```mermaid
graph LR
    A[".asm 源文件<br/>（编辑）"] -->|MASM 汇编| B[".obj 目标文件"]
    B -->|LINK 连接| C[".exe 可执行文件"]
    C -->|DOS 加载| D["运行"]
```

**那 `INT 21H` 又是什么角色？** 程序跑起来之后，总要跟外界打交道——读键盘、显示字符、退出返回。这些事都碰硬件和系统资源，用户程序自己去做既危险又麻烦。**DOS 功能调用 `INT 21H` 就是操作系统给程序开的服务窗口**：程序把功能号放进 AH、参数放进约定寄存器，执行 `INT 21H`，DOS 替你把事办完再交还结果（比如 01H 把键入的字符放进 AL）。本讲后半的七项功能——01H 键入、02H 显示一个字符、09H 显示串、0AH 读一行、25H/35H 读写中断向量、4CH 返回 DOS——全从这扇窗口走。

**考试为什么考它？** 老师把 INT 21H 功能表标为**「能熟练准确使用」，且明确「试卷不附」**——功能号、入口、出口必须整表背下来；同时**编程以作业 4.11~4.14 为纲**，四道连线题的每一空都可能原样出现在试卷上。本讲 16 条考点就是围绕「背得准 + 默得出」展开的。

## 104. 段定义 SEGMENT/ENDS；SEG/OFFSET 取段址/偏移；DB/DW 小端存储

**层级** 掌握 ｜ **来源** `章+题` ｜ **作业题** 第4讲Q1 ｜ **正文** §7.1

### ① 机理详解

汇编源程序的基本骨架单位是**段**：

```asm
段名   SEGMENT
       …（内容）
段名   ENDS
```

常用的三个段：**DATA**（数据）、**STACK**（堆栈）、**CODE**（代码）。
`ASSUME` 告诉汇编器「哪个段寄存器指向哪个段」：

```asm
       ASSUME CS:CODE, DS:DATA
```

**取段址与偏移的两个算符**：

| 算符 | 取什么 | 例 |
|---|---|---|
| **SEG 标号** | **段地址** | `MOV AX, SEG TABLE` |
| **OFFSET 标号** | **偏移地址** | `MOV BX, OFFSET TABLE` |

两者常配对使用，效果等同 `LEA BX, TABLE`。

**DB / DW 定义数据**：

| 伪指令 | 单位 | 例 | 实际字节 |
|---|---|---|---|
| **DB** | 字节（8 位） | `DB 11H` | `11` |
| **DW** | 字（16 位） | `DW 11H, 22H, 3344H` | `11 00 22 00 44 33` |
| **DD** | 双字 | `DD 12345678H` | `78 56 34 12` |

**DW 的小端存储**（与第2讲存储体、第6讲向量表同规则）：

```
DW 3344H  →  低字节 44H 存低地址，高字节 33H 存高地址
            （字内小端）
DW 11H, 22H →  11 00 22 00
              （11H 占 2 字节：低地址 11H、高地址 00H）
```

### ② 例题

`TABLE DW 11H, 22H, 3344H` 在内存中占几字节？依次写出内容。

```
3 个字 × 2 字节 = 6 字节

TABLE+0: 11H     ┐
TABLE+1: 00H     ┘ 字 11H（小端）
TABLE+2: 22H     ┐
TABLE+3: 00H     ┘ 字 22H（小端）
TABLE+4: 44H     ┐
TABLE+5: 33H     ┘ 字 3344H（小端：低字节 44H 在前）

→ 11 00 22 00 44 33
```

### ③ 易错提示

- **DW 是 2 字节**：`DW 11H` 占 2 字节（11 00），不是 1 字节。
- **小端顺序**：高位字节在后。`DW 3344H` 存成 `44 33` 不是 `33 44`。
- **SEG 取段址、OFFSET 取偏移**，别混。
- `ASSUME` 只是「声明」，不产生实际装载——真正装 DS 要靠
  `MOV AX, DATA / MOV DS, AX`（条目 119）。

### ④ 横向辨析

| 概念 | 作用 | 是否产生机器码 |
|---|---|---|
| `SEGMENT/ENDS` | 界定段范围 | 否（伪指令） |
| `ASSUME` | 声明段与段寄存器的对应 | 否 |
| `DB/DW/DD` | 定义并初始化数据 | 否（占空间） |
| `SEG`/`OFFSET` | 取段址/偏移 | **是**（编译成立即数） |

## 105. 字符 ASCII：'1'=31H、'A'=41H、'a'=61H；CR=0DH、LF=0AH、DOS 串以 '$'(24H) 结尾

**层级** 掌握 ｜ **来源** `章+题` ｜ **作业题** 第1讲Q1、第4讲Q4 ｜ **正文** §7.1

### ① 机理详解

写显示程序必须熟记的 ASCII 码：

| 字符 | ASCII | 说明 |
|---|---|---|
| **'1'** | **31H** | 数字 1（不是 01H） |
| **'0'** | **30H** | 数字 0 |
| **'A'** | **41H** | 大写 A |
| **'a'** | **61H** | 小写 a |
| **CR（回车）** | **0DH** | 光标回行首 |
| **LF（换行）** | **0AH** | 光标下一行 |
| **'$'** | **24H** | DOS 09H 的串结束符 |

**关键关系**：

```
数字字符 '0'~'9' = 30H ~ 39H     → 数字 n 的字符 = n + 30H
大写 'A' = 41H，小写 'a' = 61H    → 大小写差 20H
```

**DOS 字符串的结尾约定**：09H 功能显示字符串时，
从 DS:DX 开始逐字节输出，**遇到 '$'（24H）才停**。
所以串定义必须显式加 `'$'`：

```asm
MSG  DB 'HELLO', 0DH, 0AH, '$'
```

**回车换行的组合**：`0DH, 0AH` 顺序固定（先 CR 后 LF）。
作业 4.12 的第一空正是这个（见条目 116）。

### ② 例题

作业第4讲 Q4（4.12）第一空：提示串定义为

```asm
MESS   DB 'PLEASE INPUT A NUMBER', 第一空
```

问第一空填什么？

```
正确答案：B —— 0DH, 0AH, '$'

作用：
  0DH   回车
  0AH   换行     → 让提示语另起一行，不紧跟前面的输出
  '$'   DOS 09H 的结束符，缺了它 09H 会一直显示到内存里下一个 '$' 为止
```

### ③ 易错提示

- **'$' = 24H 不是 36H**：36H 是数字字符 '6' 的 ASCII。
- **CR/LF 顺序是 0DH, 0AH**（先回车后换行），写反了显示会闪。
- **数字字符减 30H 得数值**（SUB AL,30H），这是键盘输入转数值的标准第一步。
- 第1讲 Q1 考过 ASCII 连线（'A'/'a'/'1'），必须熟。
- 老师 p48 易错清单：「数字结尾 B/H 不可省」——`'1'` 是 31H，写 `1` 是 01H。

### ④ 横向辨析

| 需求 | 写法 |
|---|---|
| 显示一个字符 | 02H，DL = 字符 |
| 显示一串字符 | 09H，DS:DX = 串首，**串以 '$' 结尾** |
| 换行 | `0DH, 0AH` |
| 数字转字符 | `OR AL, 30H` / `ADD AL, 30H` |
| 字符转数字 | `SUB AL, 30H` |

## 106. EQU（不可重定义）vs '='（可重定义）；宏 MACRO/ENDM

**层级** 掌握 ｜ **来源** `章+网` ｜ **正文** §7.1

### ① 机理详解

两种「给符号赋值」的伪指令，**区别只有一条**：

| 伪指令 | 能否重复定义 | 例 |
|---|---|---|
| **EQU** | **不能**（重复定义报错） | `COUNT EQU 10` |
| **=** | **能**（可随时改） | `COUNT = 10` … `COUNT = 20` |

**宏（MACRO）**：把一段代码起个名字，用时展开：

```asm
CRLF    MACRO
        MOV AH, 02H
        MOV DL, 0DH
        INT 21H
        MOV DL, 0AH
        INT 21H
        ENDM

        …
        CRLF                ; 调用处展开为上面 5 行
```

**宏 vs 子程序**：

| | 宏 | 子程序 |
|---|---|---|
| 展开时机 | **汇编时**展开，每次调用都复制一份代码 | 运行时 CALL |
| 代码长度 | 调用几次就长几倍 | 只存一份 |
| 执行速度 | 快（无 CALL/RET 开销） | 慢一点 |
| 参数传递 | 直接写在宏体里（可用宏参数） | 靠寄存器/栈/内存 |
| 适用 | 短小、频繁 | 较长、多处复用 |

### ② 例题

下面哪行会报错？为什么？

```asm
NUM  EQU 10
NUM  EQU 20      ; ← A
CNT  = 10
CNT  = 20        ; ← B
```

```
A 会报错：EQU 定义的符号不可重复定义。
B 不会：'=' 可以重新赋值，CNT 先为 10 后为 20。
```

### ③ 易错提示

- **EQU 与 '=' 的唯一区别就是「能否重定义」**——老师考就考这一条。
- **宏在汇编时展开**：所以宏定义要放在使用之前，且宏体内不能有标号
  （否则多次展开标号重复）。
- 8251A 作业里的 **REVTIME 就是一个宏**（见第09讲条目 29）：
  `MOV CX, 03 / DO: LOOP DO / ENDM`——这是宏的典型用法。
- 别把宏和子程序混：`CALL` 是子程序，宏是「文本替换」。

### ④ 横向辨析

| | EQU | = | 宏 |
|---|---|---|---|
| 本质 | 符号常量 | 符号常量 | 代码模板 |
| 可重定义 | **否** | **是** | 否（宏名不可重定义） |
| 展开时机 | 汇编 | 汇编 | **汇编时展开** |
| 是否占代码空间 | 否 | 否 | **是**（每次调用一份） |

## 107. 子程序压 CS→IP（RET）vs 中断子程序压 FLAGS→CS→IP（EOI+IRET）

**层级** 掌握 ｜ **来源** `师+章+网` ｜ **正文** §7.1

### ① 机理详解

这是本讲与第6讲的交叉点，老师明确要求掌握「子程序与中断子程序压栈区别」：

| | 子程序 | 中断子程序 |
|---|---|---|
| 定义 | ` PROC [NEAR/FAR] … ENDP` | ` PROC FAR … ENDP` |
| 进入方式 | **CALL 指令** | **中断向量表硬件跳转** |
| CPU 自动压栈 | **CS → IP**（段间）或 IP（段内） | **FLAGS → CS → IP** |
| 清 IF/TF | 否 | **是** |
| 结束动作 | **RET** | **EOI（MOV AL,20H; OUT 20H,AL）** |
| 返回指令 | **RET** | **IRET** |
| 是否需要入口地址 | 否（CALL 直接给） | **是**（要先设向量） |

**代码对照**：

```asm
; ---- 普通子程序 ----
DISP    PROC NEAR
        MOV DL, AL
        MOV AH, 02H
        INT 21H
        RET                 ; 弹 IP（段内）
DISP    ENDP

; ---- 中断子程序 ----
MYINT   PROC FAR
        PUSH AX
        PUSH DS
        …                   ; 处理
        MOV AL, 20H
        OUT 20H, AL         ; EOI
        POP DS
        POP AX
        IRET                ; 弹 IP、CS、FLAGS 三字
MYINT   ENDP
```

**为什么中断子程序必须 FAR**：入口地址是完整的 CS:IP 形式，
向量表里存的就是 4 字节的 CS:IP。

### ② 例题

某程序把中断服务程序的返回写成了 `RET`，会有什么后果？

```
RET 只弹 IP（段内）或 CS+IP（段间），不弹 FLAGS：
① 栈里剩 2 字节（FLAGS）没弹 → 栈指针不对，后续 PUSH/POP 或 RET 全乱；
② IF/TF 不恢复 → 开中断状态丢失；
③ 返回地址可能错（段间时 CS 没弹）。
→ 必须改成 IRET。
```

### ③ 易错提示

- **RET vs IRET**：中断子程序必须 IRET（弹三字）。这是最高频错误之一。
- **中断子程序要 FAR**，普通子程序可 NEAR。
- **中断子程序结束前要发 EOI**：不清 ISR 则同级/低级中断永远进不来。
- 第6讲条目 71/72 已详述压栈顺序，此处只强调「与子程序的差别」。
- 作业 4.11 的 DISPLAY 是**普通子程序**（用 RET），别和中断子程序混。

### ④ 横向辨析

| 动作 | 子程序 | 中断子程序 |
|---|---|---|
| 入口 | CALL | 向量表 |
| 压栈 | CS→IP | FLAGS→CS→IP |
| 清 IF/TF | 否 | 是 |
| 结束 | RET | **EOI** |
| 返回 | RET | **IRET** |

## 108. DOS 01H 键入一字符并回显（出口 AL）

**层级** 必背·试卷不附 ｜ **来源** `师+章+题` ｜ **作业题** 第4讲Q4 ｜ **正文** §7.2

### ① 机理详解

**DOS 功能 01H：键盘输入一个字符并在屏幕回显。**

```
入口：AH = 01H
出口：AL = 键入字符的 ASCII 码
```

调用序列：

```asm
        MOV AH, 01H
        INT 21H            ; 等待按键，按下后 AL = 字符，同时屏幕显示该字符
```

**特点**：

- **阻塞**：没按键就一直等（不像 06H 那样可无等待查询）。
- **自动回显**：按下的字符会显示在屏幕上，不需程序另写显示代码。
- **出口只有 AL**：AH 被 DOS 破坏，所以后面要再用功能号时必须**重新 MOV AH**。

**与 06H/07H/08H 的对比**：

| 功能 | 回显 | 是否等待 | 出口 |
|---|---|---|---|
| **01H** | **是** | 是 | AL = 字符 |
| 06H | 否 | 否（DL=FFH 时） | AL = 字符（无键则 ZF=1） |
| 07H | 否 | 是 | AL = 字符 |
| 08H | 否 | 是 | AL = 字符 |

### ② 例题

作业第4讲 Q4（4.12）第三空：读入用户键入的一个数字。

```
正确答案：A —— MOV AH, 01H / INT 21H

        MOV AH, 09H          ; 先显示提示串
        LEA DX, MESS
        INT 21H
        MOV AH, 01H          ; ← 第三空：键入一字符并回显
        INT 21H              ; AL = 键入字符（如 '5' = 35H）
        SUB AL, 30H          ; 转成数值 5
```

> 注意 09H 与 01H **都要重新 `MOV AH`**——AH 每次被 INT 21H 破坏。

### ③ 易错提示

- **01H 出口是 AL 不是 DL**：02H 的入口才是 DL。读写方向别混。
- **每次用功能号前都要重设 AH**：`MOV AH, 02H / INT 21H / MOV DL, 0DH /
  MOV AH, 02H / INT 21H`——第二次也要重设 AH。实验九 JSQ.ASM 的 disp
  子程序正是这么写的（见第07讲条目 68 的对照）。
- **01H 有回显**：若题目要求「输入不显示」，用 07H/08H。
- 老师把 DOS 表列为必背且**试卷不附**——七项功能号 + 入口 + 出口全要记。

### ④ 横向辨析

| 功能 | 方向 | 关键寄存器 |
|---|---|---|
| **01H** | 键盘 → AL | 出口 AL |
| **02H** | DL → 屏幕 | **入口 DL** |
| 09H | DS:DX → 屏幕 | 入口 DS:DX |
| 0AH | 键盘 → 缓冲区 | 入口 DS:DX |

## 109. DOS 02H 显示一个字符（入口 DL）

**层级** 必背·试卷不附 ｜ **来源** `师+章+题` ｜ **作业题** 第4讲Q1/Q3 ｜ **正文** §7.2

### ① 机理详解

**DOS 功能 02H：显示 DL 中的一个字符。**

```
入口：DL = 待显示字符的 ASCII 码
      AH = 02H
出口：无
```

调用序列：

```asm
        MOV DL, 'A'          ; 或 MOV DL, 41H
        MOV AH, 02H
        INT 21H              ; 屏幕显示 A
```

**典型组合用法**——回车换行：

```asm
        MOV AH, 02H
        MOV DL, 0DH          ; CR
        INT 21H
        MOV AH, 02H          ; AH 要重设！
        MOV DL, 0AH          ; LF
        INT 21H
```

**02H 与 09H 的分工**：

| | 02H | 09H |
|---|---|---|
| 显示单位 | **一个字符** | **一串字符** |
| 入口 | DL = 字符 | DS:DX = 串首址 |
| 串结束 | — | **'$'(24H)** |
| 适用 | 单个字符、控制码 | 提示语、整行文本 |

### ② 例题

作业第4讲 Q1（4.11）第一空与 Q3（4.13）第二空都是显示子程序的核心。
Q3 第二空的标准答案是什么？

```
正确答案：B —— MOV DL, AL / MOV AH, 02H / INT 21H

PRINT:  MOV DL, AL          ; 待显示字符（'F'/'G'/'P'）已在 AL
        MOV AH, 02H
        INT 21H             ; 显示
        RET

→ 这是「AL 里的字符送上屏幕」的标准三行。
```

作业 Q1（4.11）第一空（DISPLAY 子程序）答案同为：

```
正确答案：F —— MOV DL, AL / MOV AH, 02H / INT 21H / RET
```

### ③ 易错提示

- **02H 的入口是 DL 不是 AL**：要把字符先搬到 DL。
- **AH 每次重设**（见条目 108）——这是 4.11/4.13 两题都涉及的细节。
- **显示字符要转 ASCII**：`MOV DL, AL` 之前若 AL 是数值，先 `OR AL, 30H`。
- **09H 不能显示单个字符**（它找 '$'），显示单字符必须 02H。

### ④ 横向辨析

| 需求 | 功能号 | 关键寄存器 |
|---|---|---|
| 显示 1 个字符 | **02H** | **DL** |
| 显示一串字符 | **09H** | DS:DX + '$' 结尾 |
| 键入 1 个字符（回显） | **01H** | 出口 AL |
| 键入一行 | 0AH | DS:DX = 缓冲区 |

## 110. DOS 09H 显示字符串（DS:DX 指向 '$' 结尾串）

**层级** 必背·试卷不附 ｜ **来源** `师+章+题` ｜ **作业题** 第4讲Q4 ｜ **正文** §7.2

### ① 机理详解

**DOS 功能 09H：显示 DS:DX 指向的字符串，遇到 '$' 停止。**

```
入口：DS:DX = 字符串首地址
      字符串必须以 '$'(24H) 结尾
      AH = 09H
出口：无
```

调用序列：

```asm
DATA    SEGMENT
MESS    DB 'PLEASE INPUT A NUMBER', 0DH, 0AH, '$'
DATA    ENDS
CODE    SEGMENT
        ASSUME CS:CODE, DS:DATA
START:  MOV AX, DATA
        MOV DS, AX
        LEA DX, MESS         ; 或 MOV DX, OFFSET MESS
        MOV AH, 09H
        INT 21H              ; 显示整串
```

**要点**：

- **DS:DX 都要对**：DS 指向数据段，DX 指向串首。DX 错了会显示乱码或找不到 '$'。
- **'$' 必须显式写**：汇编器不会自动加。
- **09H 不破坏 AL/BL** 等，但会破坏 AH。
- 若串里有 '$' 之前的控制码（如 0DH,0AH），会照原样输出。

### ② 例题

作业第4讲 Q4（4.12）第二空：把提示串打印出来。

```
正确答案：E —— MOV AH, 09H / INT 21H

        LEA DX, MESS
        MOV AH, 09H          ; ← 第二空
        INT 21H
```

> Q4 三个空的完整逻辑链：
> 第一空 = 0DH,0AH,'$'（串结尾）
> 第二空 = MOV AH,09H / INT 21H（打印串）
> 第三空 = MOV AH,01H / INT 21H（键入字符）
> 三步顺序：定义串 → 09H 打印 → 01H 读入。

### ③ 易错提示

- **'$' 不能省**：没有 '$' 时 09H 会一直显示到内存中下一个 '$' 为止，
  可能刷屏。这是作业 Q4 第一空存在的意义。
- **DS:DX 都要设**：只设 DX 不设 DS 会显示错误段的数据。
- **09H 用于串、02H 用于单字符**：别用 09H 显示一个字符（找不到 '$' 很危险）。
- `LEA DX, MESS` 与 `MOV DX, OFFSET MESS` 等价，两种写法都要认识。

### ④ 横向辨析

| | 02H | 09H |
|---|---|---|
| 入口寄存器 | **DL** | **DS:DX** |
| 显示量 | 1 字节 | 若干字节直到 '$' |
| 需数据段 | 否 | **是** |
| 需结尾符 | 否 | **是（'$'）** |

## 111. DOS 0AH 缓冲输入一行；缓冲区三段精确口径（最大数/实际数/字符+0DH）

**层级** 必背 ｜ **来源** `师+网` ｜ **正文** §7.2

### ① 机理详解

**DOS 功能 0AH：从键盘读入一行到缓冲区。**

```
入口：DS:DX = 缓冲区首地址
      AH = 0AH
出口：缓冲区被填充
```

**缓冲区格式（三段，必须精确记）**：

```
DS:DX+0 ┌──────────────────┐
         │ 第 1 字节         │ 允许输入的最大字符数（含回车，且不能为 0）
DS:DX+1 ├──────────────────┤
         │ 第 2 字节         │ 实际输入字符数（不含回车，DOS 自动回填）
DS:DX+2 ├──────────────────┤
         │ 第 3 字节起       │ 键入的字符，末尾自动存回车 0DH
         │ …                 │
         └──────────────────┘
```

**定义方式**：

```asm
BUF     DB 20, ?, 20 DUP(?)
        ↑   ↑   ↑
        │   │   └── 预留 20 字节存字符
        │   └────── 第 2 字节先置 ?（DOS 回填）
        └────────── 第 1 字节 = 20（最大字符数）
```

**三段的精确口径**（这是本条的考点）：

| 段 | 谁写 | 内容 |
|---|---|---|
| 第 1 字节 | **程序员** | 允许输入的最大字符数，**含回车，不能为 0** |
| 第 2 字节 | **DOS 回填** | 实际输入字符数，**不含回车** |
| 第 3 字节起 | **DOS** | 键入字符，**末尾自动存 0DH** |

**与 01H 的区别**：01H 只读一个字符；0AH 读一整行（可含多个字符、可退格编辑），
适合输入数字串、命令行等。

### ② 例题

`BUF DB 20, ?, 20 DUP(?)`，用户输入 "ABCD" 后按回车。问缓冲区各字节内容。

```
输入 "ABCD" + 回车，共 5 个键击，但字符数是 4（不含回车）。

BUF+0 = 20        （程序员设的最大数，不变）
BUF+1 = 04        （DOS 回填：实际 4 个字符）
BUF+2 = 'A' = 41H
BUF+3 = 'B' = 42H
BUF+4 = 'C' = 43H
BUF+5 = 'D' = 44H
BUF+6 = 0DH       （DOS 自动追加的回车）
```

### ③ 易错提示

- **第 1 字节含回车、不能为 0**：写 0 会导致 DOS 不接收输入（立即返回）。
- **第 2 字节不含回车**：数错一位会让后续解析偏移错。
- **末尾自动存 0DH，不存 '$'**：所以 0AH 的输入不能直接用 09H 显示，
  要么自己补 '$'，要么用 02H 逐字符显示。
- **缓冲区必须定义在当前数据段**（DS:DX 能指到）。
- 老师对 0AH 的要求是「能熟练准确使用」；〔了解〕另有 08H（无回显键入）、
  0BH（检查键盘状态，AL=0FFH 有键）。

### ④ 横向辨析

| | 01H | 0AH |
|---|---|---|
| 读入量 | 1 个字符 | **一行** |
| 回显 | 自动 | 自动（可退格编辑） |
| 入口 | AH=01H | **DS:DX = 缓冲区** |
| 出口 | AL = 字符 | 缓冲区三段 |
| 能否读多个字符 | 否 | **是** |

## 112. DOS 25H 设置中断向量（DS:DX=入口、AL=类型号）

**层级** 必背·试卷不附 ｜ **来源** `师+章+题` ｜ **作业题** 第6讲Q5 ｜ **正文** §7.2

### ① 机理详解

**DOS 功能 25H：设置（写入）中断向量。**

```
入口：DS:DX = 中断服务程序入口地址（段:偏移）
      AL    = 中断类型号
      AH    = 25H
出口：无
```

标准调用（**必须 PUSH/POP DS**）：

```asm
        PUSH DS
        MOV AX, SEG INTRAD    ; 取服务程序段地址
        MOV DS, AX
        MOV DX, OFFSET INTRAD ; 取偏移地址
        MOV AL, n             ; 类型号
        MOV AH, 25H
        INT 21H
        POP DS                ; 恢复原数据段
```

**为什么必须 PUSH/POP DS**：DS 原本指向程序的数据段，
设向量时要临时改成服务程序所在的段。不恢复的话，后面访问数据全错。

**作业第6讲 Q5** 第二问正是考这个（答案：第三空 DX、第四空 25H）。

### ② 例题

用 DOS 25H 为类型号 44H 设置向量（入口 2000:3600H）。

```asm
        MOV AX, 2000H         ; 段地址
        MOV DS, AX
        MOV DX, 3600H         ; 偏移地址
        MOV AL, 44H           ; 类型号
        MOV AH, 25H           ; 功能号
        INT 21H
```

（完整程序还应 PUSH/POP DS，此处从略。）

### ③ 易错提示

- **DS:DX 存入口，AL 存类型号，AH 存 25H**——三个寄存器各有任务，别漏。
- **25H 是「写」、35H 是「读」**，功能号差 10H，别混。
- **PUSH/POP DS**：作业答案虽从略，但完整程序必须有，否则 DS 被破坏。
- 详细推演见第06讲条目 81。

### ④ 横向辨析

| 功能 | 方向 | 入口 | 出口 |
|---|---|---|---|
| **25H** | **写**向量 | **DS:DX** = 入口、AL = 类型号 | — |
| **35H** | **读**向量 | AL = 类型号 | **ES:BX** = 入口 |

## 113. DOS 35H 读取中断向量（AL=类型号 → ES:BX）

**层级** 必背·试卷不附 ｜ **来源** `师+章+题` ｜ **作业题** 第6讲Q5 ｜ **正文** §7.2

### ① 机理详解

**DOS 功能 35H：读取中断向量。**

```
入口：AL = 中断类型号
      AH = 35H
出口：ES:BX = 该中断的服务程序入口地址（ES=段、BX=偏移）
```

调用序列：

```asm
        MOV AL, n             ; 类型号
        MOV AH, 35H
        INT 21H               ; 返回 ES:BX = 入口

        MOV OLD_CS, ES        ; 保存段
        MOV OLD_IP, BX        ; 保存偏移
```

**典型用途**：修改中断向量前先保存原向量，程序退出时恢复，
避免影响其他程序（尤其是接管了系统中断时）。

**与 25H 的寄存器对应**：

```
25H 写：入口从 DS:DX 取出 → 写进向量表
35H 读：入口从向量表取出 → 放进 ES:BX
```

### ② 例题

读出类型号 44H 的原中断向量并保存到变量 OLD_VEC。

```asm
OLD_CS  DW ?
OLD_IP  DW ?

        MOV AL, 44H
        MOV AH, 35H
        INT 21H               ; ES:BX = 原入口
        MOV OLD_CS, ES
        MOV OLD_IP, BX
```

### ③ 易错提示

- **35H 出口是 ES:BX**，不是 DS:DX（那是 25H 的入口形式）。
  这是与 25H 最容易混的地方。
- **AL 设类型号、AH 设 35H**，两个都要赋值。
- 读出来的 ES:BX 要**马上保存**：后续任何 INT 21H 调用都可能破坏 ES/BX。
- 第6讲条目 80 已详述，此处只强调 DOS 表的口径。

### ④ 横向辨析

| | 25H（写） | 35H（读） |
|---|---|---|
| 入口 | DS:DX + AL | AL |
| 出口 | — | **ES:BX** |
| 段寄存器 | DS | **ES** |
| 偏移寄存器 | DX | **BX** |

**记忆法**：写用 D（DS/DX），读用 E/B（ES/BX）。

## 114. DOS 4CH 程序终止返回 DOS（AL=返回码）

**层级** 必背·试卷不附 ｜ **来源** `师+章+题` ｜ **作业题** 第4讲Q1 ｜ **正文** §7.2

### ① 机理详解

**DOS 功能 4CH：终止当前程序，返回 DOS。**

```
入口：AL = 返回码（可设为 0 或 00H，表示正常退出）
      AH = 4CH
出口：无（控制权交回 DOS）
```

调用序列：

```asm
        MOV AH, 4CH
        INT 21H
```

**两种常见写法**：

```asm
MOV AX, 4C00H        ; AH=4CH、AL=00H 一次设好
INT 21H

; 或
MOV AH, 4CH
INT 21H              ; AL 不设也可（返回码无意义时）
```

**为什么每个程序都要有**：没有 4CH，程序执行完 `END START` 之后的区域会
「坠落」到内存里继续执行，行为不可预期。

**老师对 AL 的要求**：返回码。作业答案里常见 `MOV AX, 4C00H`（一次设好两个字）。
实验二 JSQ.ASM/DSQ.ASM/I8259.ASM 的退出都是 `MOV AX, 4C00H / INT 21H`。

### ② 例题

作业第4讲 Q1（4.11）程序骨架的结尾应该是什么？

```
        MOV AH, 4CH          ; 或 MOV AX, 4C00H
        INT 21H              ; 返回 DOS
```

这是程序骨架（条目 119）的最后一步。

### ③ 易错提示

- **4CH 不是 00H**：00H 也是「终止程序」的旧式功能，但 4CH 更规范
  （能传返回码、不破坏内存分配）。老师答案用 4CH。
- **AL 是返回码**：写 `MOV AX, 4C00H` 返回 0；`MOV AX, 4C01H` 返回 1。
- **AH 要设 4CH**：只设 AL 不够。
- 漏了 4CH 是「程序跑完不停」的最常见原因。

### ④ 横向辨析

| 功能 | 作用 | 入口 |
|---|---|---|
| **4CH** | 终止程序返回 DOS | AH=4CH、AL=返回码 |
| 00H | 终止程序（旧式） | AH=00H |
| 31H | 终止并驻留（TSR） | AL=返回码、DX=驻留大小 |

## 115. 4.11 显示全部 ASCII（00~FFH）：DISPLAY 子程序 + 主循环

**层级** 掌握·能默写 ｜ **来源** `师+章+题` ｜ **作业题** 第4讲Q1 ｜ **正文** §7.3

### ① 机理详解

老师 PDF p33 把 4.11~4.14 直接列为考点，必须能默写。

**结构**：一个 DISPLAY 子程序（显示 AL 中的字符）+ 主循环（AL 从 0 到 255）。

```asm
DATA    SEGMENT
DATA    ENDS
CODE    SEGMENT
        ASSUME CS:CODE, DS:DATA
START:  MOV AX, DATA
        MOV DS, AX
        MOV CX, 0FFH          ; 循环次数（作业标准答案）
        MOV AL, 0             ; 从 00H 开始
NEXT:   CALL DISPLAY
        INC AL
        LOOP NEXT
        MOV AH, 4CH
        INT 21H

; ---- DISPLAY：显示 AL 中的字符 ----
DISPLAY PROC
        MOV DL, AL            ; ← 第一空
        MOV AH, 02H
        INT 21H               ; 显示
        RET
DISPLAY ENDP
CODE    ENDS
        END START
```

**作业第4讲 Q1 的两个空**：

| 空 | 正确答案 | 内容 |
|---|---|---|
| 第一空（DISPLAY 子程序） | **F** | `MOV DL, AL` / `MOV AH, 02H` / `INT 21H` / `RET` |
| 第二空（循环次数） | **E** | `MOV CX, 0FFH` |

**关于 0FFH vs 0100H**（主文档 §7.3 已注明）：

```
00H~FFH 共 256 个字符，严格算循环次数应为 0100H。
平台给出的标准答案是 0FFH（255 次）。
→ 复习时知悉这个差异，判分以讲义/平台为准。
```

**为什么用子程序**：显示动作在循环里反复出现，抽成子程序代码短、清晰。
DISPLAY 是**普通子程序**（NEAR、用 RET），不是中断子程序。

### ② 例题

作业第4讲 Q1 原题重做：显示全部标准和扩展 ASCII 码（00~FFH）。

```
第一空（DISPLAY 内）：
        MOV DL, AL
        MOV AH, 02H
        INT 21H
        RET

第二空（循环次数）：
        MOV CX, 0FFH

标准答案：第一空 F、第二空 E
```

### ③ 易错提示

- **DISPLAY 里 `MOV DL, AL` 不能省**：02H 要的是 DL。
- **每次 `MOV AH, 02H`**：AH 被 INT 21H 破坏，但 DISPLAY 里只用一次，
  所以只需设一次（不像主循环里多次显示）。
- **`MOV CX, 0FFH` 不是 `MOV CX, 100`**：100 = 64H，差得远。
- **`MOV AL, 0` 初始化**：不初始化 AL 会从随机值开始。
- 扩展 ASCII（80H~FFH）在某些显示环境下是图形/控制字符，屏幕可能出现乱码——
  这是正常现象，不代表程序错。

### ④ 横向辨析

| 题 | 结构 | 关键指令 |
|---|---|---|
| **4.11** | DISPLAY 子程序 + 主循环 | 02H、INC AL、LOOP |
| 4.12 | 提示串 + 键入 + 查表 | 09H、01H、SUB 30H、XLAT |
| 4.13 | 分支 + PRINT 子程序 | CMP、JB/JAE、02H |
| 4.14 | 循环统计 | CMP BYTE PTR、JG/JE/JL、INC BX、LOOP |

## 116. 4.12 键入 0~9 查七段码：09H 提示 → 01H 读入 → SUB AL,30H → XLAT

**层级** 掌握·能默写 ｜ **来源** `师+章+题` ｜ **作业题** 第4讲Q4 ｜ **正文** §7.3

### ① 机理详解

**四步链**：显示提示 → 键入数字 → 转数值 → 查表。

```asm
DATA    SEGMENT
MESS    DB 'PLEASE INPUT A NUMBER', 0DH, 0AH, '$'   ; ← 第一空：串结尾
TABLE   DB 40H, 79H, 24H, 30H, 19H, 12H, 02H, 78H   ; 0~7 七段码
        DB 00H, 18H, ...                            ; 8~9 等
DATA    ENDS
CODE    SEGMENT
        ASSUME CS:CODE, DS:DATA
START:  MOV AX, DATA
        MOV DS, AX
        LEA DX, MESS
        MOV AH, 09H          ; ← 第二空：打印提示串
        INT 21H

        MOV AH, 01H          ; ← 第三空：键入一字符并回显
        INT 21H              ; AL = 键入字符（如 '5' = 35H）
        SUB AL, 30H          ; 转成数值 5

        LEA BX, TABLE        ; 表首址
        XLAT                 ; AL ← DS:[BX+AL] = 七段码
        MOV DL, AL
        MOV AH, 02H
        INT 21H              ; 显示段码

        MOV AH, 4CH
        INT 21H
CODE    ENDS
        END START
```

**作业第4讲 Q4 的三个空**：

| 空 | 正确答案 | 内容 |
|---|---|---|
| 第一空（串结尾） | **B** | `0DH, 0AH, '$'` |
| 第二空（打印串） | **E** | `MOV AH, 09H` / `INT 21H` |
| 第三空（键入字符） | **A** | `MOV AH, 01H` / `INT 21H` |

**七段码表（课本作业 3.8 的值）**：

```
0→40H  1→79H  2→24H  3→30H  4→19H
5→12H  6→02H  7→78H  8→00H  9→18H
```

### ② 例题

作业第4讲 Q4 原题：键入数字 0~9，查表求七段码存入 DL。
用户按了 '7'，写出 AL 的变化过程。

```
① MOV AH, 01H / INT 21H     → AL = '7' = 37H
② SUB AL, 30H               → AL = 07H（数值 7）
③ LEA BX, TABLE / XLAT      → AL = DS:[TABLE+7] = 78H（7 的七段码）
④ MOV DL, AL                → DL = 78H
```

### ③ 易错提示

- **`SUB AL, 30H` 不能省**：不转数值，XLAT 会拿 37H 当索引，越界。
- **XLAT 要求表在当前数据段**，且 BX 先 `LEA BX, TABLE`。
- **串结尾必须是 `0DH, 0AH, '$'`**：缺 '$' 则 09H 不停。
- **09H 与 01H 都要重设 AH**（题目第二、三空正好考这两次）。
- 与第8讲条目 51「4 开关→七段码」对照：那边用 `AND AL,0FH` 取低 4 位，
  这边用 `SUB AL,30H` 转数值——**都是为 XLAT 准备索引**。

### ④ 横向辨析

| 步骤 | 4.12（键盘） | 第8讲（开关） |
|---|---|---|
| 取索引 | 01H → SUB AL,30H | IN AL,PA → AND AL,0FH |
| 查表 | XLAT | XLAT |
| 输出 | 02H 显示段码 | OUT PB 驱动数码管 |

## 117. 4.13 分数 F/G/P 分支：CMP BL,60/JB + CMP BL,85/JAE

**层级** 掌握·能默写 ｜ **来源** `师+章+题` ｜ **作业题** 第4讲Q3 ｜ **正文** §7.3

### ① 机理详解

**条件**：BL 存英语成绩。
低于 60 显示 F，高于等于 85 显示 G，否则显示 P。

```asm
DATA    SEGMENT
DATA    ENDS
CODE    SEGMENT
        ASSUME CS:CODE, DS:DATA
START:  MOV AX, DATA
        MOV DS, AX
        CMP BL, 60
        JB  FAIL            ; < 60 → F
        CMP BL, 85
        JAE GOOD            ; ≥ 85 → G
        MOV AL, 'P'         ; ← 第一空：否则 P
        JMP PRINT
FAIL:   MOV AL, 'F'
        JMP PRINT
GOOD:   MOV AL, 'G'
PRINT:  MOV DL, AL          ; ← 第二空
        MOV AH, 02H
        INT 21H             ; 显示
        MOV AH, 4CH
        INT 21H
CODE    ENDS
        END START
```

**作业第4讲 Q3 的两个空**：

| 空 | 正确答案 | 内容 |
|---|---|---|
| 第一空（PASS 段） | **C** | `MOV AL, 'P'` |
| 第二空（PRINT 段） | **B** | `MOV DL, AL` / `MOV AH, 02H` / `INT 21H` |

**分支结构要点**：

- **两次 CMP**：`CMP BL,60` 判下限，`CMP BL,85` 判上限。
- **`JB`（Below，无符号小于）**：成绩是无符号数，用 JB 而非 JL。
  若用 JL（有符号）在成绩 ≥ 80H 时会出错。
- **三个分支都要 `JMP PRINT`**：否则 FAIL 会顺序落入 GOOD。
- **PRINT 是公共出口**：三分支汇合到一处显示，代码不重复。

### ② 例题

作业第4讲 Q3 原题重做，并说明 BL = 72 时走哪条路。

```
第一空：MOV AL, 'P'          （答案 C）
第二空：MOV DL,AL / MOV AH,02H / INT 21H   （答案 B）

BL = 72：
  CMP BL,60 → 72 ≥ 60，JB 不跳
  CMP BL,85 → 72 < 85，JAE 不跳
  → 落入 MOV AL,'P' → 显示 P ✔
```

### ③ 易错提示

- **`JB` 不是 `JL`**：成绩按无符号处理（0~100），JB 正确。
  用 JL 在成绩 ≥128 时误判——这是「有符号/无符号混用」高频错。
- **三分支都要 JMP PRINT**：漏一个会串到别的分支。
- **`MOV AL, 'P'` 别写成 `MOV AL, 50H` 之外的错值**：'P' = 50H。
- **PRINT 段用 DL 不是 AL**：02H 要 DL，所以 `MOV DL, AL` 不能省
  （这正是第二空）。

### ④ 横向辨析

| 比较 | 有符号 | 无符号 |
|---|---|---|
| 小于 | **JL** | **JB** |
| 大于等于 | **JGE** | **JAE** |
| 本题成绩（0~100） | — | **用 JB / JAE** |

## 118. 4.14 统计正/负/零：CMP BYTE PTR [BX],0 + JG/JE/JL + INC BX + LOOP

**层级** 掌握·能默写 ｜ **来源** `师+章+题` ｜ **作业题** 第4讲Q2 ｜ **正文** §7.3

### ① 机理详解

TABLE 起存放 12 个**带符号**字节，统计正数、负数、零的个数。

```asm
DATA    SEGMENT
TABLE   DB -5, 3, 0, 12, -8, 7, 0, -1, 9, 4, 0, 6   ; 12 个带符号数
PLUS    DB ?          ; 正数个数
MINUS   DB ?          ; 负数个数
ZERO    DB ?          ; 零的个数
DATA    ENDS
CODE    SEGMENT
        ASSUME CS:CODE, DS:DATA
START:  MOV AX, DATA
        MOV DS, AX
        MOV CX, 12              ; ← 第一空：循环次数
        LEA BX, TABLE
        XOR DL, DL              ; PLUS = 0
        XOR DH, DH              ; MINUS = 0
        XOR SI, SI              ; ZERO = 0
LOOP1:  CMP BYTE PTR [BX], 0    ; ← 第二空：比较（必须 BYTE PTR）
        JE  ISZERO
        JL  ISNEG               ; 带符号，用 JL
        INC DL                  ; 正数
        JMP NEXT
ISNEG:  INC DH                  ; 负数
        JMP NEXT
ISZERO: INC SI                  ; 零
NEXT:   INC BX                  ; ← 第三空
        LOOP LOOP1

        MOV PLUS, DL
        MOV MINUS, DH
        MOV ZERO, SI
        MOV AH, 4CH
        INT 21H
CODE    ENDS
        END START
```

**作业第4讲 Q2 的三个空**：

| 空 | 正确答案 | 内容 |
|---|---|---|
| 第一空（循环次数） | **B** | `MOV CX, 12` |
| 第二空（循环体内比较） | **D** | `CMP BYTE PTR [BX], 0` |
| 第三空（NEXT 处） | **F** | `INC BX` / `LOOP LOOP1` |

**四个必须点**：

1. **`BYTE PTR` 不能省**：`[BX]` 的宽度不确定，汇编器无法判断是字节还是字比较。
   写成 `CMP [BX], 0` 会报错或按错误宽度解释。
2. **`JL`（有符号）**：数据是带符号数，必须用 JL/JG 而非 JB/JA。
3. **`INC BX`**：字节数组，指针每次 +1。
4. **`LOOP`** 依赖 CX，所以循环次数必须 `MOV CX, 12`。

### ② 例题

作业第4讲 Q2 原题重做，TABLE 有 12 个字节。

```
第一空：MOV CX, 12            （答案 B）
第二空：CMP BYTE PTR [BX], 0  （答案 D）
第三空：INC BX / LOOP LOOP1   （答案 F）
```

若 TABLE 只有 8 个元素，第一空改成什么？

```
MOV CX, 8
（循环次数必须与元素个数一致，否则统计不全或越界）
```

### ③ 易错提示

- **`BYTE PTR` 是本题最易漏的**：没有它 `CMP [BX], 0` 非法。
  老师答案第二空专门考这个。
- **用 `JL` 不用 `JB`**：带符号数。用 JB 会把 −5（FBH）当成 251 判成「正」。
- **三个分支都要 `JMP NEXT`**：否则统计逻辑串位。
- **`INC BX` 不是 `INC SI`**（除非指针用 SI）：与第二空的 `[BX]` 要一致。
- **计数器放哪**：可以用 DL/DH/SI 等，但要 PUSH/POP 保护（若在子程序里）。

### ④ 横向辨析

| 题 | 循环变量 | 比较 | 分支 |
|---|---|---|---|
| **4.14** | CX = 元素个数 | `CMP BYTE PTR [BX], 0` | JG/JE/JL（带符号） |
| 4.13 | 无循环 | `CMP BL, 60` / `CMP BL, 85` | JB/JAE（无符号） |

**同一个课程里两种符号性**：4.13 成绩是无符号（JB/JAE），
4.14 带符号数是有符号（JG/JL）。**先判数据有无符号，再选指令**。

## 119. 程序骨架：段定义 + ASSUME + 经 AX 装 DS + 4CH 返回

**层级** 必背 ｜ **来源** `章+题` ｜ **作业题** 第4讲Q1 ｜ **正文** §7.4

### ① 机理详解

所有汇编程序的通用骨架（主文档 §7.4 原版）：

```asm
DATA    SEGMENT
MSG     DB 'HELLO$'
DATA    ENDS
CODE    SEGMENT
        ASSUME CS:CODE, DS:DATA
START:
        MOV AX, DATA         ; 段址不能直接进 DS！
        MOV DS, AX
        ……                   ; 程序体
        MOV AH, 4CH
        INT 21H
CODE    ENDS
        END START
```

**五要素**：

| 要素 | 作用 | 易错点 |
|---|---|---|
| **段定义** | `DATA/CODE SEGMENT … ENDS` | 段名要配对 |
| **ASSUME** | 声明 CS:CODE、DS:DATA | 只是声明，不装载 |
| **经 AX 装 DS** | `MOV AX, DATA / MOV DS, AX` | **不能 `MOV DS, DATA`** |
| **程序体** | 具体逻辑 | — |
| **4CH 返回** | `MOV AH, 4CH / INT 21H` | 漏了程序不停 |
| `END START` | 指明入口 | 漏了汇编器找不到入口 |

**为什么必须经 AX**：8086 规定**立即数不能直接送入段寄存器**。
`MOV DS, DATA` 是非法的（第3讲 Q7 考过）——必须绕道 AX。

### ② 例题

下面这段哪里错了？

```asm
CODE    SEGMENT
        ASSUME CS:CODE
START:  MOV DS, DATA          ; ← 错 1
        MOV AH, 09H
        LEA DX, MSG
        INT 21H
CODE    ENDS
        END START
```

```
三处错：
① MOV DS, DATA 非法 → 改成 MOV AX, DATA / MOV DS, AX
② 没有 DATA 段定义，MSG 无处可寻 → 加 DATA SEGMENT / MSG DB … / DATA ENDS
   并把 ASSUME 改成 ASSUME CS:CODE, DS:DATA
③ 缺 4CH 返回 → 加 MOV AH, 4CH / INT 21H
```

### ③ 易错提示

- **`MOV DS, DATA` 非法**：必须 `MOV AX, DATA / MOV DS, AX`。
  这是第3讲 Q7 的「MOV 四禁令」之一，也是本骨架的核心考点。
- **`ASSUME` 不产生代码**：它只告诉汇编器段寄存器的对应关系。
  真正的装载是 `MOV AX, DATA / MOV DS, AX`。
- **`END START` 不能省**：否则汇编器不知道入口在哪。
- **4CH 不能省**：程序会「坠落」。
- 若用了堆栈（如 PUSH/POP），还要定义 `STACK SEGMENT STACK`。

### ④ 横向辨析

| 步骤 | 是否产生机器码 |
|---|---|
| `SEGMENT/ENDS` | 否 |
| `ASSUME` | 否 |
| `DB/DW` | 否（占数据空间） |
| `MOV AX, DATA` | **是** |
| `MOV DS, AX` | **是** |
| `END START` | 否（指定入口） |
