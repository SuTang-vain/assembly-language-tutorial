# D/A 部分

## 1. D/A 与 A/D 转换基本原理

**层级** 了解 ｜ **来源** `师` ｜ **正文** §一

### ① 机理详解

两种转换是把「数字世界」与「模拟世界」对起来的两座桥，方向相反：

- **D/A（数→模）**：输入一个 n 位二进制数 D，输出一个与 D 成正比的模拟量（电压或电流）。
  核心是**权电阻网络 / R-2R 梯形网络**：每一位控制一个电子开关，把参考电压 VREF 按该位的
  「权重」送到求和点。第 i 位的权重是 2^i，所以 D 的数值大小直接决定输出幅度。
  输出是**阶梯状**的：D 从 0 逐次加 1，输出按 LSB 的步长一级级跳。
- **A/D（模→数）**：输入一个连续电压 VIN，输出最接近它的 n 位二进制数。
  必须经历**采样 → 量化 → 编码**三步：采样把连续时间离散化，量化把连续幅度用有限个
  电平近似（必然引入量化误差），编码把电平转成二进制码。
  常见实现有**逐次逼近（SAR，ADC0809 用）**、双积分、并行比较等。

关键对称性：**D/A 是 A/D 的逆，但两者都有同一个分辨率下限 LSB = 满量程 / 2^n**。
这个 LSB 既决定 D/A 输出能调多细，也决定 A/D 能量多准。

### ② 例题

一个 8 位 D/A，VREF = 5V，问输出一共能分成几级、每级多大？

```
级数 = 2^8 = 256 级（D = 00H ~ FFH）
LSB  = VREF / 2^8 = 5V / 256 = 19.53 mV
```

即输出从 0 到约 −4.98V（接反相运放时）之间，以约 19.5mV 为最小步长分 256 档。

### ③ 易错提示

- 老师只要求「了解」，**不要花时间背转换器内部电路图**（p47 明确：画任何图都不考）。
- 容易和「指标」混：转换原理了解，但**输出电压公式、满量程误差是掌握级**，别一听说「了解」
  就整讲都略过——范围里公式和误差是单独点名的掌握项。

### ④ 横向辨析

| | DAC0832 | ADC0809 |
|---|---|---|
| 方向 | 数字 → 模拟 | 模拟 → 数字 |
| 输出/输入 | 输出 IOUT1/IOUT2 电流 | 输入 IN0~IN7 电压 |
| 是否需要外部时钟 | 不需要 | **需要**（~640kHz） |
| 转换速度 | 建立时间 ~1μs 量级，无「转换中」状态 | **约 100μs**，必须等待 |
| 关键控制信号 | WR/CS/XFER/ILE | **ALE/START/EOC/OE** |
| 本课程层级 | 输出电压公式掌握 | 四步流程掌握 |

## 2. DAC0832 结构：8 位、电流输出 IOUT1/2、两级锁存、倒 T 型 R-2R

**层级** 掌握 ｜ **来源** `章+网` ｜ **正文** §1.1

### ① 机理详解

DAC0832 的数据通路是一条四级流水：

```
CPU 数据线 D7~D0
      │
      ▼
┌───────────────┐
│ ① 输入寄存器  │ ← 由 ILE + CS + WR1 控制
│   （第一级）   │
└───────┬───────┘
        │  只有 XFER + WR2 有效时才放行
        ▼
┌───────────────┐
│ ② DAC 寄存器  │ ← 由 XFER + WR2 控制
│   （第二级）   │
└───────┬───────┘
        │
        ▼
┌───────────────┐
│ ③ D/A 转换器   │ 倒 T 型 R-2R 电阻网络 + 电子开关阵列
└───────┬───────┘
        │
   ┌────┴────┐
 IOUT1    IOUT2      ← 两个互补电流输出
```

四个设计要点：

1. **8 位分辨率**：D 的范围 00H~FFH，共 256 档。
2. **电流输出**：芯片吐出来的是电流（IOUT1），不是电压。IOUT1 + IOUT2 ≈ 常数
   （互补），这是 R-2R 网络的自然结果。
3. **倒 T 型 R-2R 网络**：只用 R 和 2R 两种阻值，梯形拼接，避免了权电阻网络需要
   很多种精密阻值的工艺困难。
4. **两级锁存**：这是 0832 相对于 0830/0831 的改进之处，也是「为什么要双缓冲」的物理基础
   （见条目 5）。输入寄存器可单独锁一路，DAC 寄存器统一放行，从而支持多路同步。

### ② 例题

**真题（课堂练习 AD/DA Q1，多选）**：DAC0832 芯片是？

```
正确答案：ABCD（全选）

  A 分辨率 8 位（256 级）              ✔ 对应本条
  B 建立时间仅需约 1μs                ✔ 对应本条（电流输出型 DAC 的典型速度）
  C 电流输出型，实际常外接运放转电压    ✔ 对应本条 + 条目 3
  D National Semiconductor 开发，后归 TI  ✔ 厂商常识，同 ADC0809
```

> **本条新增两个细节**（初稿未写，真题逼出来的）：
> ① **建立时间约 1μs**——DAC0832 是电流输出型，不用逐次逼近，所以比 ADC0809 的
>   **100μs** 快约 100 倍。这个对比是「D/A 快、A/D 慢」的典型例证。
> ② **厂商沿革**：National Semiconductor（美国国家半导体）开发，后被 Texas Instruments
>   （TI）收购，现归 TI 旗下。ADC0809 同为 NS 出身（真题 Q2 的 D 项）。



把 8 位 D7~D0 送进 DAC0832，问数据要经过几道「关卡」才能变成模拟输出，各自由什么信号控制？

```
D7~D0 → [输入寄存器] --ILE·CS·WR1--> 放行
              ↓
         [DAC 寄存器] --XFER·WR2--> 放行
              ↓
         [R-2R 网络 + 开关] → IOUT1 / IOUT2
```

答案：**两道**。第一道 ILE/CS/WR1，第二道 XFER/WR2。单缓冲就是把其中一道旁路
（信号常有效），双缓冲是两道都受控。

### ③ 易错提示

- **别把「两级锁存」答成「两级缓冲器」**——它们是**锁存器**，作用是「在某一刻把数据
  保持住」，与 8255 的「三态缓冲」（只负责隔离/驱动，不保持）机制不同。
- 输出是**电流**，直接量引脚得不到电压（见条目 3）。

### ④ 横向辨析

| 器件 | 锁存/缓冲结构 | 是否「两级」 |
|---|---|---|
| **DAC0832** | 输入寄存器 + DAC 寄存器，**两级锁存** | 是 |
| DAC0830 / 0831 | 只有一级（或无锁存） | 否 |
| 8255A | 数据口是**三态缓冲**（方式 0 输入不锁存） | 否 |
| 8086 的 74LS373 | 电平触发的**地址锁存器**，锁 A0~A19+BHE | 一级 |

**为什么 0832 要特意做成两级**：如果只有一级，CPU 写完数据后输出立刻变；多片 DAC
想同时输出时，各片写入时刻不同，输出就会先后不一。加第二级就能「先各自写进输入
寄存器，再同一时刻统一放行到 DAC 寄存器」——这就是条目 5 的答案。

## 3. DAC0832 必须外接反相运放（电流→电压、负→正）

**层级** 掌握 ｜ **来源** `章+网` ｜ **正文** §1.1

### ① 机理详解

芯片输出的 IOUT1 是流入/流出芯片的电流，要拿到可用的电压必须外接一级
**反相运算放大器**：

```
                  Rf（常等于 R，片内 15kΩ）
        ┌───────╱╲───────┐
        │      ╱   ╲     │
IOUT1 ──┤─────╱  OP  ╲────┴───► VOUT
        │    ╱  AMP  ╲   │
        │   ╱       ╲   │
        └──╱─────────╲──┘
                │
               GND
```

由虚短/虚断：**VOUT = −IOUT1 × Rf**。

两个「负号 / 正号」要分清：

- **电流侧**：IOUT1 = (D/256) × (VREF/R)，是正的（当 VREF 为正参考时）。
- **电压侧**：反相放大器的传递函数自带负号，所以 VOUT = −(D/256) × VREF，**输出为负**。
- 若希望得到正电压，把 **VREF 接负参考**（如 −5V）即可，公式里的负号与参考的负号相乘得正。

这也解释了公式（条目 6）里那个「−」号的物理来源：**不是 D/A 转换本身有负号，是反相运放
引入的**。

### ② 例题

**真题（课堂练习 AD/DA Q5，判断）**：DAC0832 芯片，可以直接输出模拟电压信号。

```
我的答案：错 ✔    正确答案：错 ✔
答案解析原文：输出为电流，需外接运放转换为电压。
```

**真题（课堂练习 AD/DA Q1 的 C 项，多选）**：「电流输出型（实际中常外接运算放大器，
将输出电流转换为电压信号）」是正确说法 → 选。

两道题从正反两面考同一条：**DAC0832 吐出来的是电流，不是电压**。
本题是送分题，但若记成「DAC 输出的是电压」，条目 6 的公式里那个负号也会一起记错。



DAC0832 的 IOUT1 引脚直接接到电压表，会看到什么？正确接法是什么？

```
直接量：读数无意义（电流源两端电压随负载变化，且电表内阻会改变工作点）。
正确接法：IOUT1 → 运放反相输入端，Rf 接输出端到反相端形成负反馈，同相端接地，
         从运放输出端取 VOUT。
```

### ③ 易错提示

- 本讲易错第 3 条（主文档 §1.3）原话：**「DAC 输出直接量电压（忘接运放/忘负号）」**。
- 写公式时**负号不能丢**；题目问「输出范围」时记得答「−VREF ~ 0」而非「0 ~ VREF」。

### ④ 横向辨析

| | DAC0832 | ADC0809 |
|---|---|---|
| 模拟侧形态 | 电流输出，**必须**外接运放 | 电压输入 IN0~IN7，直接接被测电压 |
| 参考电压引脚 | VREF | VREF(+) / VREF(−)（可双极性） |
| 是否需要「调理电路」 | 需要（I→V，可选双极性） | 需要（信号调理/限幅） |

**记忆钩子**：DAC 是「电流型输出」，ADC 是「电压型输入」。凡是「电流型」就要想着
「怎么把它变成电压」，凡是「电压型」就要想着「别超量程」。

## 4. DAC0832 三种工作方式：直通 / 单缓冲 / 双缓冲

**层级** 掌握 ｜ **来源** `章+网` ｜ **正文** §1.1

### ① 机理详解

三种方式的区别只在**两级锁存各处于什么状态**：

| 方式 | 输入寄存器 | DAC 寄存器 | 特点 | 典型用途 |
|---|---|---|---|---|
| **直通** | 常透明 | 常透明 | 数据一上线就直达网络，无保持 | 调试、连续刷新 |
| **单缓冲** | 常透明 | 受控 | CPU 写数据即刻反映到输出；只需一次写 | **单路输出最常用** |
| **双缓冲** | 受控 | 受控 | 先各自写进输入寄存器，再统一放行 | **多路同步更新** |

单缓冲的两种实现：把 XFER/WR2 常有效（第二级常透明，第一级受控），或反之。
效果一样——CPU 一条 `OUT` 指令就能改变输出。

双缓冲的写序列：

```
① OUT 输入寄存器口, 数据1     ; 各片分别写入（第一级）
   OUT 输入寄存器口, 数据2
   ...
② OUT DAC寄存器口, 任意值     ; 一个统一的 XFER/WR2 脉冲，所有片同时放行
```

### ② 例题

**真题（课堂练习 AD/DA Q3，多选）**：DAC0832 芯片的工作模式包括？

```
正确答案：ABC（全选）
  A 单缓冲模式（最常用）   ✔
  B 双缓冲模式             ✔
  C 直通模式               ✔

我的答案：ABC ✔
```

三种模式的差别与用途见①的表。注意「单缓冲最常用」是题目给的提示语，
也是实际工程的默认选择——单路输出时双缓冲反而多一次 OUT。



用两片 DAC0832 分别驱动 X 轴和 Y 轴偏转，要求两轴电压严格同时变化。问用哪种方式，
写出控制序列。

```
用双缓冲。单缓冲会让先写的那片先变、后写的那片后变，两轴不同步（显示曲线会出现毛刺）。

控制序列（设片1输入口=278H、片2输入口=279H、共用的 DAC 口=27AH）：
      MOV AL, X_DATA
      MOV DX, 278H
      OUT DX, AL          ; 片1数据进它的输入寄存器（输出未变）
      MOV AL, Y_DATA
      MOV DX, 279H
      OUT DX, AL          ; 片2数据进它的输入寄存器（输出仍未变）
      MOV DX, 27AH
      OUT DX, AL          ; XFER+WR2 同时有效 → 两片 DAC 寄存器一起放行
                          ; 此刻 X、Y 两轴输出严格同步改变
```

### ③ 易错提示

- 本讲易错第 4 条（主文档 §1.3）：**「双缓冲的意义答成『更快』（是多路同步）」**。
  双缓冲不会提高单片速度，它解决的是**多片之间的时间一致性**。
- 单缓冲场合写了双缓冲的序列不会出错，只是多一次 OUT；但**双缓冲场合用单缓冲会真的错**
  （失去同步性）。考试问「为什么需要双缓冲」→ 只答「多路同步更新」。

### ④ 横向辨析

| | DAC0832 单缓冲 | DAC0832 双缓冲 | 8253 级联 |
|---|---|---|---|
| 目的 | 单路输出，简化控制 | **多路同步** | 单路分频超 65536 |
| 手段 | 一级锁存一级透明 | 两级都受控 + 统一放行 | 两个计数器接力 |
| 「同时」的含义 | 无 | 多片输出同时变 | 两级计数同时运行 |

**易混点**：8253 的级联也是「两级」，但那是**计数接力**（OUT1→CLK2），
目的是扩展计数范围；DAC0832 的双缓冲是**数据接力**（输入寄存器→DAC 寄存器），
目的是同步更新。两者都叫「两级」，机制完全不同。

## 5. 双缓冲用途 = 多路 DAC 同步更新输出（标准答案）

**层级** 掌握 ｜ **来源** `章+网` ｜ **正文** §1.1

### ① 机理详解

这是本讲最可能出简答题的一条，标准答案句式：

> **双缓冲用于多片 DAC 的同步更新输出**：各片数据先分别写入第一级输入寄存器
> （此时各片输出都还未改变），随后通过一个公共的 XFER/WR2 脉冲同时放行到第二级
> DAC 寄存器，使多路模拟输出在同一时刻刷新。

为什么单缓冲做不到：

```
单缓冲（第二级常透明）：
   t1: OUT 片1 → 片1输出立即变为 V1
   t2: OUT 片2 → 片2输出才变为 V2
   → 在 t1~t2 之间，系统处于 (V1, 旧V2) 的中间态 ✗

双缓冲：
   t1: OUT 片1输入寄存器 → 片1输出不变
   t2: OUT 片2输入寄存器 → 片2输出不变
   t3: OUT 公共 DAC 口  → 两片同时变 ✗→✓
   → 不存在中间态 ✓
```

典型应用：X-Y 绘图仪 / 示波器偏转、多路波形发生器、电机多轴驱动。

### ② 例题

简答题：「DAC0832 为什么要设置两级锁存器？请说明其应用场合。」

```
答：设置两级锁存器是为了实现多片 DAC 的同步更新输出。
工作过程：CPU 先把各片数据分别写入第一级输入寄存器（各级联片的模拟输出此时均保持
原值不变），然后用一个公共的传送控制信号（XFER 与 WR2 同时有效）把各片输入寄存器
中的数据同时送入第二级 DAC 寄存器，使多路模拟输出在同一时刻刷新，避免出现中间态。
应用场合：X-Y 偏转显示、多路波形发生器、多轴电机控制等需要多路模拟量严格同步的
系统。若只有单路输出，用单缓冲即可，无需双缓冲。
```

### ③ 易错提示

- **不能答「提高转换速度」**。D/A 转换本身是并行的，双缓冲不改变转换时间。
- **不能答「增加锁存能力/数据不易丢失」**——那是锁存器的通用功能，不是双缓冲的**设计动机**。
- 标准答案的关键词是「**同步**」与「**多路**」，两个词都要出现。

### ④ 横向辨析

| 问法 | 正确答案关键词 |
|---|---|
| 「双缓冲的用途」 | **多路同步更新** |
| 「单缓冲的用途」 | 单路输出、控制简单 |
| 「直通的用途」 | 调试用 / 连续刷新 |
| 「两级锁存分别叫什么」 | 输入寄存器 + DAC 寄存器 |

## 6. DAC0832 输出电压公式 VOUT = −(D/256) × VREF

**层级** 掌握·必背 ｜ **来源** `章+网` ｜ **正文** §1.1

### ① 机理详解

$$V_{OUT} = -\frac{D}{256} \times V_{REF}$$

其中 D 为输入数字量（0~255，即 00H~FFH），256 = 2^8。

推导链：

```
IOUT1 = (D / 256) × (VREF / R)          # R-2R 网络，第 i 位权重 2^i
VOUT  = −IOUT1 × Rf                     # 反相运放，Rf 常等于 R
      = −(D / 256) × VREF
```

三个推论：

- **D = 00H → VOUT = 0**
- **D = FFH(255) → VOUT = −(255/256) VREF ≈ −0.996 VREF**（注意**不是** −VREF）
- **满刻度（D = 256，比全 1 多一个 LSB）→ VOUT = −VREF**

也就是说 **FFH 对应「满量程减去一个 LSB」**，这是最常考的数字细节。

### ② 例题

VREF = 5V，分别求 D = 00H、80H、C0H、FFH 时的 VOUT。

```
LSB = 5 / 256 = 19.531 mV

D = 00H =   0 → VOUT = −(0/256)×5   =  0.000 V
D = 80H = 128 → VOUT = −(128/256)×5 = −2.500 V
D = C0H = 192 → VOUT = −(192/256)×5 = −3.750 V
D = FFH = 255 → VOUT = −(255/256)×5 = −4.980 V   ← 不是 −5.000 V

验算：255 × 19.531 mV = 4.980 V ✓
```

### ③ 易错提示

- **负号**来自反相运放，不能丢。
- **D = FFH 时输出不是 −VREF**，而是 −(255/256)VREF；「满量程」指 D = 256。
- 若题目要求正输出，会把 VREF 设为负值，此时负负得正——**先判 VREF 极性再代数**。
- 换算时 256 不要写成 255 或 100H。

### ④ 横向辨析

| 公式 | 器件 | 方向 |
|---|---|---|
| `VOUT = −(D/256) × VREF` | **DAC0832** | 数字 → 电压 |
| `D = (VIN/VREF) × 256` | **ADC0809** | 电压 → 数字（条目 14） |

两者是互逆的：把 D/A 的公式解出 D 就得到 A/D 的公式。
**考试如果只记得一个，现场反解另一个**——但两者都是必背，别赌。

## 7. 满量程误差定义（约 ±1 LSB 量级）

**层级** 掌握 ｜ **来源** `章+网` ｜ **正文** §1.1

### ① 机理详解

**满量程误差（Full-Scale Error）= 实际满量程输出 − 理想满量程输出。**

- 理想满量程：D = 256（满刻度）时 VOUT = −VREF。
- 实际满量程：受电阻网络失配、参考电压偏差、运放失调影响，会偏离理想值。
- 量级：**约 ±1 LSB**。

它通常由几部分叠加而成（能说出组成即可，不要求分解计算）：

| 分量 | 来源 |
|---|---|
| 增益误差 | R-2R 电阻比例偏差、VREF 偏差 |
| 零点误差 | 运放输入失调电压 |
| 线性误差（非线性） | 各位权重不成精确 2 的幂 |

**必背的三级误差体系**：零点误差 / 满量程误差 / 线性度（非线性）。
满量程误差可以靠外部调零和增益校准补偿，**线性度不能校准**——所以线性度是 DAC
最根本的精度指标。

### ② 例题

某 8 位 DAC，VREF = 5V，实测满量程输出为 −5.02V。求满量程误差（以 V 和 LSB 表示）。

```
理想满量程 = −VREF = −5.000 V
实际满量程 = −5.020 V
满量程误差 = 实际 − 理想 = −5.020 − (−5.000) = −0.020 V = −20 mV

LSB = 5 / 256 = 19.53 mV
误差 = −20 / 19.53 ≈ −1.02 LSB

答：满量程误差约 −20 mV，即约 −1 LSB（略超 ±1 LSB 量级，属可调校范围）。
```

### ③ 易错提示

- **「约 ±1 LSB 量级」不等于「恰好 ±1 LSB」**，题目给了实测值就要用实测值算。
- 满量程误差是**输出侧的误差**；量化误差（条目 16）是 **A/D 固有的 ±1/2 LSB**，
  两者不是一回事，别混。
- 老师只要求「能写出定义即可」——定义写对就有分，不必推导误差合成。

### ④ 横向辨析

| 误差 | 所属 | 数值 | 能否外部校准 |
|---|---|---|---|
| 量化误差 | **ADC 固有** | ±1/2 LSB | 否（原理决定） |
| 满量程误差 | **DAC 实测** | ~±1 LSB | 可（增益/调零） |
| 线性度误差 | DAC 实测 | ~±1/2 LSB | 否 |

## 8. DAC0832 波形编程：锯齿波 / 三角波 / 方波

**层级** 掌握 ｜ **来源** `章+网` ｜ **正文** §1.1

### ① 机理详解

三种波形本质都是「**往 DAC 端口循环送不同的数**」，差别只在送数的规律：

| 波形 | 送数规律 | 关键指令技巧 |
|---|---|---|
| **锯齿波** | 0,1,2,…,255,0,1,… | `INC AL` 到 FFH 再 INC 回 00H 并置 ZF |
| **三角波** | 0→255 递增，再 255→0 递减 | 两段循环，峰值处转向 |
| **方波** | 交替送 00H / FFH，中间插延时 | `CALL DELAY` 决定占空比与频率 |

**频率由送数节奏决定**：软件延时（NOP/DELAY 循环）最廉价但占用 CPU；
用 8253 定时中断里送数可精确控频，且不占 CPU（这是「DAC + 8253」的典型组合）。

锯齿波用 `INC AL; JNZ` 收尾是一个经典技巧：**AL 从 FFH 加 1 变 00H 时 ZF=1**，
于是恰好执行 256 次后退出，不需要额外的计数器。

### ② 例题

设 DAC 数据口为 278H，写一段产生锯齿波的程序，并说明如何提高其频率。

```asm
DATA    SEGMENT
DATA    ENDS
CODE    SEGMENT
        ASSUME CS:CODE, DS:DATA
START:  MOV AX, DATA
        MOV DS, AX
        MOV DX, 278H         ; DAC0832 数据口（按译码确定）
        MOV AL, 0
SAW:    OUT DX, AL           ; 送当前值
        INC AL               ; AL: 00→01→…→FF→00
        JNZ SAW              ; FFH+1=00H 时 ZF=1，退出本轮
        JMP SAW              ; 立即开始下一轮 → 周期性锯齿波
        MOV AH, 4CH
        INT 21H
CODE    ENDS
        END START
```

> 实际使用时要让主循环周而复始，上面把 `JMP SAW` 放在返回 DOS 前仅为示意结构；
> 交付运行的版本应去掉 4CH 返回或把循环体作为子程序。

提高频率的办法：

```
① 去掉软件延时（本身已无 DELAY，频率已较高）
② 减小延时：把 CALL DELAY_20MS 改成 CALL DELAY_1MS
③ 改用 8253 定时：设好初值后开中断，在中断服务程序里 OUT DX,AL + INC AL，
   CPU 可同时干别的事，频率由 8253 初值精确决定
```

三角波与方波对照：

```asm
; ---- 三角波 ----
        MOV DX, 278H
        MOV AL, 0
UP:     OUT DX, AL
        INC AL
        CMP AL, 0FFH         ; 到峰值
        JNE UP
DOWN:   OUT DX, AL
        DEC AL               ; 255→0
        JNZ DOWN             ; AL=0 时 ZF=1，转上升段
        JMP UP

; ---- 方波 ----
        MOV DX, 278H
HI:     MOV AL, 0FFH
        OUT DX, AL
        CALL DELAY           ; 高电平持续时间
        MOV AL, 0
        OUT DX, AL
        CALL DELAY           ; 低电平持续时间
        JMP HI
```

### ③ 易错提示

- **锯齿波别写成 `CMP AL,0FFH / JE`**——这样在 AL=FFH 那次就退出，会漏掉 0 这一步，
  周期只有 255 而非 256。用 `INC AL; JNZ` 最稳。
- **三角波两段都要有转向判断**，只写递增段会溢出回绕变成锯齿波。
- **方波的延时决定频率**：f ≈ 1/(2×t_delay)（高低各一次延时）。
- 本讲无真题，但这是「掌握」级编程，老师可能作为综合设计题的素材。

### ④ 横向辨析

| | DAC 波形编程 | 8253 方式 3 方波 |
|---|---|---|
| 谁在产生波形 | 软件循环送数 | **硬件计数器**自动翻转 OUT |
| 频率精度 | 受指令周期/延时影响，低 | 由 CLK 与初值精确决定 |
| CPU 占用 | 全程占用 | 不占用（可中断通知） |
| 波形种类 | 任意（软件定义） | 仅方式 2/3 两种固定波形 |

**结论**：要「精确频率的方波」用 8253 方式 3；要「任意形状的慢速波形」用 DAC 软件送数。
两者也常组合：8253 定时中断驱动 DAC 送数。

## 9. DAC0832 双极性电压输出（需再加一级运放）

**层级** 了解 ｜ **来源** `网` ｜ **正文** §1.1

### ① 机理详解

单级反相运放只能得到 **0 ~ −VREF** 的单极性输出。要得到 **−VREF/2 ~ +VREF/2**
的双极性输出，需再加一级运放做**电流求和（加法器）**：

```
                       Rf
        ┌────────────╱╲──────────┐
        │           ╱   ╲        │
IOUT1 ──┤── R ─────╱  OP  ╲──────┴──► VOUT
        │        ╱  AMP   ╲      │
VREF/2 ─┤── R ──╱           ╲────┤
        │   ╱               ╲    │
        └─╱─────────────────╲───┘
```

原理：反相求和放大器把两路电流相加

```
VOUT = −( IOUT1×Rf + (VREF/2)×Rf/R )
     = −( (D/256)×VREF + VREF/2 )
```

于是：

| D | VOUT |
|---|---|
| 00H(0) | −VREF/2 |
| 80H(128) | 0 |
| FFH(255) | +VREF/2 − 1 LSB |

即输出范围被平移并缩放到以 0 为中心——这就是「双极性」。

> 偏移量由一路 VREF/2 提供，通常用电阻分压从 VREF 取得。
> 老师对本条只要求「了解」，**能说出「再加一级运放做电流求和」即可**，
> 不要求推导上面的式子。

### ② 例题

8 位双极性 DAC，VREF = 10V，求 D = 80H 时的输出电压。

```
VOUT = −(D/256 × VREF + VREF/2)
     = −(128/256 × 10 + 5)
     = −(5 + 5) = 0 V
```

即数字量 80H（中点值）对应模拟 0V——这是双极性输出的标志性特征，
与单极性时 00H 对应 0V 不同。

### ③ 易错提示

- **这是单一来源条目**（只有 `网` 源），四源中无老师 PDF / 笔记 / 真题佐证。
  考前只按「了解」准备，若考到能写出「再加一级运放做电流求和实现双极性」即可。
- 别把「双极性输出」和「双缓冲」混——一个是**电压范围**，一个是**锁存级数**。

### ④ 横向辨析

| | 单极性输出 | 双极性输出 |
|---|---|---|
| 运放级数 | 1 级（反相） | **2 级**（反相 + 求和） |
| 输出范围 | 0 ~ −VREF | −VREF/2 ~ +VREF/2 |
| 零点数字量 | 00H | **80H** |
| 老师层级 | 掌握 | 了解 |

# A/D 部分

## 10. ADC0809 结构：8 位、8 通道、SAR、约 100μs、时钟 ~640kHz、单 +5V

**层级** 掌握 ｜ **来源** `章+网` ｜ **正文** §1.2

### ① 机理详解

ADC0809 的数据通路：

```
IN0~IN7 ──► [8 选 1 模拟开关] ──► [比较器] ◄── [D/A 转换器] ◄── [SAR 逐次逼近寄存器]
                  ▲                                                  │
             ADD C/B/A                                                │
                  ▲                                              逐位置 1 试触
                  │                                                  ▼
             ALE 锁存                                          D7~D0 输出（OE 控制）
```

要点分解：

1. **8 位分辨率**：输出 00H~FFH，256 档。
2. **8 个模拟通道 IN0~IN7**：由 ADD C、B、A 三位地址经 8 选 1 开关选择，
   同一时刻只有一个通道接入。
3. **逐次逼近（SAR）原理**〔理解〕：从最高位开始，逐位「试探」——
   先把 D7 置 1 送 D/A 得到参考电压与 VIN 比较，若 VIN 大则保留该位为 1，否则清 0；
   再试 D6……共 8 次比较后得到结果。
   **8 位就需要 8 个时钟周期**，这就是它需要外部时钟的原因。
4. **转换时间约 100μs**：8 位 × 8 个时钟 + 内部建立时间。
   当时钟 ~640kHz（周期约 1.56μs）时，8×1.56 ≈ 12.5μs，加上建立与校准余量，
   手册给出 ≤100μs 的保证值。**课程按 100μs 记**。
5. **单 +5V 供电**：与 TTL 电平兼容，可直接挂 CPU 总线。

SAR 的「二分搜索」特性：n 位转换只需 n 次比较，比双积分快得多，比并行比较省面积。

### ② 例题

**真题（课堂练习 AD/DA Q2，多选）**：ADC0809 芯片是？

```
正确答案：ABCD（全选）
  A 8 位分辨率（256 个量化等级）                  ✔ 对应本条
  B 可依次轮流采集 8 个通道模拟信号               ✔ 对应本条 + 条目 11
  C 逐次逼近型（SAR），转换时间约 100μs           ✔ 对应本条
  D National Semiconductor 开发，后归 TI          ✔ 厂商常识

我的答案：ABCD ✔
```

> **本条新增一个细节**：真题 Q4 的 B 项提示 ADC0809 有 **VREF(+) 与 VREF(−) 两个**
> 参考电压引脚（不是一个）。这意味着：
> - 单极性量程：VREF(−) 接地、VREF(+) 接 +5V → 量程 0~5V
> - 双极性量程：VREF(−) 接 −5V、VREF(+) 接 +5V → 量程 ±5V
>
> 条目 14 的公式 `D = (VIN/VREF)×256` 里的 VREF 应理解为 **VREF(+) − VREF(−)**。
> 初稿只写「VREF」，真题逼出这个区分。



ADC0809 为什么必须有外部时钟？若时钟为 640kHz，8 位转换理论上至少需要多少个时钟周期？

```
因为 SAR 采用逐次逼近，每确定 1 位需要 1 次比较，即 1 个时钟周期；
没有内部振荡器，必须外部提供 CLOCK。

8 位 → 至少 8 个时钟周期（TCLK = 1/640kHz ≈ 1.5625 μs）
      → 8 × 1.5625 ≈ 12.5 μs
手册保证 ≤100 μs（含内部建立时间）。课程口径记 100μs。
```

### ③ 易错提示

- **8 位 ≠ 8 个时钟**是个巧合式的正确关系（SAR 正好 1 位 1 周期），
  但别推广成「n 位 n 周期」的通用规律去答别的 A/D 芯片。
- **640kHz 是典型值不是固定值**，答「约」即可。
- 转换时间 100μs 是**上限保证值**，不是精确值；题目给时钟让算理论周期时用 n×TCLK。

### ④ 横向辨析

| | DAC0832 | ADC0809 |
|---|---|---|
| 转换方式 | R-2R 并行电阻网络 | **SAR 逐次逼近** |
| 位数/速度 | 8 位，建立 ~1μs | 8 位，**≤100μs** |
| 外部时钟 | 不需要 | **必须**（~640kHz） |
| 多「通道」概念 | 无（单路） | **8 路模拟开关** |
| 电源 | VREF + VCC | 单 +5V |

**ADC0809 的「8 通道」与 8255 的「3 个端口」不是一回事**：前者是**模拟多路开关**
（选哪一路被测电压进来），后者是**数字端口**（选哪个数据口读写）。

## 11. ADC0809 通道选择 CBA + ALE 锁存

**层级** 掌握 ｜ **来源** `章+网` ｜ **正文** §1.2

### ① 机理详解

8 个模拟通道由 **ADD C、ADD B、ADD A** 三位地址选择：

| C | B | A | 选中通道 |
|---|---|---|---|
| 0 | 0 | 0 | IN0 |
| 0 | 0 | 1 | IN1 |
| 0 | 1 | 0 | IN2 |
| 0 | 1 | 1 | IN3 |
| 1 | 0 | 0 | IN4 |
| 1 | 0 | 1 | IN5 |
| 1 | 1 | 0 | IN6 |
| 1 | 1 | 1 | IN7 |

**ALE（Address Latch Enable）** 的作用：地址线 C/B/A 是 CPU 数据总线分时送出的，
ALE 的**上升沿**把这一刻的 C/B/A 电平锁进芯片内部的地址锁存器，
此后即使数据总线变了，选中的通道也不变。

> 若 ALE 常低（不锁存），通道选择会随数据总线上的后续数据漂移——
> 这就是易错第 2 条「只写 CBA 不发 ALE，转换的还是上一个通道」的机理。

### ② 例题

**真题（课堂练习 AD/DA Q4，多选）**：ADC0809 芯片引脚功能，下列说法正确的有？

```
正确答案：ABCD（全选）
  A ALE 为地址锁存允许                ✔ 对应本条
  B VREF(+) 和 VREF(−) 为参考电压输入  ✔ 对应条目 10（双参考引脚）
  C CLK 为时钟输入，需外部提供         ✔ 对应条目 10（SAR 需 8 个时钟）
  D OE 为输出允许，高电平时数据输出    ✔ 对应条目 12

我的答案：ABCD ✔
```

四条全对，且四条分别落在本讲四个条目上——这是一道「一题串四题」的综合题。
ALE 的上升沿锁存细节见①。



要把被测信号接到 IN5，问 ADD C/B/A 应为什么电平，并说明 ALE 何时有效。

```
IN5 = 二进制 101 → C=1, B=0, A=1
操作：把 05H 送到数据线，然后给 ALE 一个正脉冲（上升沿锁存）。

MOV AL, 05H        ; CBA = 101
OUT CH_PORT, AL    ; 送通道号（该口的译码同时产生 ALE 正脉冲）
```

> 端口分配按实验箱译码确定：有的箱子上「写通道口」这一个 OUT 动作就同时产生
> ALE 与 START；也有分成两个口分别控制的。**以所用实验箱的接线图为准**。

### ③ 易错提示

- 本讲易错第 2 条（主文档 §1.3）：**「只写 CBA 不发 ALE → 转换的还是上一个通道」**。
- **C 是最高位**：IN5 = 101B 写成 05H，不要写成 50H 或把 CBA 顺序颠倒成 A 最高。
- ALE 是**上升沿锁存**（与 8086 的 ALE 同沿），不是电平有效。

### ④ 横向辨析

| 信号 | 所属芯片 | 作用对象 | 锁存内容 |
|---|---|---|---|
| **ALE** | ADC0809 | 模拟开关地址 | 通道号 C/B/A |
| **ALE** | 8086 CPU | 地址锁存器 74LS373 | A0~A19 + BHE（21 位） |
| **ALE** | 8086 CPU | 与 ADC0809 的 ALE 同名不同物 | — |

**同名不同物**：两个 ALE 都是「地址锁存使能、上升沿锁存」，但 8086 的 ALE 锁的是
**CPU 发出的地址**（为了地址/数据总线复用），ADC0809 的 ALE 锁的是**通道选择码**。
考试若同时出现，注意区分锁的是什么。

## 12. 控制信号时序：START 上升沿复位/下降沿启动；EOC 转换中低、结束高；OE 有效才输出

**层级** 理解 ｜ **来源** `章+网` ｜ **正文** §1.2

### ① 机理详解

三个控制信号的分工：

| 信号 | 有效方式 | 作用 |
|---|---|---|
| **ALE** | 上升沿 | 锁存通道地址 C/B/A |
| **START** | 正脉冲 | **上升沿**复位内部 SAR；**下降沿**启动一次转换 |
| **EOC** | 电平输出 | **转换过程中为低**；转换结束**变高** |
| **OE** | 高有效 | 为高时 D7~D0 输出三态门打开，才可读数据 |

完整时序：

```
   ALE  ──┐
          └──┐
             └────────────  (锁存 CBA)

  START        ┌──┐
               │  └────────  (上升沿复位 SAR，下降沿启动转换)

   EOC  ───────┐   ┌────────  转换中：低；结束：高
               └───┘
               ├─ 转换中 ─┤

    OE                     ┌──────────  为高才输出数据
                           │
   D7~D0 ～～～～～～～～～ valid ～～～  仅 OE=高 期间有效
```

**EOC 的妙用**：它既是「转换完成标志」，也可以反相连到 CPU 的中断输入（INTR），
用中断方式代替查询方式——EOC 上升沿请求中断，服务程序里读数。

### ② 例题

**真题（课堂练习 AD/DA Q4 的 C、D 项）**：CLK 需外部提供？OE 高电平时数据输出？

```
C：正确。ADC0809 无内部振荡器，CLK 必须外部提供（典型 ~640kHz）。
   → 这正是它与 DAC0832 的一大差别：DAC0832 不需要时钟。
D：正确。OE（Output Enable）高有效，为高时 D7~D0 三态门打开才可读。
   → 与 8255A 的 RD̄ 不同，ADC0809 的 OE 是**高**有效。
```



画出一次完整转换中 START、EOC、OE 的电平变化顺序，并说明 CPU 应在何时读数。

```
顺序：
① ALE 上升沿 → 锁存通道号
② START 上升沿 → SAR 复位
③ START 下降沿 → 转换开始，EOC 变低
④ 等待 EOC 由低变高（约 100μs）
⑤ OE 置高 → D7~D0 输出有效
⑥ CPU 执行 IN 读数

读数时机：必须在「EOC 已变高」且「OE 已有效」之后。
提前读会拿到上一次的残留值或高阻态。
```

### ③ 易错提示

- 本讲易错第 1 条（主文档 §1.3）：**「EOC 极性反：转换中低、结束高」**。
  记法：**EOC = End Of Conversion**，名字就是说「转换结束它为高」。
- **START 的正脉冲不能省**：只给下降沿（如一次写操作自然产生的高低变化）可能不足以
  保证 SAR 已复位。老师原话强调「启动前要不断检测是否已开始转换」——就是这个时序细节。
- **OE 不给就读不出数据**：D7~D0 是高阻三态，读到的是 0FFH 或总线残留值。

### ④ 横向辨析

| | ADC0809 | 8251A |
|---|---|---|
| 「忙」标志 | **EOC（低=忙）** | 状态字 D0 TxRDY / D1 RxRDY |
| 极性 | 忙=低，闲=高 | 就绪=1 |
| 读取方式 | 查询 EOC 或中断 | 查询状态字或中断（引脚） |
| 数据使能 | **OE** | 无（读数据口即可） |

**极性记忆**：ADC0809 的 EOC 是「低有效表示忙」，而绝大多数「就绪」类标志是「高有效」。
这是本讲最容易记反的一处。

## 13. ADC0809 转换四步流程（选通道→START→等 EOC→OE 读数）

**层级** 掌握·必背 ｜ **来源** `章+网` ｜ **正文** §1.2

### ① 机理详解

必背的四步，一步不能乱：

```
① 送通道号（CBA）并给 ALE 锁存
② 发 START 正脉冲启动转换
③ 等 EOC 由低变高（查询或中断）
④ OE 有效后读走 D7~D0
```

为什么这个顺序不可交换：

- ① 必须先于 ②：通道没锁好就启动，转换的是错误通道。
- ② 必须先于 ③：不启动就永远等不到 EOC 变高（EOC 在空闲时本就是高）。
- ③ 必须先于 ④：数据锁存器在转换期间不更新，提前读是旧值。
- ④ 是最后一步：OE 只是打开输出门，不影响转换本身。

「查询 / 中断」两种等待方式的取舍：查询简单但占 CPU；中断高效但要设向量、
开中断、写服务程序（第6讲内容）。

### ② 例题

默写四步流程，并指出哪一步可以改为中断方式。

```
① 送通道号 CBA，ALE 锁存
② 发 START 正脉冲（上升沿复位、下降沿启动）
③ 查询 EOC 由低变高   ← 这一步可改为中断方式（EOC 反相连 INTR，上升沿请求）
④ OE 置高，读 D7~D0

若改中断方式：主程序里设好中断向量、STI、允许该 IR，然后去干别的事；
EOC 上升沿触发中断，服务程序里 OE 有效 + IN 读数 + EOI + IRET。
```

### ③ 易错提示

- **四步是「掌握·必背」级**，主文档原文即要求能完整默写。
- **不要漏掉 ①的 ALE**：只送 CBA 不锁存等于没选通道（易错第 2 条）。
- **不要把 OE 提到 ③ 之前**：OE 不与 EOC 联动，早开 OE 只会更早暴露无效数据。
- 简答题若问「完整的采集流程」，四步之后通常还要加「**保存数据**」一步。

### ④ 横向辨析

| 步骤 | ADC0809 | 8251A 接收一字节 | 8253 启动一个计数器 |
|---|---|---|---|
| 1 | 送通道号 + ALE | 写方式字（复位后） | 写控制字 |
| 2 | 发 START | 写命令字（允许收发） | 写计数初值 |
| 3 | 等 EOC 变高 | 查 RxRDY（先查错误） | 写完即自动启动 |
| 4 | OE 有效后读数 | IN 数据口 | 读 OUT / 锁存计数值 |

**共同模式**：「选对象 → 下命令 → 等就绪 → 取数据」。三个芯片都是这个套路，
差别只在就绪标志的极性（EOC 高=就绪，TxRDY 1=就绪）与启动方式（脉冲 / 电平 / 自动）。

## 14. 数字量换算 D = (VIN/VREF) × 256 及反推 VIN

**层级** 掌握 ｜ **来源** `章+网` ｜ **正文** §1.2

### ① 机理详解

$$D = \frac{V_{IN}}{V_{REF}} \times 256 \qquad
V_{IN} = \frac{D \times V_{REF}}{256}$$

其中 VREF 是参考电压（满量程对应的输入电压），256 = 2^8。

推导：满量程 VREF 对应数字量 256（比全 1 多一个 LSB），所以

```
D / 256 = VIN / VREF   →   D = (VIN/VREF) × 256
```

注意：**D 取整数，向下取整（或四舍五入，按题目要求）**。
这也解释了量化误差的来源（条目 16）：VIN 落在两个量化电平之间，只能取其一。

### ② 例题

VREF = 5V，求 VIN = 1.25V 和 VIN = 3.6V 时的 D 值；若 D = 0C0H，反推 VIN。

```
(1) VIN = 1.25V:
    D = (1.25/5) × 256 = 0.25 × 256 = 64 = 40H

(2) VIN = 3.6V:
    D = (3.6/5) × 256 = 0.72 × 256 = 184.32 → 取整 184 = B8H

(3) D = 0C0H = 192:
    VIN = (192 × 5) / 256 = 960/256 = 3.75 V
```

### ③ 易错提示

- **分母是 VREF 不是 VCC**：ADC0809 的 VREF(+) 引脚决定量程，与 +5V 供电无关。
- **乘 256 不是乘 255**：全 1（255）对应「满量程减一个 LSB」。
- **别忘了取整**：算出 184.32 要处理成整数，题目未说明时按「截断」并注明。
- 反推时 `D × VREF / 256` 的顺序不影响结果，但**先乘后除**可减少中间小数。

### ④ 横向辨析

| | ADC0809 | DAC0832 |
|---|---|---|
| 公式 | `D = (VIN/VREF) × 256` | `VOUT = −(D/256) × VREF` |
| 已知求 | 已知 VIN 求 D | 已知 D 求 VOUT |
| 互逆 | 把 DAC 公式解出 D 即得 | 把 ADC 公式解出 VIN 即得 |
| 256 的角色 | 量程档数 | 量程档数 |

**考试技巧**：两式互为逆运算，记住一个就能推出另一个。但都是必背，直接写更省时间。

## 15. ADC0809 采集编程：单通道子程序 / 循环 8 路存内存

**层级** 掌握 ｜ **来源** `网` ｜ **正文** §1.2

### ① 机理详解

这是把四步流程（条目 13）落成代码。两种结构：

**单通道采集子程序**：封装四步，入口给通道号，出口给结果。
**循环 8 路**：外层循环让通道号 0→7，每路调一次子程序，结果依次存内存。

保存现场的三条铁律（来自第4讲子程序规则）：

- 子程序内改了 BX/CX/SI 等，调用前要 `PUSH`、返回前要 `POP`；
- 用 `[BX]` 存结果并 `INC BX`，比用 `[SI+n]` 直观；
- CX 作外层循环计数器，子程序内不要动 CX。

端口命名按实验箱译码确定，下面代码用符号名表示，实际值由接线图决定。

### ② 例题

写一个单通道采集子程序（入口 AL = 通道号，出口 AL = 转换结果），
再写主程序循环采集 8 路存入 BUF。

```asm
DATA    SEGMENT
BUF     DB 8 DUP(?)
DATA    ENDS
CODE    SEGMENT
        ASSUME CS:CODE, DS:DATA

; ---------------------------------------------------------------
; GETADC：采集一路。入口 AL=通道号(0~7)，出口 AL=转换结果
; 端口：CH_PORT 通道锁存口、ST_PORT 启动口、EOC_PORT 状态口、DATA_PORT 数据口
; ---------------------------------------------------------------
GETADC  PROC
        PUSH DX
        PUSH BX                ; 保护现场
        MOV  BL, AL            ; 记住通道号（ALE 之后 AL 还会被复用）

        MOV  AL, BL            ; ① 送通道号
        MOV  DX, CH_PORT
        OUT  DX, AL            ;    该口译码产生 ALE 正脉冲，锁存 CBA

        MOV  DX, ST_PORT       ; ② 发 START 正脉冲
        OUT  DX, AL            ;    先写高
        NOP                    ;    保证脉冲宽度
        IN   AL, DX            ;    再写低（形成下降沿 → 启动转换）

        MOV  DX, EOC_PORT      ; ③ 等 EOC 由低变高
POLL:   IN   AL, DX
        TEST AL, EOC_BIT
        JZ   POLL              ;    低=转换中，继续等

        MOV  DX, DATA_PORT     ; ④ OE 已有效，读数
        IN   AL, DX            ;    AL = 转换结果
        POP  BX
        POP  DX
        RET
GETADC  ENDP

; ---------------------------------------------------------------
; 主程序：循环采集 8 路，结果依次存入 BUF
; ---------------------------------------------------------------
START:  MOV  AX, DATA
        MOV  DS, AX
        MOV  BX, OFFSET BUF    ; 存放指针
        MOV  CX, 8             ; 8 个通道
        MOV  SI, 0             ; 通道号 0~7
NEXT:   PUSH CX                ; 保护外层计数器
        PUSH SI                ; 保护通道号
        MOV  AL, SI            ; 入口：AL = 通道号
        CALL GETADC            ; 出口：AL = 该通道结果
        POP  SI
        POP  CX
        MOV  [BX], AL          ; 存入缓冲区
        INC  BX                ; 指针后移
        INC  SI                ; 下一个通道
        LOOP NEXT              ; CX=0 时采完 8 路

        MOV  AH, 4CH
        INT 21H
CODE    ENDS
        END START
```

**代码要点对照四步流程**：

| 四步 | 对应代码 |
|---|---|
| ① 送通道号 + ALE | `MOV AL,BL / OUT CH_PORT,AL` |
| ② START 正脉冲 | `OUT ST_PORT,AL` 后 `IN AL,DX`（形成下降沿） |
| ③ 等 EOC | `POLL: IN AL,DX / TEST AL,EOC_BIT / JZ POLL` |
| ④ OE 后读数 | `IN AL,DATA_PORT` |

> 端口的实际值（CH_PORT / ST_PORT / EOC_PORT / DATA_PORT / EOC_BIT）取决于实验箱
> 译码接线，本代码不绑定具体地址。**OE 若非常有效，需在读数前先写 OE 口**。

### ③ 易错提示

- **这是单一来源条目**（只有 `网` 源），仓库内无 ADC 参考程序、无真题。
  准备时以「四步流程正确 + 现场能写查询循环」为目标，不必逐字背某份标准答案。
- **主循环的 CX 必须保护**：`CALL GETADC` 内部若用了 CX 或改了标志，会破坏 `LOOP`。
  上面用 `PUSH CX / POP CX` 包住调用。
- **通道号在 ALE 之后不能丢**：上面用 BL 暂存，因为 ③④ 会反复用 AL。
- `TEST AL, EOC_BIT` 的位号取决于 EOC 接在数据线哪一位（常接 D0 或 D7）。

### ④ 横向辨析

| | ADC0809 查询采集 | 8251A 查询收发 | 8253 读取当前值 |
|---|---|---|---|
| 就绪判据 | EOC 由低变高 | 状态字 D0/D1 = 1 | 无需等待 |
| 保护现场 | CX / SI | SI / DI 指针 | 无 |
| 循环对象 | 8 个通道 | 缓冲区长度 | — |
| 等待指令 | `TEST + JZ` | `TEST + JZ/JNZ` | 直接 IN |

**共同点**：都是「查询标志位 → 满足则操作」的模式，用 `TEST` + 条件转移实现。
差别只在**标志极性**：ADC0809 的 EOC 忙时为低（`JZ POLL` 继续等），
8251A 的 TxRDY 就绪时为 1（`JZ SEND` 继续等）——**两者恰好相反**，是最常写错的地方。

## 16. 量化误差 ±1/2 LSB（8 位 5V 量程 ≈ 9.8mV）

**层级** 掌握 ｜ **来源** `网` ｜ **正文** §1.3

### ① 机理详解

A/D 转换只能输出有限个离散码，而 VIN 是连续的。量化就是把 VIN 「四舍五入」
到最近的一个量化电平，这个近似带来的最大偏差就是**量化误差**：

```
量化电平间隔 = LSB = VREF / 2^n
最大量化误差 = ±1/2 LSB
```

为什么是 1/2：VIN 落在第 k 与第 k+1 两个电平之间时，最坏情况是正好在中点，
此时无论取 k 还是 k+1，偏差都是半个 LSB。

对 8 位、VREF = 5V：

```
LSB = 5 / 256 = 19.531 mV
±1/2 LSB = ±9.766 mV ≈ ±9.8 mV
```

**这是原理性误差，无法靠校准消除**——要提高精度只能增加位数 n
（n 每加 1，LSB 减半）。

### ② 例题

12 位 A/D、VREF = 10V，求 LSB 与最大量化误差。

```
LSB = 10 / 2^12 = 10 / 4096 = 2.4414 mV
±1/2 LSB = ±1.2207 mV ≈ ±1.22 mV

对比 8 位 10V：LSB = 10/256 = 39.06 mV，±1/2 LSB = ±19.53 mV
→ 位数从 8 升到 12，量化误差降到约 1/16（每加 1 位减半，加 4 位 → 1/16）✓
```

### ③ 易错提示

- **量化误差属于 A/D，不属于 D/A**。D/A 没有量化误差，它有满量程误差 / 线性度（条目 7）。
- **±1/2 LSB 不是 ±1 LSB**：±1 LSB 是 DAC 满量程误差的量级。
- 8 位 5V 的 **9.8mV** 是要求记住的具体数字（主文档 §1.3 原值）。
- 计算时 **2^n** 不要写成 2^n − 1：n 位有 2^n 个间隔。

### ④ 横向辨析

| | 量化误差 | 满量程误差 | 线性度误差 |
|---|---|---|---|
| 器件 | **ADC 固有** | DAC 实测 | DAC 实测 |
| 数值 | **±1/2 LSB** | ~±1 LSB | ~±1/2 LSB |
| 成因 | 有限离散电平 | 电阻/参考/运放偏差 | 各位权重不成 2 的幂 |
| 可否校准 | **否** | 可 | 否 |
| 降低手段 | 增加位数 | 外部调零/增益校准 | 换更高精度器件 |
