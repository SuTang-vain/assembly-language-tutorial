# 第01讲 基础知识（绪论）· 逐考点详解

## 本讲是什么 & 为什么考

**先从一个问题说起**：计算机只认识 0 和 1，那数、字母、符号怎么存进去？

答案只有一条：**事先约定一套编码**。数要换算成二进制（于是有了数制转换、
原码/反码/补码），字母和符号要查一张对照表（于是有了 ASCII）。**数制与编码
就是这门课的字母表**——后面 8086 的地址与指令机器码、各接口芯片的命令字，
追到根上全是本讲的内容换个场合出现。

⚠ 但本讲情况特殊：老师 PDF 原话标了「（无需复习）」，所以这段动机也从简，
只点一句——虽不细考，**ASCII 大小写差 20H、十六进制必须以数字开头**这类规矩，
是后面每一讲读程序、写程序时默认你已经会的地基，地基松了处处绊脚。

## 本讲学习目标

学完本讲，你应该能：

1. **默写常用 ASCII**：'A'=41H、'a'=61H、'1'=31H、'0'=30H，会用「大小写差 20H」
   互转大小写、用 ±30H 在数字与字符间换算（条目 158）。
2. **说出发展脉络**：4004→8008/8080→8086→80386→Pentium（条目 159）。
3. **写对十六进制**：必须以数字开头，字母开头时补前导 0（条目 160）。
4. **分清三大总线**：数据 / 地址 / 控制总线各管什么（条目 161）。
5. **做数制与补码运算**：进制互转、原/反/补码换算、溢出判断，写得出
   8 位补码范围 −128~+127（条目 162）。

> 对应总清单第 **158~162** 条，覆盖本讲全部 5 个考点。

## 158. 常用 ASCII：'A'=41H、'a'=61H、'1'=31H、'0'=30H（大小写差 20H）

**层级** 掌握 ｜ **来源** `章+题` ｜ **作业题** 第1讲Q1 ｜ **正文** §十

### ① 机理详解

写汇编程序天天要用的 ASCII 码：

| 字符 | ASCII | 备注 |
|---|---|---|
| **'A'** | **41H** | 大写 A |
| **'a'** | **61H** | 小写 a |
| **'1'** | **31H** | 数字 1 |
| **'0'** | **30H** | 数字 0 |

**两条规律比硬背更有用**：

```
① 大小写差 20H：'A' = 41H，'a' = 41H + 20H = 61H
   → 大写转小写：OR AL, 20H
     小写转大写：AND AL, 0DFH（清 bit5）

② 数字字符连续：'0'~'9' = 30H~39H
   → 数字 n 的字符 = n + 30H
     字符转数字：SUB AL, 30H
```

**作业第1讲 Q1** 原题（连线题）：常见字符及其对应的十六进制代码。

```
'A' → 41H
'1' → 31H
'a' → 61H
（大小写、数字都要连对）
```

### ② 例题

把 AL 中的大写字母转成小写，再转成数字 '5'。

```
① 大写 → 小写：OR AL, 20H
   'C' = 43H → 43H ∨ 20H = 63H = 'c' ✔

② 数值 5 → 字符 '5'：OR AL, 30H 或 ADD AL, 30H
   05H ∨ 30H = 35H = '5' ✔
```

### ③ 易错提示

- **'1' = 31H 不是 01H**：老师 p48 易错清单第 1 条「数字结尾 B/H 不可省」的姊妹点。
- **大小写差 20H**（不是 10H 或 40H）。
- **数字字符减 30H 得数值**——这是第4讲 4.12（键入数字查表）的第一步。
- 主文档 §7.1 还列了 **CR=0DH、LF=0AH、'$'=24H**（DOS 串结尾），
  详见第04讲条目 105。

### ④ 横向辨析

| 字符 | ASCII | 二进制 |
|---|---|---|
| '0' | **30H** | 0011 0000 |
| '9' | 39H | 0011 1001 |
| 'A' | **41H** | 0100 0001 |
| 'a' | **61H** | 0110 0001 |
| 'Z' | 5AH | 0101 1010 |
| 'z' | 7AH | 0111 1010 |
| '$' | 24H | 0010 0100 |
| CR | 0DH | |
| LF | 0AH | |

## 159. 微处理器发展史：4004→8008/8080→8086→80386→Pentium

**层级** 了解 ｜ **来源** `章+题` ｜ **作业题** 第1讲Q2 ｜ **正文** §十

### ① 机理详解

**作业第1讲 Q2** 原题（连线题）：微处理器的主要发展历史及典型产品。

| 代际 | 典型产品 | 位数 |
|---|---|---|
| 第一代 | **4004** | **4 位** |
| 第二代 | **8008 / 8080** | **8 位** |
| 第三代 | **8086 / 8088** | **16 位** |
| 第四代 | **80386** | **32 位** |
| 第五代 | **Pentium（奔腾）** | 32/64 位 |

**只需记住这条链**：

```
4004 → 8008/8080 → 8086 → 80386 → Pentium
4位    8位         16位    32位     32/64位
```

**几个易混点**：

- **4004 是 4 位**（Intel 1971 年，世界第一片微处理器）。
- **8088 也是 16 位**（准 16 位，见第02讲条目 139），不是 8 位产品。
- **80286 是 16 位**（第三代后期），**80386 才是 32 位**。
- 本课程只讲 8086/8088，后续代际了解即可。

### ② 例题

「32 位微处理器」的典型产品是哪一代？8088 属于哪一代？

```
32 位 → 第四代 → 80386（及以后的 80486）
8088 → 第三代（16 位，准 16 位）

注意：8088 虽是「准 16 位」，仍归第三代，不是第二代。
```

### ③ 易错提示

- **老师 PDF 对本讲整体标「无需复习」**，本条只按「了解」准备——能连出链条即可。
- **8088 不是 8 位产品**（它是 16 位内核、8 位外部数据线）。
- **80286 ≠ 32 位**（它是 16 位）。
- 作业 Q2 是连线题，连错一代整题错，务必记准链条。

### ④ 横向辨析

| 位数 | 典型产品 |
|---|---|
| 4 | **4004** |
| 8 | **8008 / 8080** |
| 16 | **8086 / 8088 / 80286** |
| 32 | **80386 / 80486** |
| 32/64 | **Pentium** |

## 160. 十六进制写法规范：必须以数字开头

**层级** 掌握 ｜ **来源** `师+题` ｜ **作业题** 第1讲Q3 ｜ **正文** §十

### ① 机理详解

**本课程十六进制数的写法规则**：

```
① 必须以「H」结尾（H = Hexadecimal，十六进制）
② 必须以**数字**开头——字母开头的要在最前面补 0
```

**作业第1讲 Q3** 原题（多选题）：以下符合本课程十六进制数写法的是？

| 选项 | 写法 | 判定 | 原因 |
|---|---|---|---|
| **A** | **0F1H** | **✔ 合法** | 数字 0 开头 + H 结尾 |
| **B** | **16** | **✘ 不合法** | **缺 H 后缀 → 表示十进制 16** |
| **C** | **16H** | **✔ 合法** | 数字开头 + H 结尾（= 22D） |
| **D** | **3FH** | **✔ 合法** | 数字开头 + H 结尾（= 63D） |

```
我的答案：ACD ✔
正确答案：ACD ✔

答案解析原文：
「H 代表十六进制，缺失则表示十进制；如果以字母开头，须在最前面加零（0）」
```

**「补 0」的实例**：

| 错误写法 | 正确写法 | 数值 |
|---|---|---|
| `FFH` | **`0FFH`** | 255 |
| `F2H` | **`0F2H`** | 242 |
| `ABH` | **`0ABH`** | 171 |

**为什么不能省 H**：`16` 与 `16H` 在本课程是**不同的数**：

```
16   = 十进制 16    = 10H
16H  = 十六进制 16  = 22D（十进制 22）
```

这是老师 p48 易错清单第 1 条「数字结尾 B/H 不可省」的十六进制版本。

### ② 例题

判定下列写法的合法性，非法的改正：

```
① MOV AL, 0FFH        ✔ 合法（已补 0）
② MOV AL, FFH         ✘ 应改为 0FFH
③ OUT 0F2H, AX        ✔ 合法（已补 0，且 242 ≤ FFH 可直接寻址）
④ MOV AX, 16          ✔ 合法——但它是**十进制 16**，不是 16H！
                       若要十六进制 16，必须写 16H
⑤ MOV AL, 3FH         ✔ 合法
```

### ③ 易错提示

- **老师 p48 易错清单第 1、2 条都在这**：
  「结尾缺失报错」（`01001010` 漏 B、`INT 21` 漏 H）、
  「字母开头补 0」（`FFH` → `0FFH`、`F2` → `0F2H`）。
- **`16` 与 `16H` 数值不同**（10H vs 22D），别混。
- **`0F1H` 合法**（Q3 选项 A）：数字 0 开头满足「以数字开头」。
- 与第05讲条目 103 的澄清联动：`0F2H` 补了 0 之后**仍在 ≤FFH 范围内**，
  所以 `OUT 0F2H, AX` 合法——「补 0」与「超范围」是两件独立的事。

### ④ 横向辨析

| 需求 | 写法 |
|---|---|
| 十六进制 255 | **0FFH**（不能写 FFH） |
| 十六进制 242 | **0F2H**（不能写 F2H） |
| 十六进制 241 | **F1H** ✔（F 开头本身没问题？不——F1H 字母开头，应写 0F1H） |
| 十进制 16 | **16**（不带 H） |
| 十六进制 16 | **16H** |
| 二进制 8 位 | 必须带 **B**（如 `01001010B`） |

> ⚠ **F1H 也要补 0**：任何以 A~F 开头的十六进制数都要补 0。
> `F1H` → `0F1H`、`ABH` → `0ABH`、`FFH` → `0FFH`。

## 161. 三大总线：数据总线 / 地址总线 / 控制总线

**层级** 掌握 ｜ **来源** `章+题` ｜ **作业题** 第1讲Q4 ｜ **正文** §十

### ① 机理详解

**作业第1讲 Q4** 原题（多选题）：被称为「三大总线」（Three Primary Buses）的是哪三项？

```
正确答案：BDG
  B = 控制总线（Control Bus, CB）
  D = 地址总线（Address Bus, AB）
  G = 数据总线（Data Bus, DB）

我的答案：BDG ✔
```

**三大总线的分工**：

| 总线 | 传什么 | 方向 | 位数（8086） |
|---|---|---|---|
| **数据总线 DB** | **数据** | **双向** | 16（8088 为 8） |
| **地址总线 AB** | **地址** | **单向**（CPU 发出） | 20 |
| **控制总线 CB** | **控制/状态信号** | 混合 | 若干 |

**控制总线上跑的信号**（本课程常见的）：

```
RD̄ / WR̄     读写控制
M/IŌ        存储器 / I/O 选择
ALE          地址锁存
BHĒ          高字节允许
INTR / INTĀ  中断请求 / 响应
READY        就绪
DT/R̄ / DEN̄  数据收发方向 / 使能
RESET        复位
```

**干扰项为什么错**（Q4 的 A/C/E/F）：

| 选项 | 为什么不选 |
|---|---|
| A 系统总线 | 是「三大总线的集合」的上位概念，不是其中一项 |
| C 信号总线 | **不存在**这个标准术语 |
| E 串行总线 | 是「按传送方式」分类，不是三大总线之一 |
| F 输入/输出总线 | I/O 总线是控制/数据总线的应用，不是三大总线之一 |

### ② 例题

某 CPU 有 20 根地址线、16 根数据线，问内存寻址空间多大？三大总线各传什么？

```
寻址空间 = 2^20 = 1MB

三大总线：
· 数据总线（16 根，双向）→ 传数据
· 地址总线（20 根，单向）→ 传地址
· 控制总线 → 传 RD̄/WR̄/M/IŌ/ALE 等控制与状态信号
```

### ③ 易错提示

- **三大总线 = 数据 / 地址 / 控制**（Q4 答案 BDG）。
- **数据总线双向、地址总线单向**——方向别记反。
- **地址线 20 根 → 1MB**：`2^20 = 1048576 = 1MB`。
- **「系统总线」不是三大总线之一**，它是三者的总称（Q4 干扰项 A）。
- 与第05讲条目 97「总线 vs 接口」联动：总线共享，接口点对点。

### ④ 横向辨析

| | 数据总线 | 地址总线 | 控制总线 |
|---|---|---|---|
| 传内容 | **数据** | **地址** | 控制/状态信号 |
| 方向 | **双向** | **单向**（CPU→外） | 混合 |
| 8086 位数 | **16** | **20** | 若干 |
| 对应寻址 | — | 2^20 = 1MB | — |

## 162. 数制转换、原码/反码/补码、溢出判断；8 位补码范围 −128~+127、80H=−128

**层级** 掌握 ｜ **来源** `章+网` ｜ **作业题** 第1讲Q5 ｜ **正文** §十

### ① 机理详解

**三种机器数表示**（以 8 位 −5 为例）：

| 表示法 | 规则 | −5 的表示 |
|---|---|---|
| **原码** | 最高位符号位 + 数值位 | 1000 0101B = **85H** |
| **反码** | 正数同原码；负数**数值位取反** | 1111 1010B = **FAH** |
| **补码** | 反码 + 1 | 1111 1011B = **FBH** |

**8086 用补码**（加减法统一，符号位参与运算）。

**补码速算口诀**（主文档 §十）：

> **「从右往左第一个 1 右边不变，左边取反」**

以 −5 的补码 `1111 1011` 为例，反推原码：

```
   1 1 1 1 1 0 1 1
              ↑ 从右往左第一个 1
        右边（1 1）不变
        左边（1 1 1 1 1 0）取反 → 0 0 0 0 0 1 0
   → 原码 = 0000 0101 = +5
   加上符号位 1 → 1000 0101 = −5 ✔
```

**8 位补码的范围**：

```
8 位补码：−128 ~ +127
  · 最大值 +127 = 7FH（0111 1111）
  · 最小值 −128 = 80H（1000 0000）
  · **80H = −128**（不是 −0，补码没有 −0）
```

**为什么范围不对称**：8 位有 256 个编码，0 占一个（00H），
剩下 255 个分正负 → 负数多一个 → −128 ~ +127。

**溢出判断**：

| 方式 | 判据 |
|---|---|
| **单符号位** | 双正得负 / 双负得正 → 溢出 |
| **双符号位（变形补码）** | 两位符号位**不同** → 溢出 |

```
例：+127 + 1
  0111 1111（+127）
+ 0000 0001（+1）
= 1000 0000（−128）  ← 双正得负 → **溢出**
  结果 80H 在补码里表示 −128，不是 +128（+128 表示不了）
```

**作业第1讲 Q5** 原题（单选题）：`12345678H` 存于 10000H 开始的内存，
小端模式下地址 10000H 的内容是？

```
答：78H（小端：低字节存低地址）
（完整推演见第02讲条目 156）
```

### ② 例题

求 −1 的 8 位补码，并验算 5 + (−1)。

```
① −1 的补码：
   原码 1000 0001 → 反码 1111 1110 → 补码 1111 1111 = FFH

② 5 + (−1)：
   0000 0101（+5）
 + 1111 1111（−1）
 ───────────
 1 0000 0100   → 取低 8 位 0000 0100 = +4 ✔
   （第 9 位的进位自然丢弃，这正是补码的好处）
```

**溢出判据练习**：`80H + 80H`（−128 + −128）

```
  1000 0000（−128）
+ 1000 0000（−128）
= 1 0000 0000 → 低 8 位 0000 0000 = 0

双负得正（结果符号位 0）→ **溢出**
真实结果应是 −256，8 位补码表示不了
```

### ③ 易错提示

- **8 位补码范围 −128 ~ +127**，`80H = −128`（必背）。
- **补码没有 −0**：`00H` 是 0，`80H` 是 −128。
- **8086 用补码**，不是原码/反码。
- **补码速算口诀**：「从右往左第一个 1，右边不变左边取反」。
- **溢出判据**：单符号位用「双正得负/双负得正」，双符号位用「两位不同」。
- 与第02讲条目 146、第03讲条目 138 联动：CF 管无符号、OF 管有符号溢出。

### ④ 横向辨析

| 表示法 | 正数 | 负数 | 0 的表示 | 8086 用？ |
|---|---|---|---|---|
| 原码 | 符号位 0 | 符号位 1 + 数值 | +0 / **−0** | 否 |
| 反码 | 同原码 | 数值位取反 | +0 / −0 | 否 |
| **补码** | 同原码 | 反码 +1 | **只有 +0** | **✔** |

**补码的三大优点**：① 符号位参与运算；② 加减法统一（减法转加法）；
③ 只有一个 0。

- [ ] 「系统总线」是三者总称，不是三大总线之一
- [ ] 原码/反码/补码的区别；8086 用**补码**
- [ ] 补码速算口诀：「从右往左第一个 1，右边不变左边取反」
- [ ] **8 位补码范围 −128 ~ +127**，`80H = −128`
- [ ] 补码只有一个 0（没有 −0）
- [ ] 溢出判据：单符号位「双正得负/双负得正」；双符号位「两位不同」
- [ ] `5 + (−1)` = 4、`80H + 80H` 溢出，能验算
