## 怎么用

1. **按讲次从后往前刷**：建议第 6~10 讲重点、从后往前复习（第10 → 第1）。上表顺序即此顺序。
2. **看「层级」分配时间**：〔掌握〕必须会编程/计算 → 〔理解〕能说清机理 → 〔了解〕有印象即可。
3. **看「来源」判断可信度**：四源齐全最稳；**只有单一来源的条目见下方缺口清单，是最需要补强的地方**。
4. **「详解」列是四段式补充说明的入口**：点 `#编号` 跳到对应讲次详解文件中的该条目。
   每个条目在该文件里都是固定四段——① 机理详解 ② 例题（逐步推演）③ 易错提示 ④ 横向辨析。
5. **「正文」列是主文档的知识锚点**：两列配合使用——主文档给结论，详解给推演。
6. **「自测」列用来打勾**：全部勾完再进考场。
